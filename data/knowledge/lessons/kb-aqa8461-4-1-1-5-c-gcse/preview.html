Microscopy

Magnification = size of image ÷ size of real object, with both in the same unit.

GCSE

Learning objectives

  • Use magnification = size of image ÷ size of real object to work out magnification
  • Calculate real size from an image
  • Calculate answers in standard form

Units for small lengths

Cells are measured in micrometres (µm): 1 mm = 1000 µm. Smaller structures are measured in nanometres (nm): 1 µm = 1000 nm. Before comparing or dividing two lengths, convert them to the same unit.

Calculations

Magnification says how many times bigger an image is than the real object. Use the formula: divide the size of the image by the real size of the object, with both in the same unit. Magnification has no unit: write it as, for example, ×400.

magnification = size of image ÷ size of real objectboth sizes in the same unit

Rearrange the magnification equation to find a real size from an image and its magnification, or an image size from a real size.

size of real object = size of image ÷ magnificationand size of image = size of real object × magnification

Very small sizes are often written in standard form. To express a number in standard form, write it as a number between 1 and 10 multiplied by a power of ten.

  • Write the number with one non-zero digit before the decimal point.
  • Count how many places the decimal point moved: that is the power of ten.
  • Moving it to the right gives a negative power: 0.000 025 m = 2.5 × 10⁻⁵ m.
Worked example

In a drawing at a magnification of ×1500, a cell is 30 mm long. What is its real length, in µm and in metres in standard form?

  1. Convert the image size: 30 mm = 30 000 µm.
  2. Real size = size of image ÷ magnification = 30 000 µm ÷ 1500 = 20 µm.
  3. In metres: 20 µm = 0.000 020 m = 2.0 × 10⁻⁵ m.
Worked example

A cell is 15 µm long. In a micrograph it is 45 mm long. What is the magnification?

  1. Convert to the same unit: 45 mm = 45 × 1000 = 45 000 µm.
  2. Magnification = size of image ÷ size of real object = 45 000 µm ÷ 15 µm.
  3. Magnification = ×3000.
Common mistake"Magnification = size of real object ÷ size of image." Divide the image size by the real size; a magnification is bigger than 1 because the image is bigger than the object.
Common mistake"A 45 mm image of a 15 µm cell is magnified ×3, because 45 ÷ 15 = 3." Convert to the same unit first: 45 mm is 45 000 µm, so the magnification is 45 000 ÷ 15 = ×3000.
Common mistake"The magnification is 400 mm." Magnification is a ratio of two lengths, so it has no unit: write ×400.

  2. Which of these best describes nanometre?

    • A unit of length, nm: one thousandth of a micrometre
    • A 45 mm image of a 15 µm cell is magnified ×3, because 45 ÷ 15 = 3
    • Magnification = size of real object ÷ size of image
    • The magnification is 400 mm

  3. A 45 mm image of a 15 µm cell is magnified ×3, because 45 ÷ 15 = 3. true or false

    Answer: False

    Convert to the same unit first: 45 mm is 45 000 µm, so the magnification is 45 000 ÷ 15 = ×3000.

  4. The magnification is 400 mm. true or false

    Answer: False

    Magnification is a ratio of two lengths, so it has no unit: write ×400.

  5. Magnification = size of real object ÷ size of image. true or false

    Answer: False

    Divide the image size by the real size; a magnification is bigger than 1 because the image is bigger than the object.
