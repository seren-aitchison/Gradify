## Rules

| Area | Points | How they're earned |
|---|---|---|
| Functionality | 20 | Homepage built (4) · every internal link on its pages resolves (6, less a share for each broken one) · a course or dedicated subject tool (6) · the shared notes tools (4) |
| Content | 20 | Written lessons, up to 300 (12) · share of the course's lessons written (8) · a subject tool without a course counts 6 |
| Learning experience | 15 | The course engine's learning tools: paths, review, mastery, revisit, plan and AI tutor (5) · interactives, up to 15 (5) · cumulative exams, up to 3 (3) · a dedicated subject tool (2) |
| Engineering | 15 | Automated tests that cover its course or tool (4) · title, description, viewport and language on every page (4, by share) · no broken internal links (3) · homepage HTML under 150 KB (2) · built on the shared Gradify Kit (2) |
| Backend | 10 | Shared by every site: backend code in the repository (2) · project configured in gradify.config.js (3) · accounts verified working in production (3) · AI verified working in production (2), both from the last scripts/verify-backend.mjs run |
| Academic quality | 10 | For each school: reviewed (4) · sources checked (3) · expert sign-off (3), by share of schools. No course means nothing to review: 0 |
| Accessibility | 10 | Static, on every page by share: a language set (1) · zoom not disabled (2) · a title (1) · every static image has alt text (1) · every static button has a name (1). In a real browser (scripts/check-a11y.cjs, homepage and course page): text meeting WCAG AA contrast (2) and focus stops with a visible indicator (2), by share. Not run means 0 for those 4 |
