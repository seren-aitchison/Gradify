# HistoryGradify: review pack for a history teacher or university historian

Generated by `node scripts/review-pack.mjs history` on 2026-11-08. Every school listed here is **generated** and **QA verified** (automated checks pass) and **not yet academically verified**. Automated checks establish structure, format and internal consistency; they can't establish that explanations, interpretations, dates, figures and mark schemes are right. That is this review.

**Scope:** 12 schools, 215 lessons, 1077 questions. Lessons are listed in priority order within each school: most contested material first.

## What to check

Work through the checklist in docs/CURRICULUM_QA.md, lesson by lesson. In particular:

- **Facts**: dates, names, figures and technical claims, against the sources each lesson cites (the citation register is `docs/qa/history-sources.md`).
- **Interpretations**: every `contested` evidence line presents the debate fairly, names the main positions correctly, and nothing contested is stated as settled fact elsewhere in the lesson.
- **Level**: the depth matches each lesson's stated level (its LV: line); nothing is claimed about any exam board's or professional body's specification that it doesn't say.
- **Questions**: one defensible right answer; distractors plausibly wrong, not partly right; explanations correct; the extended-answer rubric points match what an examiner would credit.
- **Sources**: each citation exists as cited (author, title, publisher, year).

## How to record the review

In `kit/courses/history/qa.js`, for each school reviewed:

```js
reviewed: { date: "YYYY-MM-DD", by: "name (role)", findings: ["…"], open: ["…"] },
sources: { date: "YYYY-MM-DD", by: "name (role)", method: "…", checked: 0, corrected: 0, open: [] },
signoff: { date: "YYYY-MM-DD", by: "name (role)" },
```

Sources can't be recorded before review, and sign-off needs both (tests/qa.test.mjs and tests/new-courses.test.mjs enforce the order). An AI session can never record sign-off. Until sign-off, every lesson shows that it hasn't been expert-reviewed.
