Lessons in this school

  1. Control Theory
    Control theory designs inputs that make a dynamical system behave as we want: a thermostat holding temperature, cruise control holding speed, an autopilot holding course.
  2. Linear Systems
    Linear systems obey superposition: the response to a sum of inputs is the sum of the responses.
  3. Nonlinear Systems
    Real systems are often non-linear: saturating actuators, friction, aerodynamics, chemical kinetics.
  4. State-Space Representation
    State-space models describe a system by a vector of state variables and first-order differential equations, ẋ = Ax + Bu and y = Cx + Du.
  5. Transfer Functions
    A transfer function is the Laplace transform of a system's output divided by that of its input, assuming zero initial conditions.
  6. Hybrid Systems
    Hybrid systems combine continuous dynamics with discrete events and modes, like a bouncing ball, a thermostat switching a heater, or a car changing gears.
  7. Switched Systems
    A switched system changes between several dynamical modes according to a switching signal, as in power converters or gear changes.
  8. Open-Loop Control
    Open-loop control applies a pre-planned input without measuring the result, like a toaster timer or a washing machine cycle.
  9. Closed-Loop Control
    Closed-loop control measures the output and uses the error to adjust the input continuously.
  10. Feedback Control
    Feedback is the principle behind all closed-loop control: measure, compare, correct.
  11. PID Control
    PID controllers combine proportional, integral and derivative actions on the error.
  12. Stability Theory
    Stability theory asks whether a system returns to equilibrium after a disturbance, or whether its responses stay bounded.
  13. Lyapunov Stability
    Lyapunov's direct method proves stability without solving the equations, by finding an energy-like function that always decreases along trajectories.
  14. Controllability
    A system is controllable if inputs can steer it from any state to any other in finite time.
  15. Observability
    A system is observable if its internal state can be worked out from its outputs and inputs over time.
  16. Frequency Response
    The frequency response describes how a stable linear system scales and shifts sinusoids of each frequency.
  17. Bode Plots
    Bode plots show a system's gain in decibels and its phase against frequency on a logarithmic scale.
  18. Nyquist Stability Criterion
    The Nyquist criterion decides closed-loop stability from the open-loop frequency response by counting how the Nyquist plot encircles the point −1.
  19. Root Locus
    The root locus shows how the closed-loop poles move in the complex plane as a gain varies from zero to infinity.
  20. State Estimation
    State estimation reconstructs a system's internal state from noisy, incomplete measurements.
  21. Kalman Filtering
    In control, the Kalman filter is the optimal state observer for linear systems with Gaussian process and measurement noise.
  22. System Identification
    System identification builds mathematical models of dynamical systems from measured input–output data.
  23. Linear Quadratic Regulation
    The linear quadratic regulator chooses state feedback that minimises a weighted sum of state deviations and control effort.
  24. Model Predictive Control
    Model predictive control repeatedly solves an optimisation over a future horizon using a model, applies the first input, then re-plans with new measurements.
  25. Robust Control
    Robust control designs controllers that keep stability and performance despite uncertainty in the plant model.
  26. Adaptive Control
    Adaptive controllers adjust their own parameters online as they learn about an uncertain or changing plant.
  27. Stochastic Control
    Stochastic control chooses actions for systems driven by random disturbances, optimising expected performance.
  28. Nonlinear Control
    Nonlinear control designs controllers that work across large operating ranges where linear approximations fail.
  29. Distributed Control
    Distributed control coordinates many agents, such as drones, robots, power generators or sensors, each acting on local information and communicating with neighbours.
  30. Networked Control Systems
    Networked control systems close feedback loops over communication networks, which add delays, packet losses and limited data rates.

Key terms

Plant
The system being controlled, such as a motor, aircraft or chemical reactor
Superposition
For linear systems, input au₁ + bu₂ produces output ay₁ + by₂
Equilibrium point
A state x* where f(x*) = 0, so the system stays there if undisturbed
State vector
x(t), the minimal set of variables whose current values, with future inputs, determine future behaviour
Transfer function
G(s) = Y(s)/U(s), the ratio of Laplace transforms of output and input
Hybrid automaton
A model with discrete modes, continuous dynamics in each mode, guard conditions for switching and reset maps
Switched linear system
ẋ = Aσ(t)x, where the switching signal σ(t) selects one of several matrices A₁, …, Am
Open-loop control
Control where the input is computed from the reference and a model, without using measurements of the output
Sensitivity function
S = 1/(1 + L), with loop gain L = GC; it measures how disturbances and model errors affect the output
Pole placement
Choosing state-feedback gains K in u = −Kx so the closed-loop matrix A − BK has desired eigenvalues
PID controller
u = Kpe + Ki∫e dt + Kd de/dt, or C(s) = Kp + Ki/s + Kds
Asymptotic stability
Trajectories starting near the equilibrium stay near it and converge to it
Lyapunov function
A function V(x) with V(0) = 0, V(x) > 0 elsewhere and V̇ = ∇V·f(x) ≤ 0 along trajectories
Controllability matrix
𝒞 = [B, AB, A2B, …, An−1B]; the system is controllable iff rank 𝒞 = n
