Key terms and formulas at a glance

Plant
The system being controlled, such as a motor, aircraft or chemical reactor
Superposition
For linear systems, input au₁ + bu₂ produces output ay₁ + by₂
Equilibrium point
A state x* where f(x*) = 0, so the system stays there if undisturbed
State vector
x(t), the minimal set of variables whose current values, with future inputs, determine future behaviour
Transfer function
G(s) = Y(s)/U(s), the ratio of Laplace transforms of output and input
Hybrid automaton
A model with discrete modes, continuous dynamics in each mode, guard conditions for switching and reset maps
Switched linear system
ẋ = Aσ(t)x, where the switching signal σ(t) selects one of several matrices A₁, …, Am
Open-loop control
Control where the input is computed from the reference and a model, without using measurements of the output
Sensitivity function
S = 1/(1 + L), with loop gain L = GC; it measures how disturbances and model errors affect the output

Five sample flashcards

Answer each from memory, then open it to check. Still foggy? Each card has the plain-English version.

What is the error signal in a feedback loop?

The reference minus the measured output. From “Control Theory” →

In plain English: Control theory designs inputs that make a dynamical system behave as we want: a thermostat holding temperature, cruise control holding speed, an autopilot holding course. Key idea: Control systems combine plant, sensor, controller and actuator; goals are stability, tracking, disturbance rejection and robustness; feedback compares output with reference.

What does a common Lyapunov function guarantee?

Stability under arbitrary switching. From “Switched Systems” →

In plain English: A switched system changes between several dynamical modes according to a switching signal, as in power converters or gear changes. Key idea: Switched systems change modes by a switching signal; stability depends on switching; common Lyapunov functions guarantee stability under any switching; dwell-time conditions limit fast switching.

What must V̇ satisfy for asymptotic stability?

Negative definite (V̇ < 0 away from the origin). From “Lyapunov Stability” →

In plain English: Lyapunov's direct method proves stability without solving the equations, by finding an energy-like function that always decreases along trajectories. Key idea: Lyapunov functions prove stability by decreasing along trajectories; the Lyapunov equation handles linear systems; LaSalle's principle covers V̇ ≤ 0; the method works where linearisation fails.

Where does a root locus start?

At the open-loop poles. From “Root Locus” →

In plain English: The root locus shows how the closed-loop poles move in the complex plane as a gain varies from zero to infinity. Key idea: Root loci trace closed-loop poles as gain varies; Evans's rules sketch them; damping-ratio lines guide gain choice; zeros and poles from compensators reshape the locus.

What does the H∞ norm measure?

The largest gain of a system over all frequencies. From “Robust Control” →

In plain English: Robust control designs controllers that keep stability and performance despite uncertainty in the plant model. Key idea: Robust control guarantees stability under model uncertainty; the small-gain theorem gives conditions; H∞ design minimises weighted worst-case gains; μ handles structured uncertainty.

Quick quiz: test yourself on Control Theory and Systems

9 questions from the course, from foundation recall to stretch. Pick an answer, then say whether you knew it or guessed.

  1. In a car's cruise control, which component is the actuator? (Foundation recall)
    Show the answer

    The throttle that changes engine power. The actuator applies the control input to the plant.

  2. A system has eigenvalues −1 ± 3i. How does its unforced response behave? (Foundation recall)
    Show the answer

    Decaying oscillation. Negative real parts decay; imaginary parts give oscillation at 3 rad/s.

  3. For ẋ = x − x3, what is the stability of x = 0? (Foundation recall)
    Show the answer

    Unstable, since the linearisation ẋ ≈ x grows. The linearisation at 0 is ẋ ≈ f′(0)x = x, with f′(0) = 1 > 0, so small deviations grow and the origin is unstable.

  4. Why do control engineers model disturbances explicitly? (Exam style)
    Show the answer

    Controllers must keep performance despite unknown inputs like wind, load changes or hills. Disturbance rejection is a main purpose of feedback.

  5. Why are non-linear systems often linearised for control design? (Exam style)
    Show the answer

    Near an operating point a linear model approximates the behaviour well, enabling exact design tools. Small deviations obey the Jacobian dynamics.

  6. Why are state-space models well suited to multi-input, multi-output systems? (Exam style)
    Show the answer

    Matrices B and C handle any number of inputs and outputs in one framework. Single matrix equations replace many coupled transfer functions.

  7. Why can a linearisation predict local stability but not the region of attraction? (Stretch)
    Show the answer

    It describes only small deviations; far away, non-linear terms can push trajectories elsewhere. The Jacobian ignores higher-order terms that matter for large deviations.

  8. How can switching between two unstable modes produce a stable system? (Stretch)
    Show the answer

    Well-timed switching uses each mode's contracting directions, so the state shrinks. Each unstable mode may still contract in some directions, and switching exploits them.

  9. What does Bode's sensitivity integral (the waterbed effect) imply? (Stretch)
    Show the answer

    Pushing sensitivity down over some frequencies forces it up over others. For stable open loops, ∫ ln|S(iω)| dω = 0, so reductions must be balanced.

Key takeaways

  • Control systems combine plant, sensor, controller and actuator; goals are stability, tracking, disturbance rejection and robustness; feedback compares output with reference.
  • Linear systems obey superposition; state-space and transfer-function models describe them; solutions use the matrix exponential; eigenvalues determine growth, decay and oscillation.
  • Non-linear systems can have many equilibria, limit cycles, finite escape and chaos; linearisation gives local behaviour; regions of attraction and Lyapunov methods address global behaviour.
  • State-space models use first-order matrix equations; higher-order ODEs convert via position and velocity states; eigenvalues of A are poles; G(s) = C(sI − A)−1B + D links to transfer functions.
  • Transfer functions turn ODEs into algebra; poles determine stability and speed; zeros shape responses; DC gain and the final value theorem give steady states; second-order forms use ζ and ωₙ.
  • Hybrid systems mix continuous flows with discrete jumps via modes, guards and resets; Zeno behaviour and chattering can occur; reachability analysis verifies safety of cyber-physical systems.

Common mistakes in Control Theory and Systems

  • Designing a controller without considering sensor noise and actuator limits.
  • Applying superposition to a system with saturation or other non-linearity.
  • Concluding global stability from a linearisation, which only describes behaviour near the equilibrium.
  • Choosing too few state variables, so the model can't capture the system's memory.
  • Applying the final value theorem to an unstable system, where it gives a meaningless answer.
  • Simulating Zeno systems naively, which gets stuck taking ever smaller steps.

Lessons in this school

  1. Control Theory
    Control theory designs inputs that make a dynamical system behave as we want: a thermostat holding temperature, cruise control holding speed, an autopilot holding course.
  2. Linear Systems
    Linear systems obey superposition: the response to a sum of inputs is the sum of the responses.
  3. Nonlinear Systems
    Real systems are often non-linear: saturating actuators, friction, aerodynamics, chemical kinetics.
  4. State-Space Representation
    State-space models describe a system by a vector of state variables and first-order differential equations, ẋ = Ax + Bu and y = Cx + Du.
  5. Transfer Functions
    A transfer function is the Laplace transform of a system's output divided by that of its input, assuming zero initial conditions.
  6. Hybrid Systems
    Hybrid systems combine continuous dynamics with discrete events and modes, like a bouncing ball, a thermostat switching a heater, or a car changing gears.
  7. Switched Systems
    A switched system changes between several dynamical modes according to a switching signal, as in power converters or gear changes.
  8. Open-Loop Control
    Open-loop control applies a pre-planned input without measuring the result, like a toaster timer or a washing machine cycle.
  9. Closed-Loop Control
    Closed-loop control measures the output and uses the error to adjust the input continuously.
  10. Feedback Control
    Feedback is the principle behind all closed-loop control: measure, compare, correct.
  11. PID Control
    PID controllers combine proportional, integral and derivative actions on the error.
  12. Stability Theory
    Stability theory asks whether a system returns to equilibrium after a disturbance, or whether its responses stay bounded.
  13. Lyapunov Stability
    Lyapunov's direct method proves stability without solving the equations, by finding an energy-like function that always decreases along trajectories.
  14. Controllability
    A system is controllable if inputs can steer it from any state to any other in finite time.
  15. Observability
    A system is observable if its internal state can be worked out from its outputs and inputs over time.
  16. Frequency Response
    The frequency response describes how a stable linear system scales and shifts sinusoids of each frequency.
  17. Bode Plots
    Bode plots show a system's gain in decibels and its phase against frequency on a logarithmic scale.
  18. Nyquist Stability Criterion
    The Nyquist criterion decides closed-loop stability from the open-loop frequency response by counting how the Nyquist plot encircles the point −1.
  19. Root Locus
    The root locus shows how the closed-loop poles move in the complex plane as a gain varies from zero to infinity.
  20. State Estimation
    State estimation reconstructs a system's internal state from noisy, incomplete measurements.
  21. Kalman Filtering
    In control, the Kalman filter is the optimal state observer for linear systems with Gaussian process and measurement noise.
  22. System Identification
    System identification builds mathematical models of dynamical systems from measured input–output data.
  23. Linear Quadratic Regulation
    The linear quadratic regulator chooses state feedback that minimises a weighted sum of state deviations and control effort.
  24. Model Predictive Control
    Model predictive control repeatedly solves an optimisation over a future horizon using a model, applies the first input, then re-plans with new measurements.
  25. Robust Control
    Robust control designs controllers that keep stability and performance despite uncertainty in the plant model.
  26. Adaptive Control
    Adaptive controllers adjust their own parameters online as they learn about an uncertain or changing plant.
  27. Stochastic Control
    Stochastic control chooses actions for systems driven by random disturbances, optimising expected performance.
  28. Nonlinear Control
    Nonlinear control designs controllers that work across large operating ranges where linear approximations fail.
  29. Distributed Control
    Distributed control coordinates many agents, such as drones, robots, power generators or sensors, each acting on local information and communicating with neighbours.
  30. Networked Control Systems
    Networked control systems close feedback loops over communication networks, which add delays, packet losses and limited data rates.

Control Theory and Systems: questions students ask

What does superposition mean?

The response to a sum of inputs is the sum of responses.

What is a region of attraction?

The set of starting states that converge to a stable equilibrium.

Where must poles lie for a continuous-time system to be stable?

In the left half of the complex plane.

What is a guard in a hybrid automaton?

A condition that triggers a transition between modes.
