Lessons in this school

  1. Vectors
    A vector has both size and direction: a displacement, velocity or force.
  2. Vector Algebra
    Vector algebra multiplies vectors in two useful ways.
  3. Vector Spaces
    A vector space is any collection of objects that can be added and scaled following the familiar rules.
  4. Subspaces
    A subspace is a vector space sitting inside a larger one: a line or plane through the origin, or the solutions of a homogeneous linear system.
  5. Linear Combinations
    A linear combination adds scalar multiples of vectors: c₁v₁ + c₂v₂ + … + ckvk.
  6. Span
    The span of a set of vectors is everything you can build from them by linear combinations.
  7. Linear Independence
    Vectors are linearly independent when none of them can be built from the others.
  8. Basis and Dimension
    A basis is an independent set that spans the space: the smallest complete set of building blocks.
  9. Matrices
    A matrix is a rectangular array of numbers.
  10. Matrix Algebra
    Matrix algebra has its own rules.
  11. Matrix Operations
    The basic matrix operations are addition, scalar multiplication, the trace and elementary row operations.
  12. Matrix Multiplication
    Matrix multiplication combines rows of the first matrix with columns of the second.
  13. Matrix Transposition
    The transpose of a matrix swaps its rows and columns.
  14. Matrix Inversion
    The inverse of a square matrix undoes it: A−1A = I.
  15. Determinants
    The determinant of a square matrix is a single number that tells you whether the matrix is invertible and how it scales area or volume.
  16. Rank of a Matrix
    The rank of a matrix is the number of independent rows (or columns), equal to the number of pivots after row reduction.
  17. Column Space
    The column space of a matrix is the span of its columns: every vector Ax can produce.
  18. Row Space
    The row space of a matrix is the span of its rows.
  19. Null Space
    The null space (kernel) of a matrix is the set of solutions of Ax = 0.
  20. Systems of Linear Equations
    Systems of linear equations appear everywhere: balancing chemical reactions, network flows, economics, circuits and fitting curves.
  21. Linear Transformations
    A linear transformation is a function between vector spaces that respects addition and scaling.
  22. Change of Basis
    The same vector has different coordinates in different bases, and the same linear map has different matrices.
  23. Similarity Transformations
    Two matrices are similar when they represent the same linear map in different bases: B = P−1AP.
  24. Eigenvalues
    An eigenvalue λ of a square matrix A is a number for which Av = λv has a non-zero solution v.
  25. Eigenvectors
    An eigenvector is a direction a linear map doesn't turn: it's only stretched by its eigenvalue.
  26. Eigenspaces
    The eigenspace for an eigenvalue λ is the set of all its eigenvectors together with zero.
  27. Characteristic Polynomials
    The characteristic polynomial det(A − λI) packages a matrix's eigenvalues as its roots, along with the trace and determinant as coefficients.
  28. Diagonalisation
    Diagonalising a matrix means writing it as A = PDP−1 with D diagonal.
  29. Jordan Normal Form
    Not every matrix can be diagonalised, but every complex matrix is similar to a Jordan normal form: nearly diagonal, with some 1s just above the diagonal.
  30. Symmetric Matrices
    Real symmetric matrices (A = Aᵀ) are the best-behaved matrices: their eigenvalues are real and their eigenvectors can be chosen orthonormal.
  31. Hermitian Matrices
    A Hermitian matrix equals its own conjugate transpose: the complex counterpart of a real symmetric matrix.
  32. Positive Definite Matrices
    A symmetric matrix is positive definite when xᵀAx > 0 for every non-zero x.
  33. Inner Product Spaces
    An inner product generalises the dot product, giving lengths and angles in any vector space, including spaces of functions.
  34. Norms
    A norm measures the size of a vector.
  35. Orthogonality
    Orthogonal vectors are perpendicular: their inner product is zero.
  36. Orthogonal Projections
    An orthogonal projection drops a vector onto a subspace at right angles, giving the closest point in that subspace.
  37. Gram–Schmidt Process
    The Gram–Schmidt process turns any linearly independent set into an orthonormal one spanning the same space.
  38. Matrix Decomposition
    A matrix decomposition writes a matrix as a product of simpler matrices: triangular, orthogonal or diagonal.
  39. LU Decomposition
    LU decomposition writes a square matrix as a lower triangular L times an upper triangular U.
  40. QR Decomposition
    QR decomposition writes a matrix as an orthogonal (or orthonormal-column) Q times an upper triangular R.
  41. Cholesky Decomposition
    The Cholesky decomposition writes a symmetric positive definite matrix as LLᵀ, a lower triangular matrix times its transpose.
  42. Singular Value Decomposition (SVD)
    The singular value decomposition writes any matrix as A = UΣVᵀ: a rotation, a stretch and another rotation.
  43. Principal Component Analysis (PCA)
    Principal component analysis finds the directions in which data vary most and re-expresses the data along them.
  44. Sparse Matrices
    A sparse matrix is mostly zeros.
  45. Block Matrices
    Partitioning a matrix into blocks lets you treat submatrices as single entries.
  46. Numerical Linear Algebra
    Numerical linear algebra designs fast, accurate algorithms for matrix problems on real computers with finite precision.
  47. Multilinear Algebra
    Multilinear algebra studies functions that are linear in each of several vector arguments, such as the dot product, the determinant and bilinear forms.
  48. Tensor Products
    The tensor product V ⊗ W combines two vector spaces into one whose dimension is the product of theirs.
  49. Tensor Algebra
    The tensor algebra collects all tensor powers of a vector space into one algebra, and tensors of each type describe multilinear quantities such as stress, curvature and multiway data.
  50. Exterior Algebra
    The exterior algebra is built from the wedge product, an antisymmetric product of vectors that measures oriented areas, volumes and their higher-dimensional analogues.

Key terms

Magnitude
The length of a vector: |v| = √(v₁2 + v₂2 + v₃2)
Dot product
a · b = Σ aibi = |a||b| cos θ, a scalar
Vector space
A set V with addition and scalar multiplication over a field, satisfying the eight axioms (associativity, commutativity, zero, negatives, distributivity, …)
Subspace
A subset containing 0 and closed under addition and scalar multiplication
Linear combination
c₁v₁ + … + ckvk for scalars ci
Span
span{v₁, …, vk}, the set of all linear combinations of the vi
Linearly independent
c₁v₁ + … + ckvk = 0 only when every ci = 0
Basis
A linearly independent spanning set
m × n matrix
A matrix with m rows and n columns; aij is the entry in row i, column j
Non-commutativity
In general AB ≠ BA
Trace
tr A, the sum of the diagonal entries of a square matrix
Matrix product
(AB)ij = Σk aikbkj, the dot product of row i of A with column j of B
Transpose
Aᵀ with (Aᵀ)ij = aji
Inverse matrix
A−1 with AA−1 = A−1A = I
