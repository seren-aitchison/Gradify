Lessons in this school

  1. Mathematics for Machine Learning
    Machine learning builds models that improve from data, and it rests on four mathematical pillars: linear algebra, calculus, probability and optimisation.
  2. Statistical Learning Theory
    Statistical learning theory asks when and why learning from finite data works.
  3. Linear Models
    Linear models predict outputs as weighted sums of inputs.
  4. Optimisation Algorithms
    Training a machine learning model means minimising a loss function, often with millions of parameters.
  5. Stochastic Gradient Descent
    Stochastic gradient descent updates a model using the gradient on a small random batch of data rather than the whole dataset.
  6. Backpropagation Mathematics
    Backpropagation computes the gradient of a neural network's loss with respect to every weight by applying the chain rule backwards through the network.
  7. Probability Models
    Probability models describe data as generated by random processes with parameters to learn.
  8. Bayesian Learning
    Bayesian learning treats model parameters as uncertain, updating a prior distribution with data to get a posterior.
  9. Bayesian Networks
    A Bayesian network represents a joint probability distribution with a directed acyclic graph, where each variable depends only on its parents.
  10. Probabilistic Graphical Models
    Probabilistic graphical models use graphs to represent dependencies among many random variables.
  11. Markov Models
    Markov models assume the future depends on the present but not the past beyond it.
  12. Gaussian Processes
    A Gaussian process is a probability distribution over functions, where any finite set of function values has a joint Gaussian distribution.
  13. Uncertainty Estimation
    Machine learning models should know what they don't know.
  14. Conformal Prediction
    Conformal prediction wraps any machine learning model to produce prediction sets or intervals with a guaranteed coverage rate, such as 90%, assuming only that data are exchangeable.
  15. Kernel Methods
    Kernel methods let linear algorithms learn non-linear patterns by implicitly mapping data into a high-dimensional feature space.
  16. Support Vector Machines
    Support vector machines find the boundary that separates two classes with the widest possible margin.
  17. Decision Trees
    Decision trees predict by asking a sequence of yes/no questions about features, splitting the data into regions.
  18. Ensemble Learning Mathematics
    Ensemble methods combine many models to get better predictions than any one alone.
  19. Random Forest Theory
    Random forests average many decision trees, each grown on a bootstrap sample and choosing splits from a random subset of features.
  20. Boosting Theory
    Boosting builds a strong model by adding weak learners one at a time, each correcting the errors of the current ensemble.
  21. Clustering Mathematics
    Clustering groups data points so that points in a cluster are more similar to each other than to those in other clusters.
  22. Dimensionality Reduction
    Dimensionality reduction represents high-dimensional data with fewer variables while keeping its important structure.
  23. Manifold Learning
    Manifold learning assumes high-dimensional data lie near a lower-dimensional curved surface and tries to unroll it.
  24. Neural Network Theory
    Neural network theory explains what networks can represent and why they learn.
  25. Deep Learning Mathematics
    Deep learning mathematics covers the building blocks of modern networks: convolutions, activation functions, normalisation, initialisation and regularisation.
  26. Representation Learning
    Representation learning discovers useful features of data automatically rather than designing them by hand.
  27. Attention Mechanisms
    Attention lets a model weigh different parts of its input when producing each output, focusing on what's relevant.
  28. Transformer Mathematics
    Transformers stack attention and feed-forward layers with residual connections and normalisation.
  29. Information-Theoretic Learning
    Information theory gives machine learning its common losses and many of its explanations.
  30. Reinforcement Learning
    Reinforcement learning trains agents to make sequences of decisions by trial and error, maximising cumulative reward.
  31. Bellman Equations
    The Bellman equations express the value of a state as immediate reward plus the discounted value of what comes next.
  32. Policy Optimisation
    Policy optimisation improves a parameterised policy directly by following the gradient of expected return.
  33. Multi-Armed Bandits
    A multi-armed bandit chooses repeatedly among options with unknown rewards, balancing exploring uncertain arms with exploiting the best so far.
  34. Causal Machine Learning
    Causal machine learning combines causal inference with flexible models to estimate what would happen under interventions, such as a treatment's effect, rather than mere associations.
  35. Explainable AI Mathematics
    Explainable AI develops mathematical tools to show why a model made a prediction.

Key terms

Empirical risk
(1/n) Σ L(f(xᵢ), yᵢ), the average loss of model f on the training data
VC dimension
The largest number of points a model class can label in every possible way (shatter)
Logistic regression
P(y = 1 ∣ x) = σ(wᵀx + b) with sigmoid σ(z) = 1/(1 + e−z), fitted by maximising likelihood
Momentum
v ← βv + ∇L, w ← w − ηv: accumulating past gradients to speed progress along consistent directions
Mini-batch gradient
(1/B) Σi∈batch ∇Lᵢ(w), an unbiased estimate of the full gradient from B random examples
Backpropagation
Computing ∂L/∂w for all weights by propagating error signals δ backwards layer by layer
Likelihood
L(θ) = Π p(xᵢ ∣ θ), the probability of the observed data as a function of the parameters
Posterior
p(θ ∣ D) ∝ p(D ∣ θ)p(θ): the prior updated by the likelihood of the data
Directed acyclic graph
A graph with directed edges and no cycles, used to show which variables influence which
Markov random field
An undirected graphical model where the joint distribution factorises over cliques: p(x) = (1/Z) Π ψC(xC)
Stationary distribution
A distribution π with πP = π, unchanged by one step of the chain
Gaussian process
f ~ GP(m, k): any finite collection f(x₁), …, f(xₙ) is jointly Gaussian with mean m and covariance kᵢⱼ = k(xᵢ, xⱼ)
Aleatoric uncertainty
Irreducible noise in the data, such as label ambiguity or measurement error
Nonconformity score
A measure of how unusual an example is under the model, such as |y − ŷ| for regression
