Key terms and formulas at a glance

Truncation error
Error from approximating an infinite or exact process by a finite one, such as cutting off a series
Order of convergence
p such that errors satisfy ek+1 ≈ C ekp; p = 1 is linear, p = 2 quadratic
Minimax approximation
The polynomial p minimising the maximum error max|f(x) − p(x)| on an interval
Relative error
|x̂ − x|/|x|, the error as a fraction of the true value
Machine epsilon
The gap between 1 and the next floating-point number; about 2.2 × 10−16 in double precision
Backward stable algorithm
One whose computed result is the exact result for slightly perturbed data, with perturbations of the order of machine precision
Condition number of a function
κ(x) = |x f′(x)/f(x)|, the ratio of relative output change to relative input change
Interval
[a, b], the set of reals between a and b, representing an uncertain value
Bracketing method
A method that keeps an interval [a, b] with f(a) and f(b) of opposite signs, so a root stays inside
Intermediate value theorem
A continuous function with f(a) and f(b) of opposite signs has a root in (a, b)
Newton–Raphson iteration
xn+1 = xₙ − f(xₙ)/f′(xₙ)
Secant iteration
xn+1 = xₙ − f(xₙ)(xₙ − xₙ₋₁)/(f(xₙ) − f(xₙ₋₁))

What is truncation error?

Error from replacing an exact process by a finite approximation. From “Numerical Analysis” →

In plain English: Numerical analysis designs and studies algorithms that compute approximate answers to mathematical problems: solving equations, integrating, simulating. Key idea: Numerical analysis studies approximate algorithms for accuracy, stability and cost; errors come from modelling, data, truncation and rounding; error bounds and estimates guide trust in results.

What is [2, 3] + [−1, 1]?

[1, 4]. From “Interval Arithmetic” →

In plain English: Interval arithmetic computes with intervals guaranteed to contain the true values, rounding outward at every step. Key idea: Interval arithmetic encloses true values with guaranteed bounds; multiplication takes extremes of endpoint products; repeated variables cause overestimation; it powers computer-assisted proofs.

How fast does the Lebesgue constant grow for Chebyshev nodes?

Like log n. From “Lagrange Interpolation” →

In plain English: The Lagrange form writes the interpolating polynomial as a weighted sum of basis polynomials, each equal to 1 at one node and 0 at the others. Key idea: Lagrange basis polynomials are 1 at one node and 0 at the others; p = Σ yᵢℓᵢ; the barycentric form is fast and stable; Lebesgue constants measure error amplification and favour Chebyshev nodes.

What does the Armijo condition require?

Sufficient decrease in f relative to the step and slope. From “Numerical Optimisation” →

In plain English: Numerical optimisation turns the theory of minimisation into working algorithms: line searches, trust regions, and methods from gradient descent to Newton. Key idea: Line searches and trust regions globalise local methods; algorithm choice depends on derivatives and size; scaling, gradient checks and honest stopping tests make optimisation reliable.

Why are dot products costly in parallel?

They need global reductions across all processors. From “Parallel Numerical Algorithms” →

In plain English: Parallel numerical algorithms split computations so many processors can work at once while communicating as little as possible. Key idea: Parallel algorithms use data, domain and task parallelism; communication (halos, reductions) and load balance limit performance; communication-avoiding and domain decomposition methods address this.

Quick quiz: test yourself on Numerical Analysis and Scientific Computing

9 questions from the course, from foundation recall to stretch. Pick an answer, then say whether you knew it or guessed.

  1. Which kind of error comes from cutting a Taylor series off after a few terms? (Foundation recall)
    Show the answer

    Truncation error. Replacing an infinite series by a finite sum is a truncation (discretisation) error.

  2. What does quadratic convergence mean for an iterative method? (Foundation recall)
    Show the answer

    The error is roughly squared each iteration, doubling the correct digits. ek+1 ≈ Cek2, so 10−3 becomes about 10−6.

  3. Which approximation minimises the largest error over an interval? (Foundation recall)
    Show the answer

    The minimax (best uniform) approximation. Minimax approximation is defined by minimising the maximum absolute error.

  4. Why can't rounding error be eliminated by using a better formula alone? (Exam style)
    Show the answer

    Every floating-point operation rounds its result to finitely many digits. Finite precision means each arithmetic step may introduce a small error.

  5. How can you check a simulation code is implemented correctly? (Exam style)
    Show the answer

    Run it on a manufactured problem with a known solution and confirm errors shrink at the expected rate. Correct codes show the theoretical convergence order when the mesh is refined.

  6. What does a small backward error tell you about an algorithm's answer? (Exam style)
    Show the answer

    It is the exact answer to a problem very close to the one posed. Backward stability says the algorithm solved a nearby problem; conditioning decides how close that answer is.

  7. What property identifies a best minimax polynomial of degree n? (Stretch)
    Show the answer

    Its error reaches its maximum size at n + 2 points with alternating signs. Chebyshev's equioscillation theorem characterises the best approximation this way.

  8. Why is backward recursion stable for Iₙ₋₁ = (1 − Iₙ)/n? (Stretch)
    Show the answer

    Each step divides the existing error by n, so errors shrink rather than grow. The forward recursion multiplies errors by n; reversing it divides them.

  9. Why does x(1 − x) on [0, 1] give a wider interval than x − x2 written as ¼ − (x − ½)2? (Stretch)
    Show the answer

    Each form treats repeated occurrences of x independently; the second uses x only once, removing the overestimation. x(1 − x) evaluates to [0, 1] × [0, 1] = [0, 1], while the single-use form gives the exact [0, ¼].

Key takeaways

  • Numerical analysis studies approximate algorithms for accuracy, stability and cost; errors come from modelling, data, truncation and rounding; error bounds and estimates guide trust in results.
  • Numerical methods are matched to problem types; convergence and accuracy orders compare them; cost, robustness and verification by refinement and known solutions all matter.
  • Approximation replaces functions by simple ones; Taylor is local, least squares averages, minimax controls worst error; Weierstrass guarantees polynomial approximations exist; Chebyshev polynomials are key.
  • Absolute and relative errors measure accuracy; backward error asks what problem was solved; forward error ≲ condition × backward error; relative errors add in products, absolute in sums.
  • IEEE doubles have about 16 significant digits and unit roundoff 1.1 × 10−16; cancellation, overflow and non-associativity cause surprises; reformulate expressions to avoid them.
  • Stable algorithms keep rounding errors under control; pivoting and Householder QR are stable; recurrences can amplify errors; ODE methods have stability limits, and stiff problems need implicit methods.

Common mistakes in Numerical Analysis and Scientific Computing

  • Assuming more digits in the output means a more accurate answer.
  • Judging a method by one run instead of checking errors under refinement.
  • Expecting a Taylor polynomial to be accurate across a whole interval.
  • Reporting absolute error for quantities of very different sizes, where relative error is meaningful.
  • Testing two floating-point results with == instead of a tolerance.
  • Blaming the problem for an inaccurate result when an unstable algorithm is the cause.

Lessons in this school

  1. Numerical Analysis
    Numerical analysis designs and studies algorithms that compute approximate answers to mathematical problems: solving equations, integrating, simulating.
  2. Numerical Methods
    Numerical methods are the practical recipes of numerical analysis: algorithms for roots, integrals, linear systems and differential equations.
  3. Numerical Approximation
    Approximation theory replaces complicated functions by simpler ones, usually polynomials or rational functions, that are easy to compute.
  4. Error Analysis
    Error analysis quantifies how far a computed answer is from the truth and where the error comes from.
  5. Floating-Point Arithmetic
    Computers store real numbers in floating-point form, like scientific notation in binary with a fixed number of digits.
  6. Numerical Stability
    An algorithm is numerically stable if rounding errors don't grow out of control during the computation.
  7. Numerical Conditioning
    The condition number measures how sensitive a problem's answer is to small changes in its data.
  8. Interval Arithmetic
    Interval arithmetic computes with intervals guaranteed to contain the true values, rounding outward at every step.
  9. Root-Finding Algorithms
    Root-finding solves f(x) = 0, from computing square roots to finding equilibria.
  10. Bisection Method
    The bisection method halves an interval containing a sign change, keeping the half where the sign still changes.
  11. Newton–Raphson Method
    The Newton–Raphson method finds roots by following the tangent line to where it crosses the axis.
  12. Secant Method
    The secant method replaces Newton's derivative with the slope through the last two points.
  13. Fixed-Point Iteration
    Fixed-point iteration rewrites f(x) = 0 as x = g(x) and repeats xₙ₊₁ = g(xₙ).
  14. Polynomial Interpolation
    Polynomial interpolation finds the unique polynomial of degree at most n through n + 1 data points.
  15. Lagrange Interpolation
    The Lagrange form writes the interpolating polynomial as a weighted sum of basis polynomials, each equal to 1 at one node and 0 at the others.
  16. Newton Interpolation
    Newton's form builds the interpolating polynomial term by term using divided differences.
  17. Spline Interpolation
    Splines join low-degree polynomial pieces smoothly at points called knots, avoiding the wild oscillations of high-degree interpolation.
  18. Numerical Differentiation
    Numerical differentiation estimates derivatives from function values using finite differences.
  19. Gaussian Quadrature
    Gaussian quadrature chooses both the nodes and the weights of an integration rule to be as accurate as possible.
  20. Iterative Solvers
    Iterative solvers find the solution of Ax = b by improving a guess step by step, rather than factorising A.
  21. Conjugate Gradient Method
    The conjugate gradient method solves symmetric positive definite systems by minimising a quadratic along mutually conjugate directions.
  22. Gradient-Based Methods
    Gradient-based methods use derivative information to solve numerical problems, from minimising functions to fitting models and computing sensitivities.
  23. Numerical Optimisation
    Numerical optimisation turns the theory of minimisation into working algorithms: line searches, trust regions, and methods from gradient descent to Newton.
  24. Numerical Solutions of Differential Equations
    Most differential equations can't be solved exactly, so we approximate them on a grid of time steps or spatial points.
  25. Finite Element Analysis
    The finite element method breaks a complex region into small simple elements, such as triangles, and approximates the solution by simple functions on each.
  26. Mesh Generation
    Mesh generation divides a geometric domain into elements for numerical simulation.
  27. Adaptive Mesh Refinement
    Adaptive mesh refinement concentrates computational effort where it's needed, refining elements near shocks, corners or boundary layers and coarsening elsewhere.
  28. Computational Mathematics
    Computational mathematics uses computers to explore, conjecture and prove mathematical results, as well as to solve applied problems.
  29. High-Performance Computing
    High-performance computing (HPC) uses supercomputers with thousands to millions of processor cores to solve problems too large for ordinary computers.
  30. Parallel Numerical Algorithms
    Parallel numerical algorithms split computations so many processors can work at once while communicating as little as possible.
  31. Symbolic Computation
    Symbolic computation manipulates mathematical expressions exactly, rather than with approximate numbers: factorising polynomials, integrating functions in closed form and solving equations with parameters.
  32. Computer Algebra Systems
    Computer algebra systems (CAS) such as Mathematica, Maple, SageMath and SymPy put symbolic algorithms in the hands of everyone.
  33. Uncertainty Quantification
    Uncertainty quantification (UQ) asks how uncertainty in inputs, parameters and models affects the predictions of a simulation.
  34. Sensitivity Analysis
    Sensitivity analysis asks which inputs matter most for a model's output.
  35. Surrogate Modelling
    A surrogate model is a cheap approximation to an expensive simulation, built from a limited number of runs.
  36. Scientific Simulation
    Scientific simulation uses mathematical models and computation to study systems too large, small, fast, slow or dangerous for experiment: galaxies, proteins, climate and nuclear reactors.
  37. Mathematical Software
    Mathematical software packages the best numerical algorithms into reliable, tested libraries such as BLAS, LAPACK, FFTW and SciPy.

Numerical Analysis and Scientific Computing: questions students ask

What does Richardson extrapolation do?

Combines results at different h to cancel the leading error term.

What does the Weierstrass theorem guarantee?

Continuous functions on a closed interval can be uniformly approximated by polynomials.

What is backward error?

The input change needed for the computed result to be exact.

Which famous attractor's existence was proved with interval methods?

The Lorenz attractor (Tucker 2002).
