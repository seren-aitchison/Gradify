Lessons in this school

  1. Mathematica
    Mathematica is a commercial technical computing system from Wolfram Research, first released in 1988.
  2. Wolfram Language
    The Wolfram Language is the programming language behind Mathematica, Wolfram|Alpha and the Wolfram Cloud.
  3. Wolfram Alpha
    Wolfram|Alpha, launched in 2009, is a computational knowledge engine that answers questions typed in plain language by computing results rather than searching web pages.
  4. Mathematica Notebooks
    Mathematica notebooks are interactive documents that mix input code, output results, text and graphics in cells.
  5. Maple
    Maple is a commercial computer algebra system from Maplesoft, originating at the University of Waterloo in the early 1980s.
  6. Maxima
    Maxima is a free, open-source computer algebra system descended from Macsyma, developed at MIT from the late 1960s.
  7. SageMath
    SageMath is a free, open-source mathematics system started by William Stein in 2005.
  8. Jupyter Notebook
    Jupyter notebooks are web-based documents that combine live code, results, equations, text and plots.
  9. MATLAB
    MATLAB, from MathWorks, is a commercial environment for numerical computing built around matrices; its name means "matrix laboratory".
  10. GNU Octave
    GNU Octave is a free, open-source numerical computing environment largely compatible with MATLAB.
  11. Julia
    Julia is a high-level, high-performance language for technical computing, publicly launched in 2012.
  12. Python for Mathematics
    Python is a general-purpose language whose clear syntax and huge ecosystem make it a leading tool for mathematics, science and data.
  13. NumPy
    NumPy is Python's fundamental package for numerical arrays.
  14. SciPy
    SciPy builds on NumPy with algorithms for integration, optimisation, interpolation, linear algebra, statistics and signal processing.
  15. SymPy
    SymPy is a free computer algebra library written entirely in Python.
  16. JAX
    JAX is a Google library that combines a NumPy-like interface with automatic differentiation and compilation to accelerators.
  17. R
    R is a free language and environment for statistical computing and graphics, created by Ross Ihaka and Robert Gentleman in the 1990s.
  18. RStudio
    RStudio is an integrated development environment for R, providing an editor, console, plots, help and project management in one window.
  19. pandas
    pandas is Python's main library for tabular data, created by Wes McKinney in 2008.
  20. statsmodels
    statsmodels is a Python library for statistical modelling and econometrics.
  21. scikit-learn
    scikit-learn is Python's standard library for classical machine learning, started in 2007.
  22. SPSS
    IBM SPSS Statistics is a commercial package for statistical analysis, widely used in social sciences, psychology, health and market research.
  23. SAS
    SAS is a long-established commercial software suite for data management, statistics and analytics, originating at North Carolina State University and sold by SAS Institute since 1976.
  24. Stata
    Stata is a commercial statistics package from StataCorp, first released in 1985 and especially popular in economics, epidemiology and political science.
  25. Minitab
    Minitab is a commercial statistics package designed for ease of use, developed at Penn State University in 1972.
  26. Stan
    Stan is an open-source probabilistic programming language for Bayesian statistical modelling, released in 2012.
  27. PyMC
    PyMC is an open-source Python library for Bayesian modelling and probabilistic programming.
  28. BUGS
    BUGS (Bayesian inference Using Gibbs Sampling) was developed at the MRC Biostatistics Unit in Cambridge from 1989.
  29. PyTorch
    PyTorch is an open-source deep learning framework first released by Facebook (now Meta) AI Research in 2016 and now governed by the PyTorch Foundation.
  30. TensorFlow
    TensorFlow is Google's open-source machine learning platform, released in 2015.
  31. Excel
    Microsoft Excel is the world's most widely used spreadsheet, first released in 1985.
  32. Solver in Excel
    Excel's Solver add-in finds values of decision cells that optimise a target cell subject to constraints.
  33. Spreadsheet Calculations
    Spreadsheets are used for budgets, statistics, engineering calculations and models of all kinds.
  34. GeoGebra
    GeoGebra is free dynamic mathematics software created by Markus Hohenwarter in 2001.
  35. Desmos
    Desmos is a free online graphing calculator launched in 2011.
  36. LaTeX
    LaTeX is the standard system for typesetting mathematics, created by Leslie Lamport in the 1980s on top of Donald Knuth's TeX.
  37. MathJax
    MathJax is an open-source JavaScript library that displays mathematical notation in web browsers.
  38. GAP
    GAP (Groups, Algorithms, Programming) is a free system for computational discrete algebra, especially group theory, begun at RWTH Aachen in 1986.
  39. Magma
    Magma is a commercial computer algebra system from the University of Sydney, first released in 1993 as a successor to Cayley.
  40. PARI/GP
    PARI/GP is a free computer algebra system specialising in number theory, started by Henri Cohen and colleagues at Bordeaux in 1985.
  41. FEniCS
    FEniCS is an open-source platform for solving partial differential equations with the finite element method.
  42. COMSOL Multiphysics
    COMSOL Multiphysics is a commercial simulation package, originally released in 1998 as FEMLAB, for finite element modelling of coupled physical phenomena.
  43. ANSYS
    ANSYS is a widely used commercial suite for engineering simulation, founded by John Swanson in 1970.
  44. OpenFOAM
    OpenFOAM is a free, open-source C++ toolbox for computational fluid dynamics, released as open source in 2004.
  45. MapleSim
    MapleSim is a commercial physical modelling tool from Maplesoft, released in 2008 and built on the Modelica language and Maple's symbolic engine.
  46. Simulink
    Simulink, from MathWorks, is a graphical environment for modelling, simulating and analysing dynamic systems with block diagrams.
  47. Gurobi
    Gurobi is a commercial optimisation solver for linear, quadratic and mixed-integer programming, founded in 2008 by Zonghao Gu, Edward Rothberg and Robert Bixby.
  48. IBM ILOG CPLEX
    CPLEX is a commercial optimisation solver for linear, quadratic and mixed-integer programming, originally developed by Robert Bixby from 1988 and now owned by IBM.
  49. OR-Tools
    Google OR-Tools is a free, open-source software suite for combinatorial optimisation.
  50. CVXPY
    CVXPY is an open-source Python library for convex optimisation using disciplined convex programming.

Key terms

Computer algebra system
Software that manipulates mathematical expressions exactly, such as expanding, factorising, differentiating and integrating
Expression
The universal data structure head[arg₁, arg₂, …]; for example x + y is Plus[x, y]
Computational knowledge engine
A system that interprets queries and computes answers from algorithms and curated data
Cell
A unit of a notebook holding input, output, text or graphics; input cells are evaluated with Shift+Enter
Worksheet
A Maple document containing commands, results and text, in document or worksheet mode
Macsyma
An early computer algebra system developed at MIT in the 1960s–70s, ancestor of Maxima
Parent and element
Sage's way of tracking which structure a number belongs to, such as ZZ (integers), QQ (rationals) or GF(7)
Kernel (Jupyter)
The process running code for a notebook in a particular language, such as Python or R
Vectorisation
Writing operations on whole arrays instead of loops, such as y = x.^2
MATLAB compatibility
Octave's aim of running MATLAB code with little or no change
Multiple dispatch
Choosing which method of a function to run based on the types of all its arguments
Arbitrary-precision integer
Python's int type, which grows as needed, so 2**100 is exact
ndarray
NumPy's n-dimensional array of elements of one data type, stored contiguously for fast computation
scipy.integrate
Routines such as quad for definite integrals and solve_ivp for ODE initial value problems
