Lessons in this school

  1. Discrete Mathematics
    Discrete mathematics studies countable, separate objects: integers, graphs, logical statements, finite sets and algorithms.
  2. Combinatorics
    Combinatorics is the mathematics of counting, arranging and selecting.
  3. Counting Principles
    The basic counting principles (add for "or", multiply for "and", subtract the complement, divide out overcounting) solve a huge range of problems.
  4. Permutations
    A permutation is an ordered arrangement.
  5. Combinations
    A combination is a selection where order doesn't matter: a committee, a lottery ticket, a hand of cards.
  6. Binomial Theorem
    The binomial theorem expands (a + b)ⁿ using binomial coefficients, connecting algebra to counting.
  7. Pigeonhole Principle
    If more than n pigeons go into n holes, some hole has at least two.
  8. Inclusion–Exclusion Principle
    Inclusion–exclusion counts the union of overlapping sets by adding sizes, subtracting pairwise overlaps, adding back triple overlaps and so on.
  9. Generating Functions
    A generating function packs a whole sequence into the coefficients of a power series.
  10. Enumerative Combinatorics
    Enumerative combinatorics counts families of structures: partitions of numbers and sets, permutations with given properties, trees and lattice paths.
  11. Extremal Combinatorics
    Extremal combinatorics asks how large or small a structure can be while avoiding (or forcing) some property: the most edges in a graph with no triangle, the largest family of sets where none contains another.
  12. Ramsey Theory
    Ramsey theory shows that complete disorder is impossible: any large enough structure contains an orderly substructure.
  13. Design Theory
    Design theory constructs arrangements with perfect balance: Latin squares, Steiner systems and block designs in which every pair of items appears together equally often.
  14. Block Designs
    A balanced incomplete block design (BIBD) arranges v items into b blocks of size k so that every pair of items appears together in exactly λ blocks.
  15. Invariants
    An invariant is a quantity that doesn't change when allowed moves are made.
  16. Coding Theory
    Coding theory designs ways to send information reliably over noisy channels by adding structured redundancy.
  17. Boolean Functions
    A Boolean function takes true/false inputs and returns true or false.
  18. Algorithms and Complexity
    An algorithm is a precise step-by-step procedure; complexity measures how its running time or memory grows with input size.
  19. Computational Complexity Theory
    Complexity theory classifies problems by the resources needed to solve them.
  20. Automata Theory
    Automata are abstract machines that read input and change state.
  21. Formal Languages
    A formal language is a set of strings over an alphabet, defined by rules.
  22. Cellular Automata
    A cellular automaton is a grid of cells, each updating its state by a simple rule depending on its neighbours.
  23. Game Theory
    Game theory studies strategic decisions where each player's outcome depends on others' choices.

Key terms

Discrete structure
A set of separate objects with relations between them, such as a graph or a set of strings
Bijective proof
Proving two sets have the same size by pairing their elements exactly
Product rule
If a task has stages with m and n options, there are mn ways overall
Factorial
n! = n × (n − 1) × … × 1, with 0! = 1
Binomial coefficient
C(n, r) = n!/(r!(n − r)!), the number of r-element subsets of an n-element set
Binomial theorem
(a + b)ⁿ = Σk=0n C(n, k) an−kbk
Pigeonhole principle
If N objects are placed in k boxes and N > k, some box contains at least two
Inclusion–exclusion
|A ∪ B ∪ C| = |A| + |B| + |C| − |A ∩ B| − |A ∩ C| − |B ∩ C| + |A ∩ B ∩ C|
Ordinary generating function
A(x) = Σ aₙxⁿ for a sequence a₀, a₁, a₂, …
Integer partition
A way to write n as a sum of positive integers, order ignored; p(n) counts them
Mantel's theorem
A triangle-free graph on n vertices has at most ⌊n2/4⌋ edges
Ramsey number
R(s, t), the smallest n such that every red/blue colouring of the edges of Kn has a red Ks or a blue Kt
Latin square
An n × n grid with n symbols, each appearing exactly once in every row and column
BIBD (v, b, r, k, λ)
v points, b blocks of size k, each point in r blocks, each pair in λ blocks
