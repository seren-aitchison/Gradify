Lessons in this school

  1. Information Theory
    Information theory, founded by Claude Shannon in 1948, measures information and sets the limits of compression and communication.
  2. Entropy
    Entropy measures the average uncertainty, or information content, of a random variable.
  3. Conditional Entropy
    Conditional entropy measures how much uncertainty remains about one variable once another is known.
  4. Mutual Information
    Mutual information measures how much knowing one variable tells you about another.
  5. Kullback–Leibler Divergence
    The Kullback–Leibler divergence measures how one probability distribution differs from another: the extra bits needed if you code data from P using a code designed for Q.
  6. Cross-Entropy
    Cross-entropy measures the average number of bits needed to encode data from distribution P using a code optimised for Q.
  7. Fisher Information
    Fisher information measures how much a sample tells you about an unknown parameter: the sharper the likelihood curve, the more information.
  8. Minimum Description Length
    The minimum description length principle chooses the model that gives the shortest total description of the model plus the data encoded with it.
  9. Shannon's Theorems
    Shannon's theorems are the fundamental limits of information theory.
  10. Compression Theory
    Compression theory studies how to represent data in fewer bits.
  11. Source Coding
    Source coding assigns codewords to symbols so that messages are as short as possible on average while remaining decodable.
  12. Channel Coding
    Channel coding adds structured redundancy to data so that errors introduced by a noisy channel can be detected and corrected.
  13. Error-Correcting Codes
    Error-correcting codes protect data in QR codes, CDs, phones, spacecraft and computer memory.
  14. Signal Processing Mathematics
    Signal processing analyses, transforms and extracts information from signals such as sound, images, radar returns and sensor readings.
  15. Convolution
    Convolution combines two functions by sliding one across the other and integrating their product.
  16. Correlation Functions
    Correlation functions measure how similar a signal is to a shifted version of itself (autocorrelation) or of another signal (cross-correlation).
  17. Sampling Theory (Signals)
    Sampling turns a continuous signal into a sequence of numbers taken at regular intervals.
  18. Nyquist–Shannon Sampling Theorem
    The Nyquist–Shannon sampling theorem says a signal containing no frequencies above B can be perfectly reconstructed from samples taken faster than 2B per second.
  19. Digital Signal Processing
    Digital signal processing manipulates sampled signals with computers: filtering audio, compressing images, equalising communications channels.
  20. Filtering Theory
    Filtering theory designs systems that separate wanted signals from noise or interference.
  21. Spectral Estimation
    Spectral estimation determines how a signal's power is distributed across frequencies from finite, noisy data.
  22. Wavelet Analysis
    Wavelet analysis represents signals with short, localised waves at different scales, showing both when and at what frequency features occur.
  23. Image Processing Mathematics
    Image processing treats images as functions or matrices of pixel values and applies mathematics to enhance, analyse and compress them.
  24. Statistical Signal Processing
    Statistical signal processing treats signals and noise as random processes and uses probability to estimate parameters and detect signals.

Key terms

Bit
The unit of information: the information in one fair yes/no choice
Shannon entropy
H(X) = −Σ p(x) log₂ p(x), measured in bits
Conditional entropy
H(Y ∣ X) = Σₓ p(x) H(Y ∣ X = x) = −Σ p(x, y) log₂ p(y ∣ x)
Mutual information
I(X; Y) = H(X) − H(X ∣ Y) = H(X) + H(Y) − H(X, Y)
KL divergence
DKL(P ‖ Q) = Σ p(x) log(p(x)/q(x))
Cross-entropy
H(P, Q) = −Σ p(x) log q(x) = H(P) + DKL(P ‖ Q)
Fisher information
I(θ) = E[(∂ log f(X; θ)/∂θ)2] = −E[∂2 log f/∂θ2]
Two-part code
Description length L(M) + L(D ∣ M): bits to describe the model plus bits to describe the data given the model
Channel capacity
C = max over input distributions of I(X; Y), the highest rate of reliable communication
Lossless compression
Encoding that allows exact reconstruction of the original data, such as ZIP or PNG
Prefix code
A code in which no codeword is the start of another, so messages decode instantly
Code rate
R = k/n, for a code mapping k information bits into n coded bits
Linear code
A code whose codewords form a vector subspace; codewords are c = mG for a generator matrix G
Linear time-invariant system
A system whose response to a sum of inputs is the sum of responses, and whose behaviour doesn't change over time
