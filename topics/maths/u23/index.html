Key terms and formulas at a glance

Bit
The unit of information: the information in one fair yes/no choice
Shannon entropy
H(X) = −Σ p(x) log₂ p(x), measured in bits
Conditional entropy
H(Y ∣ X) = Σₓ p(x) H(Y ∣ X = x) = −Σ p(x, y) log₂ p(y ∣ x)
Mutual information
I(X; Y) = H(X) − H(X ∣ Y) = H(X) + H(Y) − H(X, Y)
KL divergence
DKL(P ‖ Q) = Σ p(x) log(p(x)/q(x))
Cross-entropy
H(P, Q) = −Σ p(x) log q(x) = H(P) + DKL(P ‖ Q)
Fisher information
I(θ) = E[(∂ log f(X; θ)/∂θ)2] = −E[∂2 log f/∂θ2]
Two-part code
Description length L(M) + L(D ∣ M): bits to describe the model plus bits to describe the data given the model
Channel capacity
C = max over input distributions of I(X; Y), the highest rate of reliable communication
Lossless compression
Encoding that allows exact reconstruction of the original data, such as ZIP or PNG
Prefix code
A code in which no codeword is the start of another, so messages decode instantly
Code rate
R = k/n, for a code mapping k information bits into n coded bits

How many bits of information does a fair coin toss give?

1 bit. From “Information Theory” →

In plain English: Information theory, founded by Claude Shannon in 1948, measures information and sets the limits of compression and communication. Key idea: Information theory measures information in bits as reduction of uncertainty; Shannon's source and channel coding theorems set limits of compression and communication; its ideas reach far beyond engineering.

Is KL divergence symmetric?

No. From “Kullback–Leibler Divergence” →

In plain English: The Kullback–Leibler divergence measures how one probability distribution differs from another: the extra bits needed if you code data from P using a code designed for Q. Key idea: KL divergence measures how P differs from Q; it's non-negative and asymmetric; it's the extra coding cost of a wrong model; maximum likelihood, variational inference and AIC use it.

What transform does JPEG use?

The discrete cosine transform (DCT). From “Compression Theory” →

In plain English: Compression theory studies how to represent data in fewer bits. Key idea: Lossless compression is bounded by entropy; lossy compression follows rate–distortion trade-offs; transform coding plus quantisation and entropy coding underlies JPEG, MP3 and video codecs.

What is the length of the convolution of sequences of lengths 5 and 3?

7. From “Convolution” →

In plain English: Convolution combines two functions by sliding one across the other and integrating their product. Key idea: Convolution slides and sums products; it describes LTI outputs, blurs and sums of random variables; the convolution theorem makes it multiplication in frequency; FFTs compute it fast.

What does a notch filter remove?

A narrow band of frequencies, such as mains hum. From “Filtering Theory” →

In plain English: Filtering theory designs systems that separate wanted signals from noise or interference. Key idea: Filters pass or block frequency bands with design trade-offs; Butterworth, Chebyshev and elliptic designs differ in flatness and sharpness; the Wiener filter minimises MSE using spectra.

Quick quiz: test yourself on Information Theory and Signal Processing

9 questions from the course, from foundation recall to stretch. Pick an answer, then say whether you knew it or guessed.

  1. Which outcome carries the most information? (Foundation recall)
    Show the answer

    One with probability 0.01. Self-information −log p is largest for the least likely outcome.

  2. Which distribution on four outcomes has the highest entropy? (Foundation recall)
    Show the answer

    (¼, ¼, ¼, ¼). The uniform distribution maximises entropy at log₂ 4 = 2 bits.

  3. X and Y are independent with H(Y) = 2 bits. What is H(Y ∣ X)? (Foundation recall)
    Show the answer

    2 bits. Knowing an independent variable tells you nothing about Y.

  4. Why does information theory use logarithms of probabilities? (Exam style)
    Show the answer

    So that information from independent events adds, since their probabilities multiply. −log(pq) = −log p − log q turns products into sums.

  5. Why is the entropy of English text far below log₂ 27 bits per letter? (Exam style)
    Show the answer

    Letters aren't equally likely and depend strongly on context, so each is quite predictable. Redundancy from letter frequencies and context lowers the average surprise.

  6. What does the data processing inequality imply for image enhancement? (Exam style)
    Show the answer

    Processing an image can't add information about the original scene, only reveal or lose it. For a chain scene → image → processed image, I(scene; processed) ≤ I(scene; image): processing can reveal or lose information but never add it.

  7. Why can observing a particular value of X increase uncertainty about Y, though H(Y ∣ X) ≤ H(Y)? (Stretch)
    Show the answer

    The inequality holds on average over x; some rare values can leave Y more uncertain than before. Averaging over all x gives the decrease; individual x can go either way.

  8. Why does minimising D(q ‖ p) in variational inference tend to pick one mode of a multimodal posterior? (Stretch)
    Show the answer

    It heavily penalises q placing mass where p is small, so q concentrates on a single peak. Reverse KL is "mode-seeking", while D(p ‖ q) is "mass-covering".

  9. Why was Shannon's channel coding theorem surprising in 1948? (Stretch)
    Show the answer

    It showed noise needn't force errors: with clever coding, error rates can be made tiny at positive rates. Engineers had assumed reducing errors meant reducing rate towards zero.

Key takeaways

  • Information theory measures information in bits as reduction of uncertainty; Shannon's source and channel coding theorems set limits of compression and communication; its ideas reach far beyond engineering.
  • Entropy H = −Σ p log₂ p measures average uncertainty; it's maximised by the uniform distribution at log₂ n; it sets the average bits needed to describe outcomes.
  • Conditional entropy is remaining uncertainty given another variable; H(X, Y) = H(X) + H(Y ∣ X); conditioning reduces entropy on average; functions of X have zero conditional entropy.
  • Mutual information measures shared information; it's symmetric, non-negative and zero only under independence; it detects nonlinear dependence; processing can't increase it.
  • KL divergence measures how P differs from Q; it's non-negative and asymmetric; it's the extra coding cost of a wrong model; maximum likelihood, variational inference and AIC use it.
  • Cross-entropy H(P, Q) = H(P) + DKL(P ‖ Q); minimising it fits Q to P; it's the standard classification loss; perplexity reports it for language models.

Common mistakes in Information Theory and Signal Processing

  • Confusing information in Shannon's sense with meaning or importance.
  • Forgetting that 0 log 0 is taken as 0, so impossible outcomes add nothing.
  • Thinking that observing any particular value of X must reduce uncertainty about Y.
  • Concluding independence from zero correlation.
  • Treating KL divergence as a symmetric distance.
  • Using accuracy alone to evaluate probabilistic classifiers, ignoring confidence.

Lessons in this school

  1. Information Theory
    Information theory, founded by Claude Shannon in 1948, measures information and sets the limits of compression and communication.
  2. Entropy
    Entropy measures the average uncertainty, or information content, of a random variable.
  3. Conditional Entropy
    Conditional entropy measures how much uncertainty remains about one variable once another is known.
  4. Mutual Information
    Mutual information measures how much knowing one variable tells you about another.
  5. Kullback–Leibler Divergence
    The Kullback–Leibler divergence measures how one probability distribution differs from another: the extra bits needed if you code data from P using a code designed for Q.
  6. Cross-Entropy
    Cross-entropy measures the average number of bits needed to encode data from distribution P using a code optimised for Q.
  7. Fisher Information
    Fisher information measures how much a sample tells you about an unknown parameter: the sharper the likelihood curve, the more information.
  8. Minimum Description Length
    The minimum description length principle chooses the model that gives the shortest total description of the model plus the data encoded with it.
  9. Shannon's Theorems
    Shannon's theorems are the fundamental limits of information theory.
  10. Compression Theory
    Compression theory studies how to represent data in fewer bits.
  11. Source Coding
    Source coding assigns codewords to symbols so that messages are as short as possible on average while remaining decodable.
  12. Channel Coding
    Channel coding adds structured redundancy to data so that errors introduced by a noisy channel can be detected and corrected.
  13. Error-Correcting Codes
    Error-correcting codes protect data in QR codes, CDs, phones, spacecraft and computer memory.
  14. Signal Processing Mathematics
    Signal processing analyses, transforms and extracts information from signals such as sound, images, radar returns and sensor readings.
  15. Convolution
    Convolution combines two functions by sliding one across the other and integrating their product.
  16. Correlation Functions
    Correlation functions measure how similar a signal is to a shifted version of itself (autocorrelation) or of another signal (cross-correlation).
  17. Sampling Theory (Signals)
    Sampling turns a continuous signal into a sequence of numbers taken at regular intervals.
  18. Nyquist–Shannon Sampling Theorem
    The Nyquist–Shannon sampling theorem says a signal containing no frequencies above B can be perfectly reconstructed from samples taken faster than 2B per second.
  19. Digital Signal Processing
    Digital signal processing manipulates sampled signals with computers: filtering audio, compressing images, equalising communications channels.
  20. Filtering Theory
    Filtering theory designs systems that separate wanted signals from noise or interference.
  21. Spectral Estimation
    Spectral estimation determines how a signal's power is distributed across frequencies from finite, noisy data.
  22. Wavelet Analysis
    Wavelet analysis represents signals with short, localised waves at different scales, showing both when and at what frequency features occur.
  23. Image Processing Mathematics
    Image processing treats images as functions or matrices of pixel values and applies mathematics to enhance, analyse and compress them.
  24. Statistical Signal Processing
    Statistical signal processing treats signals and noise as random processes and uses probability to estimate parameters and detect signals.

Information Theory and Signal Processing: questions students ask

Who founded information theory?

Claude Shannon (1948).

When is entropy zero?

When one outcome is certain.

What is conditional entropy?

H(Y ∣ X), the uncertainty remaining about Y once X is known, averaged over X.

When is I(X; Y) = 0?

When X and Y are independent.
