Key terms and formulas at a glance

Set
A well-defined collection of distinct objects; order and repetition don't matter
Russell's paradox
The "set" R = x : x ∉ x leads to contradiction, since R ∈ R iff R ∉ R
Set difference
A \ B = x : x ∈ A and x ∉ B
Union
A ∪ B = x : x ∈ A or x ∈ B
Complement
Aᶜ = U \ A = x ∈ U : x ∉ A
Cartesian product
A × B = (a, b) : a ∈ A, b ∈ B
Power set
P(A) = S : S ⊆ A
Countable set
A set that is finite or in bijection with ℕ
Uncountable set
An infinite set with no bijection to ℕ
Relation
A subset R ⊆ A × B; we write a R b when (a, b) ∈ R
Function
A relation f ⊆ A × B where each a ∈ A appears in exactly one pair (a, b)
Injective function
f(a) = f(a′) implies a = a′: distinct inputs give distinct outputs

Five sample flashcards

How many elements does {∅} have?

One. From “Elementary Set Theory” →

In plain English: A set is a collection of distinct objects, called its elements. Key idea: Sets are collections of distinct elements; ∈ is membership, ⊆ is inclusion; equality is proved by inclusion both ways; ∅ is a subset of every set.

Is every function a relation?

Yes. From “Relations and Functions” →

In plain English: A function is a relation in which every input is related to exactly one output. Key idea: Functions are relations with exactly one output per input; domain, codomain and range are distinct; rules on equivalence classes must be well defined.

What is the contrapositive of p → q?

¬q → ¬p. From “Propositional Logic” →

In plain English: Propositional logic studies statements that are true or false, combined with connectives such as "and", "or", "not" and "implies". Key idea: Propositional logic combines true/false statements with connectives; truth tables decide tautology and equivalence; formulas have CNF and DNF; SAT is NP-complete.

What do you assume first in a proof by contradiction?

That the statement is false. From “Proof by Contradiction” →

In plain English: Proof by contradiction assumes the statement is false and derives something impossible. Key idea: Contradiction assumes ¬P and derives an impossibility; it proves √2 irrational and the infinitude of primes; state negations carefully.

Which is stronger, a measurable or an inaccessible cardinal?

Measurable. From “Large Cardinal Theory” →

In plain English: Large cardinals are infinite sizes so big that ZFC can't prove they exist. Key idea: Large cardinals are axioms beyond ZFC; inaccessibles give models of ZFC; the ladder ranks consistency strength; they settle questions like projective determinacy.

Quick quiz: test yourself on Logic, Sets and Foundations

9 questions from the course, from foundation recall to stretch. Pick an answer, then say whether you knew it or guessed.

  1. Which statement about A = {1, {2}, 3} is true? (Foundation recall)
    Show the answer

    {2} ∈ A. A's elements are 1, the set {2} and 3, so {2} is an element but the number 2 isn't.

  2. What does Russell's paradox show? (Foundation recall)
    Show the answer

    Not every property defines a set. R = {x : x ∉ x} leads to contradiction, so unrestricted set formation must be abandoned.

  3. Which expression equals A ∩ (B ∪ C)? (Foundation recall)
    Show the answer

    (A ∩ B) ∪ (A ∩ C). Intersection distributes over union, just as multiplication distributes over addition.

  4. How is equality of two sets A and B usually proved? (Exam style)
    Show the answer

    Show A ⊆ B and B ⊆ A. Two sets are equal exactly when each is contained in the other, so both inclusions are proved.

  5. Which description fits the symmetric difference A Δ B? (Exam style)
    Show the answer

    Elements in exactly one of A and B. A Δ B = (A \ B) ∪ (B \ A), so it keeps elements belonging to one set only.

  6. If A ∪ B = B, what must be true? (Exam style)
    Show the answer

    A ⊆ B. Union with B leaves B unchanged exactly when everything in A is already in B.

  7. Why is the Kuratowski definition (a, b) = {{a}, {a, b}} useful? (Stretch)
    Show the answer

    It encodes order using only sets, so (a, b) = (c, d) exactly when a = c and b = d. Sets ignore order, yet this construction recovers which element comes first.

  8. In Cantor's proof, why can the set D = {x : x ∉ f(x)} never equal f(d)? (Stretch)
    Show the answer

    If it did, d ∈ D would hold exactly when d ∉ D. Assuming D = f(d) makes d's membership in D contradict itself.

  9. Why does the diagonal argument fail to show ℚ is uncountable? (Stretch)
    Show the answer

    The number it builds needn't be rational, so it may not belong to ℚ at all. The constructed decimal can be non-repeating, so it escapes ℚ rather than contradicting the list.

Key takeaways

  • Sets are collections of distinct elements; ∈ is membership, ⊆ is inclusion; equality is proved by inclusion both ways; ∅ is a subset of every set.
  • Cantor founded set theory; Russell's paradox showed unrestricted comprehension is inconsistent; axiomatic set theory such as ZFC is the standard foundation.
  • Union, intersection, difference, complement and symmetric difference obey commutative, associative, distributive and absorption laws; inclusion–exclusion counts unions.
  • Union is "or", intersection is "and"; A ⊆ B iff A ∪ B = B; indexed unions and intersections can produce sets unlike any member of the family.
  • Complements depend on the universal set; De Morgan's laws swap ∪ and ∩ under complement; A \ B = A ∩ Bᶜ; complementary counting simplifies problems.
  • A × B contains ordered pairs; its size is |A||B|; products distribute over ∪ and ∩; relations and functions live inside products.

Common mistakes in Logic, Sets and Foundations

  • Confusing ∈ with ⊆, for example writing 1 ⊆ {1, 2}.
  • Assuming any property defines a set (it may only carve a subset from an existing set).
  • Treating A \ B and B \ A as equal.
  • Assuming an intersection of nested non-empty sets must be non-empty.
  • Writing (A ∪ B)ᶜ = Aᶜ ∪ Bᶜ, forgetting to switch union to intersection.
  • Treating ordered pairs as sets, so that (1, 2) = (2, 1).

Lessons in this school

  1. Elementary Set Theory
    A set is a collection of distinct objects, called its elements.
  2. Set Theory
    Set theory studies sets in general: how they're built, compared and measured.
  3. Set Operations
    Set operations combine sets into new ones: union, intersection, difference, complement and symmetric difference.
  4. Union and Intersection
    Union collects everything in either set; intersection keeps only what's common.
  5. Complements
    The complement of a set is everything not in it, relative to a chosen universal set.
  6. Cartesian Products
    The Cartesian product A × B is the set of all ordered pairs with first entry from A and second from B.
  7. Power Sets
    The power set of A is the set of all subsets of A.
  8. Countability
    A set is countable if its elements can be listed as a first, second, third and so on.
  9. Countable and Uncountable Sets
    Some infinite sets are too big to list.
  10. Relations
    A relation from A to B is any set of ordered pairs, recording which elements are related.
  11. Relations and Functions
    A function is a relation in which every input is related to exactly one output.
  12. Functions and Mappings
    Functions, also called mappings, can be one-to-one, onto or both.
  13. Equivalence Relations
    An equivalence relation is reflexive, symmetric and transitive: it says when two things count as "the same" for some purpose.
  14. Equivalence Classes
    An equivalence relation splits a set into disjoint equivalence classes, each containing elements that are equivalent to each other.
  15. Partial Orders
    A partial order is a reflexive, antisymmetric and transitive relation, capturing "comes before" when not every pair needs to be comparable.
  16. Partially Ordered Sets
    A partially ordered set, or poset, is a set together with a partial order.
  17. Totally Ordered Sets
    A total order is a partial order where every two elements are comparable.
  18. Lattices
    A lattice is a poset in which every pair of elements has a least upper bound (join) and a greatest lower bound (meet).
  19. Boolean Lattices
    A Boolean lattice is a distributive lattice with a least and greatest element in which every element has a complement.
  20. Mathematical Logic
    Mathematical logic studies reasoning itself with mathematical precision.
  21. Propositional Logic
    Propositional logic studies statements that are true or false, combined with connectives such as "and", "or", "not" and "implies".
  22. Predicate Logic
    Predicate logic adds variables, predicates and the quantifiers "for all" (∀) and "there exists" (∃) to propositional logic.
  23. First-Order Logic
    First-order logic is predicate logic in which quantifiers range over individual objects, with a precise syntax, proof system and semantics.
  24. Higher-Order Logic
    Higher-order logic lets quantifiers range over properties, sets and functions, not just individual objects.
  25. Modal Logic
    Modal logic adds operators for "necessarily" (□) and "possibly" (◇).
  26. Intuitionistic Logic
    Intuitionistic logic treats a statement as true only when it has a proof or construction.
  27. Fuzzy Logic
    Fuzzy logic allows truth values anywhere between 0 and 1, modelling vague ideas like "tall" or "warm".
  28. Temporal Logic
    Temporal logic adds operators about time: "always", "eventually", "next" and "until".
  29. Proof Techniques
    A proof is a convincing logical argument that a statement follows from accepted facts.
  30. Direct Proof
    A direct proof starts from the hypotheses and moves step by step to the conclusion using definitions and known results.
  31. Proof by Contraposition
    To prove "if P then Q", you can instead prove the equivalent "if not Q then not P".
  32. Proof by Contradiction
    Proof by contradiction assumes the statement is false and derives something impossible.
  33. Mathematical Induction
    Mathematical induction proves a statement for every natural number by proving a base case and showing each case implies the next.
  34. Formal Proofs
    A formal proof is a sequence of formulas, each an axiom or following from earlier ones by an explicit rule.
  35. Axiomatic Systems
    An axiomatic system starts from a few basic statements, the axioms, and derives everything else by logic.
  36. Axiomatic Set Theory
    Axiomatic set theory replaces naive set formation with explicit axioms saying which sets exist.
  37. Zermelo–Fraenkel Set Theory
    Zermelo–Fraenkel set theory with choice, ZFC, is the standard foundation of mathematics.
  38. Axiom of Choice
    The axiom of choice says that from any collection of non-empty sets you can choose one element from each, even when there's no rule for choosing.
  39. Set-Theoretic Mathematics
    In set-theoretic foundations every mathematical object is a set: numbers, pairs, functions and spaces.
  40. Ordinal Arithmetic
    Ordinals extend counting beyond the finite: after 0, 1, 2, … comes ω, then ω + 1, ω + 2, and on.
  41. Cardinal Arithmetic
    Cardinals measure the size of sets.
  42. Large Cardinal Theory
    Large cardinals are infinite sizes so big that ZFC can't prove they exist.
  43. Proof Theory
    Proof theory treats proofs as mathematical objects.
  44. Model Theory
    Model theory studies the relationship between formal theories and the structures that satisfy them.
  45. Gödel's Incompleteness Theorems
    Gödel's incompleteness theorems (1931) show that any consistent, effectively axiomatised theory strong enough for basic arithmetic leaves some true statements unprovable, and can't prove its own consistency.
  46. Computability Theory
    Computability theory asks which problems can be solved by an algorithm at all.
  47. Recursive Functions
    The recursive functions are built from simple starting functions by composition, primitive recursion and minimisation.
  48. Lambda Calculus
    The lambda calculus, created by Alonzo Church in the 1930s, describes computation using only function definition and application.
  49. Type Theory
    Type theory classifies every term by a type, preventing nonsense like adding a number to a function.
  50. Constructive Mathematics
    Constructive mathematics requires that existence proofs show how to find the object.
  51. Category-Theoretic Foundations
    Category-theoretic foundations describe mathematics through structures and maps rather than membership.
  52. Philosophy of Mathematics
    The philosophy of mathematics asks what mathematical objects are and how we know mathematical truths.

Logic, Sets and Foundations: questions students ask

Is f(x) = eˣ from ℝ to ℝ surjective?

No: it never takes values ≤ 0.

Is "has the same birthday as" an equivalence relation?

Yes: it's reflexive, symmetric and transitive.

What does soundness say?

Everything provable is true.

When is p → q false?

Only when p is true and q is false.
