Five sample flashcards

Answer each from memory, then open it to check. Still foggy? Each card has the plain-English version.

What does the Python interpreter do?

It translates and runs a program's instructions one at a time, without producing a separate executable file. From “Programs and the Python interpreter” →

In plain English: A program is a sequence of instructions a computer carries out. Key idea: A Python program runs in sequence from the first line to the last, unless selection, loops or function calls change the order.

What type does input() always return?

A string. From “Input and output” →

In plain English: Programs communicate through input and output. Key idea: input() always returns a string; cast it before doing arithmetic, and expect that users will sometimes type something invalid.

In an if-elif-else chain, how many branches run?

At most one: the first whose condition is True, or else if none are. From “Selection with if, elif and else” →

In plain English: Selection lets a program choose which code to run depending on a condition. Key idea: In an if-elif-else chain, only the first True branch runs, so order conditions from the most specific (or highest threshold) to the least.

If an outer loop runs 5 times and its inner loop 4 times, how often does the inner block run?

20 times (5 × 4). From “Nested selection and iteration” →

In plain English: Control structures can be placed inside one another: an if inside a loop, a loop inside a loop, or an if inside an if. Key idea: In nested loops the inner loop completes all its passes for every single pass of the outer loop.

In def add(a, b): called as add(2, 5), which are the parameters and which the arguments?

a and b are parameters; 2 and 5 are arguments. From “Parameters, arguments and return values” →

In plain English: Parameters let a function work on different data each time it is called, and return values pass results back. Key idea: Parameters are the names in the definition; arguments are the values in the call. Return sends a result back; print only shows it.

Quick quiz: test yourself on Python Programming Fundamentals

9 questions from the course, from foundation recall to stretch. Pick an answer, then say whether you knew it or guessed.

  1. What is a script in Python? (Foundation recall)
    Show the answer

    A saved file of instructions run from top to bottom. A script is a saved .py file. Lines typed at the prompt are run in the interactive shell.

  2. Which is a valid Python variable name? (Foundation recall)
    Show the answer

    total_score. Names can't start with a digit, can't be keywords such as for, and can't contain hyphens.

  3. What data type is the value "3.5"? (Foundation recall)
    Show the answer

    String. The quotation marks make it text. 3.5 without quotes would be a float.

  4. A script contains print("A"), then print("B"), then print("C"). What is displayed? (Exam style)
    Show the answer

    A, B and C on three separate lines. The lines run in sequence, and each print ends with a new line by default.

  5. Trace x = 2, then y = x + 5, then x = y * 2, then y = x - y. What is y at the end? (Exam style)
    Show the answer

    7. y becomes 7, then x becomes 7 × 2 = 14, then y becomes 14 − 7 = 7.

  6. What is the result of "7" + "3" in Python? (Exam style)
    Show the answer

    "73". Adding two strings concatenates them. Cast first with int() to add numerically.

  7. Which is a genuine disadvantage of Python being interpreted rather than compiled to machine code? (Stretch)
    Show the answer

    Programs usually run more slowly than equivalent compiled code. Interpretation adds overhead at run time, so pure Python is slower than compiled C. Interpreted code is actually more portable, and errors are reported as soon as a line runs.

  8. Why is VAT_RATE = 0.2 better than writing 0.2 throughout a program? (Stretch)
    Show the answer

    The rate has a clear name and can be changed in one place if it changes. A named constant explains the number and avoids missing one copy when the rate changes. Python doesn't actually enforce constants.

  9. Why does 0.1 + 0.2 == 0.3 evaluate to False in Python? (Stretch)
    Show the answer

    0.1 and 0.2 can't be stored exactly in binary, so their sum is slightly more than 0.3. Like 1/3 in decimal, 0.1 has no exact binary representation; the tiny errors make the sum 0.30000000000000004.

Key takeaways

  • A Python program runs in sequence from the first line to the last, unless selection, loops or function calls change the order.
  • Assignment evaluates the right-hand side first, then binds the name on the left to the result; changing one variable later doesn't change another that was copied from it, for numbers and strings.
  • Choose the type that fits the data and the operations you need, and cast deliberately: text from the keyboard or a file is always a string until you convert it.
  • input() always returns a string; cast it before doing arithmetic, and expect that users will sometimes type something invalid.
  • // gives how many whole times one number goes into another and % gives what is left over; together they convert units and test divisibility (n % 2 == 0 means n is even).
  • A comparison produces True or False; use == to test equality and = only to assign.

Common mistakes in Python Programming Fundamentals

  • Mixing tabs and spaces, or indenting a line that shouldn't be indented. Python reports an IndentationError; use four spaces per level, as PEP 8 recommends.
  • Reading x = x + 1 as a false equation. In programming it is an instruction: "make x one bigger".
  • Storing a telephone number as an integer. It loses a leading zero and you never do arithmetic on it, so it should be a string.
  • Writing input("Age? ") + 1. The input is a string, so Python raises a TypeError; cast with int() first.
  • Using / when a whole number is needed. 7 / 7 is the float 1.0, which can't be used as a list index; use //.
  • Writing if score = 50:. A single = is assignment, which Python rejects in a condition with a SyntaxError; use ==.

    Scope is the part of a program in which a name can be used.

Python Programming Fundamentals: questions students ask

What does count = count + 1 do?

It adds 1 to the current value of count and stores the result back in count.

What does int(7.8) return?

7: int() truncates towards zero rather than rounding.

How do you print a float to two decimal places with an f-string?

Use a format specifier: f"value:.2f".

What is 17 % 5 in Python?

2, the remainder when 17 is divided by 5.
