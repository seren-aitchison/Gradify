Five sample flashcards

Answer each from memory, then open it to check. Still foggy? Each card has the plain-English version.

How many different values can 8 bits represent?

256 (28), from 0 to 255 for unsigned whole numbers. From “Binary and denary” →

In plain English: Computers store all data as binary: patterns of 0s and 1s. Key idea: In binary each place is worth double the one to its right; n bits give 2n values, so 8 bits store whole numbers from 0 to 255.

What is the effect of shifting a binary number two places left?

It multiplies the value by 4 (22), if no 1 bits are lost. From “Binary shifts” →

In plain English: A binary shift moves every bit of a number left or right. Key idea: Each left shift doubles the value and each right shift halves it (rounding down); bits shifted out of either end are lost, which causes overflow or loss of precision.

How many bytes are in a kibibyte?

1,024. From “Units of data” →

In plain English: Data sizes are measured in bits and bytes and in larger units such as kilobytes, megabytes and gigabytes. Key idea: Multiply by 8 to turn bytes into bits; divide by 1,000 (or 1,024 for binary prefixes) to move up a unit. Network speeds are quoted in bits per second, file sizes in bytes.

Why don't vector images pixelate when enlarged?

They are redrawn from their mathematical descriptions at the new size. From “Vector graphics” →

In plain English: Vector graphics store an image as a list of shapes and their properties rather than as pixels. Key idea: Vector images are drawn from mathematical descriptions, so they scale to any size without losing quality and are usually small; bitmaps are better for complex, photographic images.

For what kind of data does RLE work best?

Data with long runs of repeated values, such as simple images with large blocks of one colour. From “Run-length encoding” →

In plain English: Run-length encoding (RLE) is a simple lossless compression method that replaces runs of repeated values with a count and the value. Key idea: RLE works well when data contains long runs of repeated values and badly when values change often, where it can make the data larger.

Quick quiz: test yourself on Data Representation

9 questions from the course, from foundation recall to stretch. Pick an answer, then say whether you knew it or guessed.

  1. What is the denary value of binary 00001101? (Foundation recall)
    Show the answer

    13. The 1s are in the 8, 4 and 1 columns, so the value is 8 + 4 + 1 = 13.

  2. Which hex value equals binary 1111? (Foundation recall)
    Show the answer

    F. 1111 is 15 in denary, written F in hexadecimal.

  3. What is 0101 + 0011 in binary? (Foundation recall)
    Show the answer

    1000. 5 + 3 = 8, which is 1000; the carries ripple through every column.

  4. What is denary 150 in 8-bit binary? (Exam style)
    Show the answer

    10010110. 150 = 128 + 16 + 4 + 2, giving 1 0 0 1 0 1 1 0.

  5. What is hex 7D in denary? (Exam style)
    Show the answer

    125. 7 is in the sixteens column and D is 13 in the units column: 7 × 16 + 13 = 125.

  6. What is denary 200 in hexadecimal? (Exam style)
    Show the answer

    C8. 200 ÷ 16 = 12 remainder 8, and 12 is C, so 200 = C8.

  7. A sensor must report values from 0 to 1,000. What is the fewest number of bits that can store every value? (Stretch)
    Show the answer

    10. 9 bits reach only 511; 10 bits give 1,024 values, 0 to 1,023.

  8. A game stores each player's score in an unsigned 8-bit integer. A player on 250 points earns 10 more. What score is displayed? (Stretch)
    Show the answer

    4. 260 needs 9 bits; dropping the ninth bit (256) leaves 4. This is why scores use larger integer types.

  9. Why might a 4-place left shift of 00110000 give a wrong answer in an 8-bit register? (Stretch)
    Show the answer

    1s are shifted out of the top, so the result overflows. 48 × 16 = 768 needs 10 bits; the leading 1s are lost, leaving 00000000.

Key takeaways

  • In binary each place is worth double the one to its right; n bits give 2n values, so 8 bits store whole numbers from 0 to 255.
  • One hex digit is exactly four bits, so convert between hex and binary nibble by nibble; to get denary, multiply the first hex digit by 16 and add the second.
  • In binary addition, 1 + 1 makes 0 carry 1, and 1 + 1 + 1 makes 1 carry 1; an overflow occurs when there is a carry out of the most significant bit.
  • Each left shift doubles the value and each right shift halves it (rounding down); bits shifted out of either end are lost, which causes overflow or loss of precision.
  • To negate a two's complement number, invert all the bits and add 1; the most significant bit is worth −2n − 1.
  • More bits in the mantissa give more precision; more bits in the exponent give a greater range. For a fixed total, one is traded for the other.

Common mistakes in Data Representation

  • Thinking 8 bits can store 256 as the largest number. 28 = 256 is the number of different values; because one of them is 0, the largest is 255.
  • Converting hex to binary via denary for long numbers. Each hex digit maps directly to four bits; the detour through denary is slower and error-prone.
  • Ignoring the final carry in an exam answer. If the carry goes beyond the available bits, say an overflow has occurred and give the truncated result.
  • Forgetting that a right shift loses the bits that fall off the end. 7 shifted right by 1 is 3, not 3.5.
  • Converting a negative number by inverting the bits without adding 1. That gives ones' complement, which is off by one: inverting 00101101 alone gives −46, not −45.
  • Comparing floating-point results with ==. Rounding means two calculations that should agree may differ in the last bit; compare within a small tolerance.

Lessons in this school

  1. Binary and denary
    Computers store all data as binary: patterns of 0s and 1s.
  2. Hexadecimal
    Hexadecimal (base 16) is a compact way for people to read and write binary: each hex digit stands for exactly four bits.
  3. Binary arithmetic and overflow
    Computers add numbers in binary using the same column method as denary, carrying a 1 whenever a column totals 2 or more.
  4. Binary shifts
    A binary shift moves every bit of a number left or right.
  5. Two's complement
    Two's complement is the standard way computers store negative whole numbers.
  6. Fixed-point and floating-point numbers
    Real numbers with fractional parts are stored in binary either in fixed point, with the binary point in a set position, or in floating point, as a mantissa and an exponent.
  7. Units of data
    Data sizes are measured in bits and bytes and in larger units such as kilobytes, megabytes and gigabytes.
  8. Character sets: ASCII and Unicode
    Text is stored by giving every character a number, its code, defined by a character set.
  9. Bitmap images
    A bitmap image is a grid of pixels, each stored as a binary colour code.
  10. Vector graphics
    Vector graphics store an image as a list of shapes and their properties rather than as pixels.
  11. Sound
    Sound is an analogue wave, so it must be sampled to be stored digitally.
  12. Lossy and lossless compression
    Compression reduces the size of a file so it takes less storage and transfers faster.
  13. Run-length encoding
    Run-length encoding (RLE) is a simple lossless compression method that replaces runs of repeated values with a count and the value.
  14. Huffman coding
    Huffman coding is a lossless compression method that gives short binary codes to frequent characters and longer codes to rare ones.
  15. Ciphers: Caesar and Vernam
    Encryption turns plaintext into ciphertext that only someone with the key can read.
  16. Error detection: parity and check digits
    Data can be corrupted when it is transmitted or typed in.

Data Representation: questions students ask

11: write 1 and carry 1.

How do you find the two's complement of a binary number?

Invert every bit, then add 1.

What does ord("A") return in Python?

65, the character code of "A".

What is metadata in an image file?

Data about the image, such as its width, height and colour depth, used to display it correctly.
