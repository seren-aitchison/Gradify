Key terms and formulas at a glance

Closed-loop control
Control in which the output is measured and fed back to correct the input
Laplace transform
An integral transform converting a function of time into a function of the complex variable s
Transfer function
The ratio of the Laplace transform of the output to that of the input, with zero initial conditions
Mass-spring-damper
A second-order mechanical system of mass, spring and damper
Time constant
The time for a first-order response to reach 63.2% of its final change
Natural frequency
The frequency at which an undamped system would oscillate
System type
The number of pure integrators in the open-loop transfer function
Stability
The property that bounded inputs produce bounded outputs; all poles in the left half-plane
PID controller
A controller combining proportional, integral and derivative action
Root locus
The path of closed-loop poles in the s-plane as a gain varies from zero to infinity
Bode plot
Plots of magnitude in decibels and phase against log frequency
Encoder
A sensor producing digital pulses or codes that measure position or speed

Five sample flashcards

Answer each from memory, then open it to check. Still foggy? Each card has the plain-English version.

What is the error signal in a feedback loop?

The difference between the reference (set point) and the measured output. From “Introduction to control systems” →

In plain English: A control system makes a physical process behave as we want, despite disturbances. Key idea: Closed-loop control measures the output and uses the error from the set point to correct it, giving accuracy and disturbance rejection that open-loop control lacks; design balances stability, accuracy, speed and robustness.

Where are the poles of G(s) = 5/(s + 3)?

At s = −3. From “Transfer functions and block diagrams” →

In plain English: A transfer function describes how a linear system turns an input into an output in the Laplace domain. Key idea: A transfer function is output over input in the s-domain with zero initial conditions; poles govern the response; series blocks multiply, parallel blocks add, and negative feedback gives G/(1 + GH).

What is the damped natural frequency?

ωd = ωn√(1 − ζ2), the frequency of the decaying oscillation. From “Second-order system response” →

In plain English: Second-order systems, such as suspensions and positioning systems, can oscillate. Key idea: Second-order systems are described by ωn and ζ; underdamped systems overshoot by an amount set by ζ, settle in about 4/(ζωn), and designers tune ζ and ωn to meet specifications.

What does integral action do?

Removes steady-state error by acting on the accumulated error. From “Feedback and PID control” →

In plain English: The PID controller is the most widely used controller in industry. Key idea: PID combines proportional action for speed, integral action to remove steady-state error and derivative action for damping; practical controllers need anti-windup and filtered derivatives, and can be tuned with Ziegler–Nichols then refined.

What effect does a thermocouple use?

The Seebeck effect: a junction of two dissimilar metals produces a voltage that depends on temperature. From “Sensors and actuators” →

In plain English: Sensors measure the variables a control system needs, and actuators apply its decisions to the physical world. Key idea: Control relies on sensors such as encoders, strain gauges and thermocouples, chosen for range, resolution, accuracy and speed, and on actuators such as motors, solenoids and hydraulic cylinders, linked through signal conditioning and power electronics.

Quick quiz: test yourself on Control Systems and Signals

9 questions from the course, from foundation recall to stretch. Pick an answer, then say whether you knew it or guessed.

  1. Which is an example of closed-loop control? (Foundation recall)
    Show the answer

    A thermostat controlling a heater. The thermostat measures temperature and adjusts the heater.

  2. What is the Laplace transform of a unit step? (Foundation recall)
    Show the answer

    1/s. The transform of the constant 1 for t ≥ 0 is 1/s.

  3. Two blocks G1 and G2 are connected in series. What is the overall transfer function? (Foundation recall)
    Show the answer

    G1G2. Cascaded blocks multiply: the output of one is the input of the next.

  4. In a feedback loop, what does the sensor do? (Exam style)
    Show the answer

    Measures the output and feeds it back. The sensor provides the measured output for comparison.

  5. What is the transform of dy/dt if y(0) = 3? (Exam style)
    Show the answer

    sY(s) − 3. The derivative property subtracts the initial value.

  6. G(s) = 4/(s + 2) has unity negative feedback. What is the closed-loop transfer function? (Exam style)
    Show the answer

    4/(s + 6). T = G/(1 + G) = 4/(s + 2 + 4) = 4/(s + 6).

  7. Why might making a controller more aggressive be undesirable? (Stretch)
    Show the answer

    It can increase overshoot and reduce stability margins. Faster response often trades off against overshoot and robustness.

  8. What is the inverse transform of 3/(s + 4)? (Stretch)
    Show the answer

    3e−4t. The pair 1/(s + a) corresponds to e−at.

  9. What is the characteristic equation of a unity feedback system with G(s) = K/[s(s + 3)]? (Stretch)
    Show the answer

    s2 + 3s + K = 0. Setting 1 + G = 0 and clearing fractions gives s(s + 3) + K = 0.

Key takeaways

  • Closed-loop control measures the output and uses the error from the set point to correct it, giving accuracy and disturbance rejection that open-loop control lacks; design balances stability, accuracy, speed and robustness.
  • The Laplace transform converts differentiation into multiplication by s, so linear ODEs become algebra; solve for Y(s), use partial fractions and a table to invert, and check steady state with the final value theorem.
  • A transfer function is output over input in the s-domain with zero initial conditions; poles govern the response; series blocks multiply, parallel blocks add, and negative feedback gives G/(1 + GH).
  • Physical laws give differential equations that become transfer functions: the mass-spring-damper gives 1/(ms2 + cs + k), an RC circuit 1/(RCs + 1); mechanical, electrical and thermal systems are analogous, and non-linear systems are linearised.
  • A first-order system K/(τs + 1) rises to K(1 − e−t/τ) for a unit step, reaching 63.2% in one time constant and settling in about 4τ, with no overshoot.
  • Second-order systems are described by ωn and ζ; underdamped systems overshoot by an amount set by ζ, settle in about 4/(ζωn), and designers tune ζ and ωn to meet specifications.

Common mistakes in Control Systems and Signals

  • Assuming feedback always improves a system. Poorly designed feedback can cause oscillation or instability.
  • Applying the final value theorem to an unstable or oscillating system. It is valid only if the system actually settles.
  • Forgetting the sign convention. With positive feedback the closed-loop transfer function is G/(1 − GH).
  • Forgetting that models are approximations. Friction, saturation and other non-linearities mean a linear model is valid only near its operating point.
  • Reading the time constant at 50% of the final value. It is the time to reach 63.2%.
  • Thinking critical damping is always best. A slightly underdamped response, with ζ around 0.7, is often faster with acceptable overshoot.

Lessons in this school

  1. Introduction to control systems
    A control system makes a physical process behave as we want, despite disturbances.
  2. Laplace transforms
    The Laplace transform turns linear differential equations into algebraic equations, which makes analysing dynamic systems much easier.
  3. Transfer functions and block diagrams
    A transfer function describes how a linear system turns an input into an output in the Laplace domain.
  4. Modelling physical systems
    To design a controller we first need a mathematical model of the system.
  5. First-order system response
    Many systems, from heaters to motors, respond like first-order systems.
  6. Second-order system response
    Second-order systems, such as suspensions and positioning systems, can oscillate.
  7. Steady-state error
    Steady-state error is the difference between the desired and actual output after transients die away.
  8. Stability and the Routh–Hurwitz criterion
    A control system must be stable before anything else.
  9. Feedback and PID control
    The PID controller is the most widely used controller in industry.
  10. Root locus
    The root locus shows how the closed-loop poles move as a gain changes, giving a visual guide to stability and response.
  11. Frequency response and Bode plots
    Frequency response describes how a system responds to sinusoidal inputs of different frequencies.
  12. Sensors and actuators
    Sensors measure the variables a control system needs, and actuators apply its decisions to the physical world.
  13. Digital control and sampling
    Most modern controllers run on microprocessors that sample signals at discrete times.
  14. Signals and the Fourier series
    Any periodic signal can be built from sinusoids.
