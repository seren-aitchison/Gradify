Lessons in this school

  1. The information-processing approach
    The information-processing approach describes the mind as a system that takes in, transforms, stores and retrieves information in stages.
  2. Selective attention
    Selective attention is the ability to focus on some information while ignoring the rest.
  3. Divided attention
    Divided attention is attending to more than one task at once.
  4. Sustained attention
    Sustained attention (vigilance) is maintaining focus over long periods, especially when watching for rare signals.
  5. Sensation and perception
    Sensation is detecting physical energy with sense organs; perception is organising and interpreting it into meaningful experience.
  6. Visual perception
    Vision turns patterns of light on the retina into a stable, three-dimensional world of objects.
  7. Auditory perception
    Auditory perception turns pressure waves into the experience of pitch, loudness, location and speech.
  8. Gestalt principles
    Gestalt psychologists showed that we perceive organised wholes, not collections of separate parts.
  9. Pattern recognition
    Pattern recognition is identifying objects, letters, words and faces from sensory input.
  10. Sensory memory
    Sensory memory holds a brief, detailed copy of what the senses have just registered.
  11. Short-term memory
    Short-term memory holds a small amount of information for a short time unless it is rehearsed.
  12. Working memory
    Working memory is the system that holds and manipulates information while we think.
  13. Long-term memory: episodic, semantic and procedural
    Long-term memory isn't one store but several.
  14. Encoding, storage and retrieval
    Remembering involves encoding information, storing it and retrieving it.
  15. Forgetting
    Forgetting is the loss of the ability to recall or recognise information.
  16. Interference
    Interference theory holds that we forget because other memories get in the way.
  17. Retrieval failure
    Retrieval failure means information is stored but can't be accessed without the right cues.
  18. Reconstructive memory and false memories
    Remembering is an active reconstruction, not a replay.
  19. Eyewitness testimony
    Eyewitness testimony is a witness's account of a crime or event.
  20. Language acquisition
    Children learn their first language rapidly and in a predictable sequence.
  21. Language processing
    Understanding language means recognising words, building sentence structures and constructing meaning, in a fraction of a second.
  22. Speech production
    Speaking involves turning an idea into words, grammar and sounds in real time.
  23. Problem solving
    Problem solving is finding a way from a current state to a goal when the route isn't obvious.
  24. Reasoning
    Reasoning is drawing conclusions from information.
  25. Decision-making
    Decision-making is choosing between options under uncertainty.
  26. Biases and heuristics
    Heuristics are mental shortcuts that usually work but can produce systematic errors called biases.
  27. Metacognition
    Metacognition is thinking about thinking: knowing what you know and controlling how you learn.
  28. Cognitive development
    Cognitive development is how thinking changes from infancy to adulthood.
  29. Theories of intelligence
    Intelligence is the general ability to reason, learn and solve problems.
  30. Intelligence testing
    Intelligence tests measure cognitive abilities and compare people with others of the same age.
  31. Creativity
    Creativity is producing ideas or products that are both novel and useful.
  32. Cognitive ageing
    Cognitive ageing is how thinking changes in later adulthood.

Key terms

Information processing
Describing cognition as the input, transformation, storage and output of information
Dichotic listening
Presenting different messages to each ear, often asking participants to shadow one
Divided attention
Attending to two or more tasks at once
Sustained attention
Maintaining focus over extended periods
Transduction
Converting physical energy into neural signals
Retinal disparity
The difference between the two eyes' images, used as a depth cue
Cochlea
The fluid-filled inner-ear structure where sound is transduced
Figure–ground
Separating an object from its background
Feature analysis
Recognising patterns by detecting and combining basic features
Iconic memory
Brief visual sensory memory
Chunking
Grouping items into meaningful units to increase capacity
Central executive
The component that directs attention and coordinates working memory
Episodic memory
Memory for personal experiences in time and place
Consolidation
The stabilisation of memories over time after encoding
