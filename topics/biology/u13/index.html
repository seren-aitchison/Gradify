Lessons in this school

  1. Introduction to bioinformatics
    Bioinformatics uses computing to store, analyse and interpret biological data.
  2. Biological databases
    Biological databases store sequences, structures and other data for researchers worldwide.
  3. DNA sequence analysis
    Computers analyse DNA sequences to find genes and features.
  4. Protein sequence analysis
    Protein sequences reveal function, structure and evolutionary relationships.
  5. Sequence alignment
    Sequence alignment compares sequences to find similarities.
  6. BLAST
    BLAST searches databases for sequences similar to a query.
  7. Multiple sequence alignment
    Multiple sequence alignment lines up three or more sequences together.
  8. Phylogenetic analysis
    Phylogenetic analysis builds trees from sequence data.
  9. Genome annotation
    Genome annotation identifies the location and function of features in a genome.
  10. Gene expression analysis
    Gene expression analysis measures which genes are active and how much.
  11. RNA sequencing
    RNA sequencing reads the RNA in a sample to measure expression and discover transcripts.
  12. Differential expression
    Differential expression analysis finds genes whose expression changes between conditions.
  13. Proteomics
    Proteomics studies the full set of proteins in a cell or tissue.
  14. Metabolomics
    Metabolomics measures the small molecules in a biological sample.
  15. Structural bioinformatics
    Structural bioinformatics studies the 3D shapes of biological molecules.
  16. Protein structure prediction
    Computers can now predict protein structures from sequence.
  17. Molecular visualisation
    Molecular visualisation software displays molecules in 3D.
  18. Biological networks
    Biological networks represent interactions between molecules.
  19. Systems biology
    Systems biology studies how components interact to produce the behaviour of whole systems.
  20. Population genomics
    Population genomics uses genome-wide data to study variation within and between populations.
  21. Variant analysis
    Variant analysis identifies and interprets differences in a genome compared with a reference.
  22. Precision medicine
    Precision medicine tailors prevention and treatment to individual characteristics.
  23. Computational drug discovery
    Computational methods speed up the search for new medicines.
  24. Biological data science
    Biological data science applies statistics and machine learning to large biological datasets.
  25. Reproducible computational research
    Reproducible research lets others repeat analyses and get the same results.

Key terms

Bioinformatics
Using computing to analyse biological data
Accession number
A unique identifier for a database entry
FASTA
A simple text format for sequences
Protein domain
An independently folding functional unit
Global alignment
Alignment of entire sequences
BLAST
A tool searching databases for similar sequences
Multiple sequence alignment
Alignment of three or more sequences
Neighbour joining
A distance-based tree-building method
Genome annotation
Identifying features and functions in a genome
Transcriptome
All RNA in a cell at a given time
RNA-seq
Sequencing RNA to study expression
Fold change
Ratio of expression between conditions
Proteome
All proteins in a cell or tissue at a given time
Metabolome
The complete set of small molecules in a sample
