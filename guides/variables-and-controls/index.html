Variables and controls: naming vs controlling

By the Gradify team · Updated for the 2026–27 academic year

The independent variable is what you change, the dependent variable is what you measure, and control variables are everything you keep the same. The mark usually goes for saying how you keep a control constant (a water bath at 25 °C), not just naming it (temperature).

Core rule: Change one (independent), measure one (dependent), keep the rest the same (controls).

Tools for this step: Unit converter (keep quantities consistent)

Which variable is which?

VariableMeaningEnzyme example
IndependentWhat you deliberately changeTemperature: 20, 30, 40, 50, 60 °C
DependentWhat you measureTime for the starch to disappear (s)
ControlWhat you keep the samepH, enzyme and substrate concentration, volumes

Key takeaway: Change one (independent), measure one (dependent), keep the rest the same (controls).

Naming vs controlling: where the marks are

Naming (often 0 marks)Controlling (the mark)
Keep the pH the sameAdd 1 cm³ of pH 7 buffer to every tube
Same temperaturePlace tubes in a thermostatic water bath at 25 °C
Same amount of enzymeUse 2 cm³ of 1% amylase, measured with a graduated pipette
Test yourself: How would you control light intensity in a photosynthesis experiment? Reveal

Keep the lamp at a fixed, measured distance (e.g. 20 cm) and use the same bulb; block other light sources.

What's a control group?

A control group (or control experiment) is identical except it doesn't get the independent variable, for example boiled enzyme or a placebo. It shows that the effect is caused by the independent variable and not something else.

Common pitfalls

  • Naming a control without saying how it's kept constant.
  • Saying repeats improve validity (they improve reliability).

Questions

What is a control variable?

A variable kept the same throughout an experiment so it can't affect the results. You should say how it's kept constant, not just name it.
