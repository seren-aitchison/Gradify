Exam question stems and the answer skeleton for each

By the Gradify team · Updated for the 2026–27 academic year

Unfamiliar exam questions are usually familiar stems in disguise: 'account for this anomaly', 'suggest why', 'compare these two', 'design an investigation'. Each stem has a skeleton answer you can learn, so on the day you fill in content instead of inventing a structure.

Core rule: Suggest = principle → this context → consequence.

How do I answer 'suggest why'?

'Suggest' means the answer isn't in the specification word for word: apply a principle you know to a new case. Skeleton: name the principle → apply it to this context → state the consequence. Any plausible, scientifically sound answer usually earns credit.

Key takeaway: Suggest = principle → this context → consequence.

How do I answer 'account for the anomaly'?

Skeleton: identify the anomalous value → name a specific error that would push it in that direction → explain the direction ("the reading is too high because heat was lost, so less…"). Vague answers like "human error" score nothing.

Key takeaway: Name a specific error and the direction it pushes the result.

How do I answer 'compare the mechanisms'?

Skeleton: one shared feature, then two or three differences, each sentence naming both. Use a quick two-column plan first. Marks go to explicit comparison ("whereas SN1 goes via a carbocation, SN2 is a single step"), not two separate descriptions.

How do I answer 'design an investigation'?

Skeleton: independent variable and its range → dependent variable and how it's measured → control variables and how each is kept constant → repeats and means → safety. See variables and controls.

Key takeaway: Design = IV with range, DV with method, controls with how, repeats, safety.

Test yourself: What's missing from 'keep the temperature the same' as a control? Reveal

How: for example 'use a thermostatic water bath at 25 °C'. Naming a control without the method usually loses the mark.

How do I answer 'evaluate the claim'?

Skeleton: what supports the claim (with evidence) → what limits it (sample, method, alternative explanation) → judgement with a reason. End with a sentence that starts "Overall…" and answers the question.

Common pitfalls

  • 'Human error' as an anomaly explanation.
  • Naming a control without saying how.

What is a question stem?

The opening phrase of an exam question that sets the task, such as 'suggest why' or 'compare'. Learning a skeleton answer for each common stem saves time and marks.
