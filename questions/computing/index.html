Computational Thinking and Problem Solving

  1. Which best describes computer science? (Foundation recall)
    • The management of computer equipment inside an organisation
    • The repair and maintenance of computer hardware
    • The skill of using office software and the internet safely
    • The study of computation, algorithms and the systems that carry them out
    Reveal the answer and mark-scheme reasoning

    The study of computation, algorithms and the systems that carry them out. Computer science is about computation itself: what can be computed and how. Using software is digital literacy; managing systems is IT; repair is a technical trade. Revise Computational Thinking and Problem Solving →

  2. A researcher proves that a new method finds routes on any map in half the steps of the old one. Which area of computer science is this mainly part of? (Exam style)
    • Algorithms and their analysis
    • Computer networks
    • Human-computer interaction
    • Operating systems
    Reveal the answer and mark-scheme reasoning

    Algorithms and their analysis. The result concerns the number of steps a method takes, which is the analysis of algorithms. Networks and operating systems are systems areas; HCI studies how people use computers. Revise Computational Thinking and Problem Solving →

  3. Which is the strongest reply to the claim that computer science is "just programming"? (Stretch)
    • Computer science is only about hardware and electronics
    • Most computer scientists never write any code at all
    • Programming expresses ideas, but the subject also asks which methods are correct, efficient and possible at all
    • Programming is too easy to count as a university subject
    Reveal the answer and mark-scheme reasoning

    Programming expresses ideas, but the subject also asks which methods are correct, efficient and possible at all. Programming is central but is the medium, not the whole: analysing correctness, efficiency and computability is what makes it a science. The other options are false or overstate the case. Revise Computational Thinking and Problem Solving →

Python Programming Fundamentals

  1. What is a script in Python? (Foundation recall)
    • A list of error messages from the interpreter
    • A saved file of instructions run from top to bottom
    • A single line typed at the >>> prompt
    • The machine code produced by a compiler
    Reveal the answer and mark-scheme reasoning

    A saved file of instructions run from top to bottom. A script is a saved .py file. Lines typed at the prompt are run in the interactive shell. Revise Python Programming Fundamentals →

  2. A script contains print("A"), then print("B"), then print("C"). What is displayed? (Exam style)
    • A, B and C on one line with no spaces
    • A, B and C on three separate lines
    • C, B and A on three separate lines
    • Only C, because it is the last line
    Reveal the answer and mark-scheme reasoning

    A, B and C on three separate lines. The lines run in sequence, and each print ends with a new line by default. Revise Python Programming Fundamentals →

  3. Which is a genuine disadvantage of Python being interpreted rather than compiled to machine code? (Stretch)
    • Errors can never be found until the program is finished
    • Programs can't be run on more than one operating system
    • Programs usually run more slowly than equivalent compiled code
    • Python programs can't use variables or loops
    Reveal the answer and mark-scheme reasoning

    Programs usually run more slowly than equivalent compiled code. Interpretation adds overhead at run time, so pure Python is slower than compiled C. Interpreted code is actually more portable, and errors are reported as soon as a line runs. Revise Python Programming Fundamentals →

Data Structures, Files and Robust Code in Python

  1. For pets = ["cat", "dog", "fish"], what is pets[1]? (Foundation recall)
    • "cat"
    • "dog"
    • "fish"
    • An IndexError
    Reveal the answer and mark-scheme reasoning

    "dog". Indexing starts at 0, so index 1 is the second item. Revise Data Structures, Files and Robust Code in Python →

  2. What does x = [1, 2, 3], then x[0] = x[2], then x[2] = 0 leave in x? (Exam style)
    • [0, 2, 3]
    • [1, 2, 0]
    • [3, 2, 0]
    • [3, 2, 3]
    Reveal the answer and mark-scheme reasoning

    [3, 2, 0]. x[0] takes the value 3, then x[2] is set to 0, giving [3, 2, 0]. Revise Data Structures, Files and Robust Code in Python →

  3. Which is the main advantage of a dynamic list over a fixed-size array? (Stretch)
    • It always uses less memory than an array
    • It can grow or shrink as items are added or removed
    • It can never raise an IndexError
    • Its items can only be accessed in order
    Reveal the answer and mark-scheme reasoning

    It can grow or shrink as items are added or removed. Dynamic lists resize as needed; fixed arrays must be declared large enough in advance. Revise Data Structures, Files and Robust Code in Python →

Algorithms

  1. How does linear search find an item? (Foundation recall)
    • It checks each item in order until it finds the target or reaches the end
    • It jumps to the position given by a hash function
    • It repeatedly halves the list and discards one half
    • It sorts the list and then checks the middle item
    Reveal the answer and mark-scheme reasoning

    It checks each item in order until it finds the target or reaches the end. Linear search is a sequential check of every item. Halving is binary search; hashing is used by dictionaries. Revise Algorithms →

  2. How many comparisons does a linear search make to find 8 in [3, 9, 1, 8, 4]? (Exam style)
    • 1
    • 2
    • 4
    • 5
    Reveal the answer and mark-scheme reasoning

    4. It compares 3, 9, 1 and then 8, which matches on the fourth comparison. Revise Algorithms →

  3. A list of 50 unsorted items is searched only once. Why is linear search the better choice than sorting and then binary searching? (Stretch)
    • Binary search doesn't work on lists of 50 items
    • Linear search is always faster than binary search
    • Sorting costs more than the single linear search it would replace
    • Sorting would delete duplicate items from the list
    Reveal the answer and mark-scheme reasoning

    Sorting costs more than the single linear search it would replace. Sorting takes about n log n steps; one linear search takes at most n, so for a single search on unsorted data linear search wins. Revise Algorithms →

Data Structures

  1. What does an abstract data type define? (Foundation recall)
    • The exact layout of the data in memory
    • The operations on the data and how they behave
    • The programming language that must be used
    • The speed of each operation in seconds
    Reveal the answer and mark-scheme reasoning

    The operations on the data and how they behave. An ADT is about behaviour; layout is the implementation's concern. Revise Data Structures →

  2. A team replaces the array inside its stack with a linked list. Code elsewhere that only calls push and pop is unchanged. Which principle does this show? (Exam style)
    • Normalisation of data
    • Recursion replacing iteration
    • Separating an ADT's interface from its implementation
    • Static memory allocation
    Reveal the answer and mark-scheme reasoning

    Separating an ADT's interface from its implementation. Because other code uses only the operations, the implementation can change freely. Revise Data Structures →

  3. Why is it risky for code to read a stack's internal array directly instead of calling pop and peek? (Stretch)
    • Arrays can't be read once they are inside a stack
    • It makes the stack hold items in the wrong data type
    • Reading an array always causes a syntax error
    • The code breaks if the stack's implementation changes, and it may bypass rules such as last in, first out
    Reveal the answer and mark-scheme reasoning

    The code breaks if the stack's implementation changes, and it may bypass rules such as last in, first out. Depending on internals ties code to one implementation and can violate the ADT's behaviour. Revise Data Structures →

Data Representation

  1. What is the denary value of binary 00001101? (Foundation recall)
    • 11
    • 13
    • 15
    • 26
    Reveal the answer and mark-scheme reasoning

    13. The 1s are in the 8, 4 and 1 columns, so the value is 8 + 4 + 1 = 13. Revise Data Representation →

  2. What is denary 150 in 8-bit binary? (Exam style)
    • 01101001
    • 10010011
    • 10010110
    • 11000110
    Reveal the answer and mark-scheme reasoning

    10010110. 150 = 128 + 16 + 4 + 2, giving 1 0 0 1 0 1 1 0. Revise Data Representation →

  3. A sensor must report values from 0 to 1,000. What is the fewest number of bits that can store every value? (Stretch)
    • 1,000
    • 10
    • 8
    • 9
    Reveal the answer and mark-scheme reasoning

    10. 9 bits reach only 511; 10 bits give 1,024 values, 0 to 1,023. Revise Data Representation →
