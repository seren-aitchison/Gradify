Chain Rule

Differentiate the outside, keep the inside, then multiply by the derivative of the inside.

Mathematics · Calculus · about 2 minutes

What you'll be able to do

  • Differentiate composite functions with the chain rule
  • Recognise the inner and outer functions in an expression

The rule

dy/dx = (dy/du)(du/dx); equivalently d/dx f(g(x)) = f′(g(x)) g′(x)
  • (3x + 1)5: outer u5, inner u = 3x + 1. Derivative 5(3x + 1)4 × 3 = 15(3x + 1)4.
  • ex^{2}: derivative ex^{2} × 2x.
  • ln(x2 + 1): derivative (2x)/(x2 + 1). In general d/dx ln f(x) = f′(x)/f(x).
  • sin(5x): 5cos(5x); cos2 x = (cos x)2: 2cos x × (−sin x) = −2 sin x cos x.

Using it well

  • Several layers: d/dx sin3(2x) = 3 sin2(2x) × cos(2x) × 2.
  • Related to inverse functions: dy/dx = 1/(dx/dy), so for x = y3 + y, dy/dx = 1/(3y2 + 1).
Worked example

Differentiate y = √(x2 + 4x).

  1. Write y = (x2 + 4x)1/2
  2. Outer derivative: ½(x2 + 4x)−1/2; inner derivative: 2x + 4
  3. dy/dx = (2x + 4)/(2√(x2 + 4x)) = (x + 2)/√(x2 + 4x)
  • In Leibniz notation the chain rule looks like cancelling fractions, dy/du × du/dx, which helps you remember it (though it's a theorem, not cancellation).
  • It underlies implicit, parametric and logarithmic differentiation.
Common mistakeForgetting to multiply by the inner derivative, as in d/dx (3x + 1)5 = 5(3x + 1)4.

In 2 lines: The chain rule handles functions of functions. Multiply the outer derivative by the inner derivative.

Practice questions

Answer each one in your head before you open it: recalling beats rereading.

  1. What is d/dx (e4x)?
    • e4x
    • 4xe4x−1
    • e4
    • 4e4x
    • 4ex
    Show the answer

    Answer: 4e4x. The inner function 4x has derivative 4, which multiplies e4x.

  2. What is d/dx sin(x2)?
    • cos(x2)
    • 2x cos(2x)
    • −2x cos(x2)
    • 2 cos(x)
    • 2x cos(x2)
    Show the answer

    Answer: 2x cos(x2). Outer cos(x2) times inner derivative 2x.

  3. What is d/dx (1/(2x + 3)2)?
    • −4/(2x + 3)3
    • −2/(2x + 3)3
    • 1/(2(2x + 3))
    • −4/(2x + 3)2
    • 4/(2x + 3)3
    Show the answer

    Answer: −4/(2x + 3)3. (2x + 3)−2 gives −2(2x + 3)−3 × 2 = −4(2x + 3)−3.

Key terms

Chain rule
dy/dx = dy/du × du/dx, where y is a function of u and u a function of x
Inner function
The function applied first, such as u = 3x + 1 in (3x + 1)5
