Newton–Raphson Method

Newton–Raphson follows tangents; it's quadratically convergent at simple roots, linear at multiple roots; it can cycle or diverge from poor starts, so safeguards are used.

Mathematics · Numerical Analysis and Scientific Computing · about 2 minutes

What you'll be able to do

  • Apply Newton–Raphson iterations
  • Analyse convergence and failure modes

Derivation and examples

  • The tangent at xₙ meets the axis at xₙ − f(xₙ)/f′(xₙ).
  • Square roots: f(x) = x2 − a gives xn+1 = ½(xₙ + a/xₙ) (the Babylonian method).
  • Reciprocal without division: xn+1 = xₙ(2 − axₙ).

Convergence

  • Quadratic near a simple root: en+1 ≈ (f″/2f′) eₙ2.
  • Linear at multiple roots; use x − m f/f′ for multiplicity m.
  • Kantorovich's theorem gives conditions guaranteeing convergence.

Failures

  • f′ = 0 at an iterate: the step is undefined.
  • Cycling: x3 − 2x + 2 from 0 cycles between 0 and 1.
  • Divergence from poor starts; basins can be fractal (Newton fractals for z3 = 1).
  • Safeguard with line searches or bracketing.
Worked example

Compute √2 with Newton from x₀ = 1.

  1. x₁ = ½(1 + 2/1) = 1.5
  2. x₂ = ½(1.5 + 2/1.5) = 1.41667
  3. x₃ = ½(1.41667 + 1.41176) = 1.414216 (√2 = 1.414214): correct digits roughly double each step

Investigate with the lab. Find √2 to 10 decimal places in at most 5 steps, then make Newton's method fail from a start where the tangent is flat (the lab's challenges).

Common mistakeForgetting to check that f′(xₙ) isn't zero or tiny.

In 2 lines: Follow the tangent to the axis. Fast near roots, risky far away.

Practice questions

Answer each one in your head before you open it: recalling beats rereading.

  1. Newton's method on x3 − 2x + 2 from x₀ = 0 gives what behaviour?
    • It converges quadratically to a root
    • It diverges to infinity
    • It cycles between 0 and 1 forever
    • It stops because f′ = 0 at the start
    • It converges in one step
    Show the answer

    Answer: It cycles between 0 and 1 forever. x₁ = 0 − 2/(−2) = 1 and x₂ = 1 − 1/1 = 0, so it repeats.

  2. Why does Newton converge quadratically near a simple root?
    • It halves the error each step because the tangent bisects the interval
    • It uses two starting points, so it gains two digits per iteration
    • Every function is exactly linear near a root, so one step suffices
    • The tangent matches f to first order, so the remaining error comes from the second-order term, proportional to eₙ2
    • It converges only linearly near simple roots, and quadratically at double roots
    Show the answer

    Answer: The tangent matches f to first order, so the remaining error comes from the second-order term, proportional to eₙ2. Taylor expansion gives en+1 ≈ (f″(x)/2f′(x)) eₙ2.

  3. Why does Newton's method fail from a point where f′(x) = 0?
    • It converges instantly
    • It needs two starting points
    • The function has no root
    • It doesn't fail
    • The tangent is horizontal and never meets the x-axis, so the next iterate is undefined
    Show the answer

    Answer: The tangent is horizontal and never meets the x-axis, so the next iterate is undefined. The update x − f(x)/f′(x) divides by zero.

Key terms

Newton–Raphson iteration
xn+1 = xₙ − f(xₙ)/f′(xₙ)
Basin of attraction
The set of starting points from which the iteration converges to a given root
