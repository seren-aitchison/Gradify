Autonomous Differential Equations

Equilibria solve f(y) = 0; f′ < 0 means stable; read the phase line; harvesting beyond rK/4 causes collapse.

Mathematics · Differential Equations · about 2 minutes

What you'll be able to do

  • Find equilibria and classify their stability
  • Analyse population models with harvesting

Phase line

  • Mark the zeros of f on a line.
  • Where f > 0, arrows point up (y increases); where f < 0, they point down.
  • Stable: arrows point towards it; unstable: away; semi-stable: mixed.

Stability test

  • f′(y) < 0: stable. f′(y) > 0: unstable. f′(y*) = 0: inconclusive.
  • Solutions can't cross equilibria, so they're monotone between them.
  • Time translation: if y(t) solves it, so does y(t − c).

Population models

  • Logistic: y′ = ry(1 − y/K) has unstable 0 and stable K.
  • Constant harvesting h: y′ = ry(1 − y/K) − h. The largest sustainable h is rK/4; above it the population collapses.
  • Allee effect: populations below a threshold die out.
Worked example

Classify the equilibria of y′ = y(3 − y).

  1. Equilibria where y(3 − y) = 0: y = 0 and y = 3
  2. f′(y) = 3 − 2y: f′(0) = 3 > 0 (unstable), f′(3) = −3 < 0 (stable)
  3. Any positive starting value tends to 3

Investigate with the lab. Start the logistic equation at an equilibrium (y₀ = 0 or 3) and see the solution stay flat (the lab's challenge). Then start just above and just below.

Common mistakeConcluding stability from f′(y*) = 0, which needs further analysis.

In 2 lines: Phase lines reveal autonomous behaviour. The sign of f′ decides stability.

Practice questions

Answer each one in your head before you open it: recalling beats rereading.

  1. For y′ = y2 − 4, which equilibrium is stable?
    • y = 2
    • Both
    • Neither
    • y = −2
    • y = 0
    Show the answer

    Answer: y = −2. f′(y) = 2y: f′(−2) = −4 < 0 (stable), f′(2) = 4 > 0 (unstable).

  2. Why can't two different solutions of an autonomous ODE cross?
    • Autonomous equations have only one solution
    • Solutions are always parallel lines
    • Crossing would make f negative
    • They can cross
    • Uniqueness forbids two solutions through the same point
    Show the answer

    Answer: Uniqueness forbids two solutions through the same point. With f Lipschitz, the solution through any point is unique.

  3. For the logistic equation in the lab, what happens to solutions starting between 0 and 3?
    • They rise towards the stable equilibrium 3
    • They fall to 0
    • They stay constant
    • They grow without bound
    • They oscillate
    Show the answer

    Answer: They rise towards the stable equilibrium 3. Between the equilibria dy/dx > 0, and 3 attracts nearby solutions.

Key terms

Equilibrium
A value y* with f(y*) = 0, giving a constant solution
Stable equilibrium
One that nearby solutions approach; f′(y*) < 0 is a sufficient test
