Secant Method

The secant method approximates f′ by a difference quotient; order ≈ 1.618 with one evaluation per step; often more efficient than Newton; regula falsi and Broyden are relatives.

Mathematics · Numerical Analysis and Scientific Computing · about 2 minutes

What you'll be able to do

  • Apply the secant iteration
  • Compare the secant method with Newton and false position

The method

  • Uses two starting points and one new function evaluation per step.
  • The slope (f(xₙ) − f(xₙ₋₁))/(xₙ − xₙ₋₁) approximates f′.
  • Order φ ≈ 1.618: superlinear.

Efficiency

  • Newton costs one f and one f′ per step (order 2).
  • If f′ costs as much as f, two secant steps (order φ2 ≈ 2.618) cost the same as one Newton step.
  • So secant is often more efficient.

Variants

  • False position (regula falsi) keeps a bracket but can stall on one side.
  • Illinois and Anderson–Björck modifications fix the stalling.
  • Inverse quadratic interpolation uses three points (inside Brent).
  • Broyden's method generalises secant to systems.
Worked example

Apply one secant step to f(x) = x2 − 2 with x₀ = 1 and x₁ = 2.

  1. f(1) = −1 and f(2) = 2; the slope = (2 − (−1))/(2 − 1) = 3
  2. x₂ = 2 − 2/3 = 1.3333
  3. Next steps approach √2 ≈ 1.4142 superlinearly

Investigate with the lab. Run the secant method beside Newton's on the same equation and compare how many steps each needs, remembering secant needs no derivative.

Common mistakeUsing nearly equal xₙ and xₙ₋₁, so the slope suffers cancellation.

In 2 lines: Secant swaps derivatives for differences. Superlinear and efficient.

Practice questions

Answer each one in your head before you open it: recalling beats rereading.

  1. What does the secant method use in place of f′(xₙ)?
    • The second derivative estimated at xₙ
    • The function value f(xₙ) divided by xₙ
    • A random estimate of the local slope
    • The slope of the line through the last two iterates
    • The midpoint of the current bracket
    Show the answer

    Answer: The slope of the line through the last two iterates. (f(xₙ) − f(xₙ₋₁))/(xₙ − xₙ₋₁) approximates the derivative.

  2. Why can false position (regula falsi) converge slowly?
    • It never keeps a bracket, so it can wander away from the root
    • It uses exact derivatives, which are expensive to compute
    • It always diverges unless the function is linear
    • It is always fast, since it combines bisection and secant
    • One endpoint can stay fixed for many steps, so the bracket shrinks from one side only
    Show the answer

    Answer: One endpoint can stay fixed for many steps, so the bracket shrinks from one side only. When f is convex in the bracket, one end barely moves; Illinois-type modifications fix this.

  3. What does the secant method use instead of f′(x)?
    • The gradient of the line through the last two iterates
    • The second derivative
    • A fixed slope of 1
    • The midpoint of a bracket
    • Nothing at all
    Show the answer

    Answer: The gradient of the line through the last two iterates. (f(xₙ) − f(xₙ₋₁))/(xₙ − xₙ₋₁) approximates the derivative.

Key terms

Secant iteration
xn+1 = xₙ − f(xₙ)(xₙ − xₙ₋₁)/(f(xₙ) − f(xₙ₋₁))
Golden ratio order
The secant method's convergence order φ = (1 + √5)/2 ≈ 1.618
