Gradient-Based Methods

Gradients come from analytic formulas, finite differences, forward or reverse AD, or adjoints; reverse mode gives all partials for a constant multiple of the function cost; this powers optimisation and ML.

Mathematics · Numerical Analysis and Scientific Computing · about 2 minutes

What you'll be able to do

  • Describe how gradients are computed: analytic, finite difference, automatic, adjoint
  • Explain why reverse-mode differentiation costs little more than one function evaluation

Ways to get gradients

  • Analytic formulas (error-prone by hand).
  • Finite differences: n + 1 evaluations for n parameters, with truncation error.
  • Forward-mode AD: one pass per input direction.
  • Reverse-mode AD: one backward pass for all inputs of a scalar output.

Cost

  • Reverse mode costs a small constant multiple (≈ 2–5) of one function evaluation, however many parameters.
  • Memory to store the forward computation is the main cost (checkpointing reduces it).
  • Neural network training relies on this (backpropagation).

Uses

  • Optimisation of designs (aerodynamic shapes via adjoints).
  • Parameter estimation and data assimilation (4D-Var weather forecasting).
  • Sensitivity analysis.
  • Libraries: JAX, PyTorch, Enzyme.
Worked example

For f(x, y) = xy + sin x, compute ∇f at (π, 2) by reverse-mode thinking.

  1. Forward pass: a = xy = 2π, b = sin π = 0, f = 2π
  2. Backward: ∂f/∂a = 1 and ∂f/∂b = 1; ∂f/∂x = y × 1 + cos x × 1 = 2 − 1 = 1; ∂f/∂y = x = π
  3. ∇f(π, 2) = (1, π)

Investigate with the lab. Get within 0.05 of the Rosenbrock minimum (1, 1) (the lab's challenge). Notice how slowly plain gradient descent travels along the curved valley.

Common mistakeUsing finite differences for gradients with millions of parameters.

In 2 lines: Gradients guide numerical methods. Reverse mode makes them cheap.

Practice questions

Answer each one in your head before you open it: recalling beats rereading.

  1. Which method gives the full gradient of a scalar function for roughly the cost of a few function evaluations?
    • Forward-mode automatic differentiation
    • Forward finite differences
    • Central finite differences
    • Symbolic expansion by hand
    • Reverse-mode automatic differentiation
    Show the answer

    Answer: Reverse-mode automatic differentiation. One backward sweep yields every partial derivative of a scalar output.

  2. What is the main cost of reverse-mode differentiation?
    • Memory to store the intermediate values of the forward pass
    • Many more arithmetic operations than the function
    • Truncation error in the derivatives
    • Needing a second derivative
    • It has no costs
    Show the answer

    Answer: Memory to store the intermediate values of the forward pass. The backward pass needs values from the forward pass, which checkpointing trades for recomputation.

  3. Why is the Rosenbrock function hard for plain gradient descent?
    • It has no minimum
    • Its minimum lies in a long, narrow, curved valley where the gradient points mostly across the valley
    • Its gradient is always zero
    • It is linear
    • It isn't hard
    Show the answer

    Answer: Its minimum lies in a long, narrow, curved valley where the gradient points mostly across the valley. Ill-conditioning makes steps zigzag rather than move along the valley floor.

Key terms

Reverse-mode automatic differentiation
Computing all partial derivatives of a scalar output by propagating sensitivities backwards through the computation (backpropagation)
Adjoint method
Computing gradients of an objective constrained by a differential equation by solving one extra (adjoint) equation
