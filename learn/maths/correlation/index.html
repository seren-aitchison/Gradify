Correlation

r = Sxy/√(SxxSyy) measures linear association; r2 is variance explained; correlation isn't causation; plot the data.

Mathematics · Statistics · about 2 minutes

What you'll be able to do

  • Calculate and interpret Pearson's and Spearman's correlation coefficients
  • Explain the limitations of correlation, including confounding

Calculating r

  • Sxy = Σ(x − x̄)(y − ȳ), Sxx = Σ(x − x̄)2, Syy = Σ(y − ȳ)2.
  • r = 1 or −1: points on a straight line; r near 0: no linear pattern.
  • r2 is the proportion of variation in y explained by a straight-line fit.
  • r has no units and is unchanged by linear rescaling of either variable.

Limitations

  • r measures linear association only: a perfect curve can have r = 0.
  • Outliers can create or destroy a correlation; Anscombe's quartet has four very different data sets with the same r.
  • Correlation isn't causation: ice cream sales and drownings both rise in summer (a confounder, temperature).
  • Restricting the range (only top students) weakens correlations.

Spearman and testing

  • Spearman's ρ uses ranks: good for ordinal data or monotonic curves.
  • A hypothesis test asks whether the population correlation could be zero; critical values depend on n.
Worked example

Find r for x = 1, 2, 3, 4, 5 and y = 2, 4, 5, 4, 5.

  1. x̄ = 3, ȳ = 4; deviations: x: −2, −1, 0, 1, 2 and y: −2, 0, 1, 0, 1
  2. Sxy = 4 + 0 + 0 + 0 + 2 = 6; Sxx = 10; Syy = 6
  3. r = 6/√60 ≈ 0.775: a fairly strong positive correlation

Investigate with the lab. Make r above 0.95, then below −0.9. Then load the curved data where r ≈ 0 although the relationship is strong.

Common mistakeConcluding that one variable causes the other from a correlation alone.

In 2 lines: Correlation measures linear association. It doesn't establish causation.

Practice questions

Answer each one in your head before you open it: recalling beats rereading.

  1. A correlation of r = 0.8 means a straight line explains what share of the variation in y?
    • 80%
    • 64%
    • 8%
    • 40%
    • 89%
    Show the answer

    Answer: 64%. The proportion explained is r2 = 0.64.

  2. The points lie exactly on y = x2 for x = −2, −1, 0, 1, 2. What is Pearson's r?
    • 1
    • −1
    • 0
    • 0.5
    • It's undefined
    Show the answer

    Answer: 0. The pattern is a perfect symmetric curve with no linear trend, so r = 0.

  3. Data lie exactly on y = x2 for x from −3 to 3. What is the Pearson correlation r, and why?
    • 1, because the relationship is perfect
    • −1, because half the points fall
    • 0.5
    • 0, because r measures only linear association and the pattern is symmetric
    • It can't be computed
    Show the answer

    Answer: 0, because r measures only linear association and the pattern is symmetric. Pearson's r detects straight-line trends; a symmetric parabola has none.

Key terms

Pearson's correlation coefficient
r = Sxy/√(SxxSyy), between −1 and 1
Spearman's rank correlation
Pearson's r applied to the ranks of the data; measures monotonic association
