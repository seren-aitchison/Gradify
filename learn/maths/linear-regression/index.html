Linear Regression

b = Sxy/Sxx, a = ȳ − b x̄; interpret b as change per unit x; R2 measures fit; always check residual plots.

Mathematics · Statistics · about 2 minutes

What you'll be able to do

  • Calculate the least squares regression line
  • Interpret the slope, intercept and R2, and check residuals

The formulas

b = Sxy/Sxx; a = ȳ − b x̄
  • The line passes through (x̄, ȳ).
  • The slope b is the expected change in y per unit increase in x.
  • The intercept a is the predicted y at x = 0, meaningful only if x = 0 is in range.

Checking the model

  • Residual plot against x or ŷ: should be patternless with constant spread.
  • Curves suggest non-linearity; funnels suggest non-constant variance.
  • Outliers and high-leverage points can swing the line.

Inference

  • With normal, independent, constant-variance errors: t = b/SE(b) with n − 2 degrees of freedom tests whether the slope is zero.
  • Confidence intervals for the mean response; wider prediction intervals for a new observation.
  • Regress y on x to predict y; the regression of x on y is a different line.
Worked example

For x = 1, 2, 3, 4, 5 and y = 2, 4, 5, 4, 5, find the least squares line and R2.

  1. Sxy = 6, Sxx = 10, Syy = 6; b = 0.6
  2. a = 4 − 0.6 × 3 = 2.2, so ŷ = 2.2 + 0.6x
  3. R2 = Sxy2/(SxxSyy) = 36/60 = 0.6

Investigate with the lab. Add points along a trend, then add one outlier that changes the gradient by more than 50% (the lab's challenge). Watch the residuals change too.

Common mistakeInterpreting the intercept when x = 0 is far outside the data.

In 2 lines: Least squares fits the best straight line. Residuals check the fit.

Practice questions

Answer each one in your head before you open it: recalling beats rereading.

  1. A regression of exam mark on hours studied has slope 3.2. What does that mean?
    • Each mark needs 3.2 hours
    • The intercept is 3.2
    • The correlation between hours and marks
    • Each extra hour is associated with 3.2 more marks on average
    • Studying causes exactly 3.2% more marks per hour
    Show the answer

    Answer: Each extra hour is associated with 3.2 more marks on average. The slope is the average change in y per unit of x (an association, not proof of cause).

  2. Why is a prediction interval wider than a confidence interval for the mean response at the same x?
    • It uses a larger significance level than the confidence interval
    • It ignores the slope
    • It uses fewer data
    • They're the same width
    • It includes the scatter of individual points as well as uncertainty in the line
    Show the answer

    Answer: It includes the scatter of individual points as well as uncertainty in the line. A new observation varies about the true line, adding σ2 to the uncertainty.

  3. Why can one outlier change a least-squares line a lot?
    • Squaring residuals gives a far-away point a very large weight in the sum being minimised
    • Least squares ignores outliers
    • Outliers are removed automatically
    • The gradient never changes
    • Outliers only affect r
    Show the answer

    Answer: Squaring residuals gives a far-away point a very large weight in the sum being minimised. Minimising squared residuals pulls the line strongly towards extreme points.

Key terms

Least squares
Choosing a and b to minimise Σ(y − a − bx)2
Coefficient of determination
R2, the proportion of variation in y explained by the model; r2 in simple regression
