Ordinary Differential Equations (ODEs)

Classify by order and linearity; verify by substitution; n constants for order n, fixed by conditions; existence and uniqueness need f Lipschitz in y.

Mathematics · Differential Equations · about 2 minutes

What you'll be able to do

  • Classify ODEs by order and linearity
  • Verify solutions and use initial conditions to find particular solutions

Classification

  • Order: the highest derivative present.
  • Linear vs nonlinear: y″ + 3y′ + 2y = sin x is linear; y′ = y2 and θ″ + sin θ = 0 aren't.
  • Homogeneous linear: g(x) = 0 (zero right-hand side); superposition then holds.

Solutions

  • A solution makes the equation true when substituted; check by differentiating.
  • General solutions contain n arbitrary constants for an nth-order equation.
  • Initial or boundary conditions fix the constants, giving a particular solution.

Existence and understanding

  • Picard–Lindelöf: y′ = f(x, y), y(x₀) = y₀ has a unique local solution if f is continuous and Lipschitz in y.
  • Direction fields show solution curves without solving.
  • Most ODEs have no closed-form solution; numerical and qualitative methods fill the gap.
Worked example

Check that y = Ce2x solves y′ = 2y, and find the solution with y(0) = 3.

  1. y′ = 2Ce2x = 2y ✓
  2. y(0) = C = 3
  3. The particular solution is y = 3e2x

Investigate with the lab. Draw the slope field and click to set initial values. Each click traces the unique solution through that point.

Common mistakeForgetting that the general solution of an nth-order equation needs n constants.

In 2 lines: ODEs relate functions to their derivatives. Conditions pick out particular solutions.

Practice questions

Answer each one in your head before you open it: recalling beats rereading.

  1. Which equation is linear?
    • y′ = y2 + 1
    • yy″ = 1
    • y″ + x2y′ + y = ex
    • y′ + sin y = 0
    • (y′)2 = x
    Show the answer

    Answer: y″ + x2y′ + y = ex. y and its derivatives appear only to the first power, multiplied by functions of x.

  2. Why does a direction field help even without solving the ODE?
    • It gives the exact solution formula
    • It only works for linear equations
    • It replaces initial conditions
    • It shows the slope at each point, so solution curves can be sketched
    • Each arrow points to where the equation has an equilibrium
    Show the answer

    Answer: It shows the slope at each point, so solution curves can be sketched. Each arrow has slope f(x, y); solutions follow the arrows.

  3. What does a slope field show for dy/dx = f(x, y)?
    • The exact solution formula
    • Only the equilibrium points
    • The area under each solution
    • The second derivative
    • The gradient a solution must have at each point
    Show the answer

    Answer: The gradient a solution must have at each point. Each short segment has gradient f(x, y), and solutions follow them.

Key terms

Order
The highest derivative in the equation: y″ + y = 0 is second order
Linear ODE
An equation linear in y and its derivatives: an(x)y(n) + … + a₀(x)y = g(x)
