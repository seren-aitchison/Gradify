Differentiability

Differentiable means a unique tangent slope; corners, jumps and vertical tangents fail; differentiable implies continuous, not conversely.

Mathematics · Calculus · about 2 minutes

What you'll be able to do

  • Decide whether a function is differentiable at a point
  • Explain the relationship between continuity and differentiability

When derivatives fail to exist

  • Corners: |x| at x = 0 has slope −1 on the left and +1 on the right, so no single derivative.
  • Discontinuities: a jump means no tangent.
  • Vertical tangents: ∛x at x = 0 has an infinitely steep tangent.
  • Wild oscillation: x sin(1/x) is continuous at 0 but not differentiable there.

Continuity versus differentiability

  • Differentiable implies continuous: if the derivative exists at a, f is continuous at a.
  • Continuous doesn't imply differentiable: |x| is continuous everywhere but not differentiable at 0.
  • Weierstrass (1872) found a function continuous everywhere and differentiable nowhere.
  • Piecewise functions are differentiable at a join only if the values and the slopes match.
Worked example

f(x) = x2 for x ≤ 1 and ax + b for x > 1. Find a and b so that f is differentiable at x = 1.

  1. Continuity: 1 = a + b
  2. Slopes must match: 2x = 2 at x = 1, so a = 2
  3. Then b = −1: f(x) = 2x − 1 for x > 1

Investigate with the lab. Choose |x| and set the point to 0. Shrink h with positive and negative values and see the secant gradients refuse to agree.

Common mistakeAssuming that a continuous function must be differentiable.

In 2 lines: Differentiable functions are smooth. Continuity is necessary but not sufficient.

Practice questions

Answer each one in your head before you open it: recalling beats rereading.

  1. Where is f(x) = |x + 2| not differentiable?
    • At x = 0
    • At x = 2
    • At x = −2
    • Nowhere
    • Everywhere
    Show the answer

    Answer: At x = −2. The graph has a corner where x + 2 = 0, so the slope jumps from −1 to 1.

  2. Which statement about continuity and differentiability is true?
    • Every continuous function is differentiable
    • |x| is differentiable at 0
    • A jump discontinuity can still be differentiable
    • Every differentiable function is continuous
    • ∛x has derivative 0 at x = 0
    Show the answer

    Answer: Every differentiable function is continuous. Differentiability at a point forces continuity there; the converse fails, as |x| shows.

  3. Why is |x| continuous but not differentiable at 0?
    • Its graph has a gap at 0, so neither property holds
    • Its gradient is infinite at 0, like a vertical tangent
    • It isn't defined at 0, so it can't be differentiated
    • It is differentiable at 0, with derivative 0 there
    • Its graph has no gap, but the gradient jumps from −1 to +1 at a corner
    Show the answer

    Answer: Its graph has no gap, but the gradient jumps from −1 to +1 at a corner. Continuity needs no break; differentiability needs a single tangent, which a corner lacks.

Key terms

Differentiable at a
The limit limh→0 (f(a + h) − f(a))/h exists
Cusp
A sharp point where the slopes from either side approach ±∞ in opposite directions
