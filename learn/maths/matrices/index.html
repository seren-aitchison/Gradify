Matrices

An m × n matrix has m rows and n columns; know the special types; matrices represent systems, maps, data and networks.

Mathematics · Linear Algebra and Matrices · about 2 minutes

What you'll be able to do

  • Describe matrices by size and entries, and recognise special types
  • Use matrices to represent systems and data

Special matrices

  • Square, diagonal, upper and lower triangular.
  • Zero matrix, identity matrix.
  • Symmetric (Aᵀ = A) and skew-symmetric (Aᵀ = −A).
  • Row and column vectors are 1 × n and n × 1 matrices.

What matrices represent

  • Systems: the coefficient matrix of 2x + 3y = 5, x − y = 1 is [[2, 3], [1, −1]].
  • Linear maps: rotations, reflections and projections act by multiplication.
  • Data tables: rows as cases, columns as variables; images as pixel arrays.
  • Networks: adjacency matrices of graphs (School 15).

Notation

  • Capital letters for matrices, aij for entries.
  • The size must match for operations: check before calculating.
Worked example

Write the system 2x + 3y − z = 4, x − y + 2z = 0 as a matrix equation, and give the size of the coefficient matrix.

  1. Coefficients: [[2, 3, −1], [1, −1, 2]]
  2. Ax = b with x = (x, y, z) and b = (4, 0)
  3. A is 2 × 3: 2 equations, 3 unknowns

Investigate with the lab. Change one entry at a time and watch where the unit vectors i and j go: the columns of the matrix are their images.

Common mistakeWriting the size as columns × rows.

In 2 lines: Matrices organise numbers in rows and columns. They represent systems, maps and data.

Practice questions

Answer each one in your head before you open it: recalling beats rereading.

  1. Which matrix is upper triangular?
    • [[1, 0], [2, 3]]
    • [[1, 2], [0, 3]]
    • [[0, 1], [1, 0]]
    • [[1, 2], [3, 4]]
    • [[0, 0], [1, 0]]
    Show the answer

    Answer: [[1, 2], [0, 3]]. Upper triangular means every entry below the main diagonal is zero, as in [[1, 2], [0, 3]].

  2. In [[5, 2, 7], [1, 9, 4]], what is a₂₃?
    • 7
    • 9
    • 4
    • 2
    • 1
    Show the answer

    Answer: 4. a₂₃ is the entry in row 2, column 3, which is 4.

  3. For the matrix [[2, 1], [0, 3]], where does the unit vector j = (0, 1) go?
    • To (2, 0), the first column
    • To (0, 1), unchanged
    • To (3, 1)
    • To (1, 3), the second column
    • To (2, 3)
    Show the answer

    Answer: To (1, 3), the second column. A matrix sends each basis vector to the corresponding column.

Key terms

m × n matrix
A matrix with m rows and n columns; aij is the entry in row i, column j
Identity matrix
I, square with 1s on the diagonal and 0s elsewhere; AI = IA = A
