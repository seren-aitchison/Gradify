Inequalities

Reverse the inequality when multiplying or dividing by a negative; for quadratics, find the roots and sketch.

Mathematics · Algebra · about 2 minutes

What you'll be able to do

  • Solve linear and quadratic inequalities
  • Represent solution sets on number lines and in set notation

Linear inequalities

  • Solve like equations, but reverse the sign when multiplying or dividing by a negative: −3x < 12 gives x > −4.
  • 2x + 5 ≥ 11 gives x ≥ 3; on a number line, a filled circle at 3 and an arrow to the right.
  • Double inequalities: −1 < 2x + 3 ≤ 9 gives −2 < x ≤ 3. Integers satisfying it: −1, 0, 1, 2, 3.

Quadratic inequalities

  • Find the critical values by solving the equation, sketch the parabola, and read off where it's above or below the axis.
  • x2 − x − 6 < 0: roots −2 and 3; the curve is below the axis between them, so −2 < x < 3.
  • x2 − x − 6 > 0: x < −2 or x > 3 (two separate regions).
  • Set notation: {x : x < −2} ∪ {x : x > 3}.
Worked example

Solve 2x2 − 5x − 3 ≥ 0.

  1. Critical values: (2x + 1)(x − 3) = 0 gives x = −1/2 or x = 3
  2. The parabola opens upwards, so it's above or on the axis outside the roots
  3. x ≤ −1/2 or x ≥ 3
Common mistakeWriting −2 > x > 3 for "x < −2 or x > 3": no number satisfies it.

In 2 lines: Inequalities have ranges of solutions. Sketch quadratics to solve quadratic inequalities.

Practice questions

Answer each one in your head before you open it: recalling beats rereading.

  1. Solve −4x ≥ 20.
    • x ≤ −5
    • x ≥ −5
    • x ≤ 5
    • x ≥ 5
    • x ≤ −80
    Show the answer

    Answer: x ≤ −5. Dividing by −4 reverses the inequality: x ≤ −5.

  2. Solve x2 − 9 > 0.
    • −3 < x < 3
    • x < −3 or x > 3
    • x > 3
    • x > ±3
    • x > 9
    Show the answer

    Answer: x < −3 or x > 3. The parabola is above the axis outside its roots, ±3.

  3. How many integers satisfy −3 ≤ 2x + 1 < 8?
    • 5
    • 7
    • 6
    • 4
    • 11
    Show the answer

    Answer: 6. −4 ≤ 2x < 7 gives −2 ≤ x < 3.5: the integers −2, −1, 0, 1, 2, 3.

Key terms

Inequality
A statement that one quantity is less than, greater than, or at most or at least another
Critical values
The values where the two sides of an inequality are equal; for a quadratic inequality, the roots
