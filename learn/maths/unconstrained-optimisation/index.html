Unconstrained Optimisation

Minima have zero gradient and positive semidefinite Hessian; positive definite Hessian is sufficient; the discriminant classifies 2D points; convexity makes stationary points global.

Mathematics · Optimisation and Operations Research · about 2 minutes

What you'll be able to do

  • Find stationary points and classify them with the Hessian
  • State first- and second-order optimality conditions

Conditions

  • First-order necessary: ∇f(x*) = 0 at a local minimum.
  • Second-order necessary: H(x*) positive semidefinite.
  • Second-order sufficient: ∇f = 0 and H positive definite give a strict local minimum.
  • For convex f, any stationary point is a global minimum.

Classifying in two variables

  • D = fxxfyy − fxy2.
  • D > 0 and fxx > 0: minimum. D > 0 and fxx < 0: maximum.
  • D < 0: saddle point. D = 0: test inconclusive.
  • In general use the signs of the Hessian's eigenvalues.

In practice

  • Closed-form solutions are rare; iterative methods are used (see Algorithms).
  • Least squares: minimise ‖Ax − b‖2, giving the normal equations AᵀAx = Aᵀb.
  • Rosenbrock's function is a classic hard test, with a curved narrow valley.
  • Scaling variables well makes problems easier.
Worked example

Find and classify the stationary points of f(x, y) = x2 + xy + y2 − 3x.

  1. ∇f = (2x + y − 3, x + 2y) = 0 gives x = 2, y = −1
  2. Hessian [[2, 1], [1, 2]] has D = 4 − 1 = 3 > 0 and fxx = 2 > 0
  3. So (2, −1) is a minimum, with f = 4 − 2 + 1 − 6 = −3

Investigate with the lab. Start descent from several points on the bowl-shaped function and confirm every run ends at the same stationary point.

Common mistakeConcluding a point is a minimum from ∇f = 0 alone.

In 2 lines: Gradients find candidates. Hessians classify them.

Practice questions

Answer each one in your head before you open it: recalling beats rereading.

  1. For f(x, y) = x2 − y2, what kind of point is the origin?
    • A strict local minimum of f
    • A saddle point, with D = −4 < 0
    • A strict local maximum of f
    • A global minimum of the function
    • Not a stationary point at all
    Show the answer

    Answer: A saddle point, with D = −4 < 0. The Hessian diag(2, −2) has eigenvalues of both signs, so f rises one way and falls the other.

  2. Why is a stationary point of a convex function a global minimum?
    • Convex functions have no stationary points, so the question never arises in practice
    • Convex functions are always linear, so every point has the same objective value
    • Convexity puts the graph above every tangent plane, so the flat tangent at that point lies below all values
    • Every stationary point of a convex function is a maximum, never a minimum
    • It is only a local minimum; convexity says nothing about other regions
    Show the answer

    Answer: Convexity puts the graph above every tangent plane, so the flat tangent at that point lies below all values. f(y) ≥ f(x) + ∇f(x)ᵀ(y − x) = f(x) when ∇f(x) = 0.

  3. At a minimum found by gradient descent on a smooth function, what is the gradient?
    • Equal to the learning rate
    • Always positive
    • Undefined
    • Zero (approximately, within the stopping tolerance)
    • Equal to the function value
    Show the answer

    Answer: Zero (approximately, within the stopping tolerance). The first-order condition ∇f = 0 holds at any interior minimum.

Key terms

Stationary point
A point where the gradient ∇f(x) = 0
Hessian matrix
The matrix of second partial derivatives, Hij = ∂2f/∂xi∂xj
