Indefinite Integrals

Raise the power by one and divide by the new power; ∫ 1/x = ln|x|; always add c; check by differentiating.

Mathematics · Calculus · about 2 minutes

What you'll be able to do

  • Integrate powers of x and standard functions
  • Use a boundary condition to find the constant of integration

Standard integrals

∫ xn dx = xn+1/(n + 1) + c (n ≠ −1); ∫ 1/x dx = ln|x| + c
∫ ekx dx = ekx/k + c; ∫ sin kx dx = −cos(kx)/k + c; ∫ cos kx dx = sin(kx)/k + c
  • Integrate term by term: ∫ (6x2 − 4x + 3) dx = 2x3 − 2x2 + 3x + c.
  • Rewrite roots and reciprocals first: ∫ 3/√x dx = ∫ 3x−1/2 dx = 6x1/2 + c.
  • ∫ sec2 x dx = tan x + c.

Finding c

  • If dy/dx = 3x2 − 2 and the curve passes through (1, 4): y = x3 − 2x + c, so 4 = 1 − 2 + c and c = 5.
  • Check any integral by differentiating your answer.
Worked example

Find ∫ (x3 + 2)/x2 dx.

  1. Split: ∫ (x + 2x−2) dx
  2. = x2/2 + 2x−1/(−1) + c
  3. = x2/2 − 2/x + c
  • Integrate expanded forms: ∫ (x + 1)2 dx = ∫ (x2 + 2x + 1) dx = x3/3 + x2 + x + c.
  • ∫ ax dx = ax/ln a + c.
  • There's no product rule for integrals: ∫ fg dx isn't ∫ f dx × ∫ g dx.
  • ∫ f′(x)/f(x) dx = ln|f(x)| + c is a standard pattern.
Common mistakeIntegrating 1/x as x0/0: the power rule fails for n = −1.

In 2 lines: Indefinite integrals are families of antiderivatives. Boundary conditions fix the constant.

Practice questions

Answer each one in your head before you open it: recalling beats rereading.

  1. What is ∫ (4x − 1) dx?
    • 4 + c
    • 2x2 − x + c
    • 2x2 − 1 + c
    • 4x2 − x + c
    • x2 − x + c
    Show the answer

    Answer: 2x2 − x + c. 4x integrates to 2x2, −1 integrates to −x, plus the constant c.

  2. dy/dx = 2x and y = 7 when x = 2. What is y?
    • x2 + 7
    • x2 − 3
    • x2 + 3
    • 2x2 − 1
    • x2
    Show the answer

    Answer: x2 + 3. y = x2 + c, and 7 = 4 + c gives c = 3.

  3. What is ∫ 1/(3x) dx?
    • ln|3x|/3x + c
    • 3 ln|x| + c
    • x0/0 + c
    • (1/3) ln|x| + c
    • ln|x|/x + c
    Show the answer

    Answer: (1/3) ln|x| + c. 1/(3x) = (1/3) × 1/x, and ∫ 1/x dx = ln|x|.

Key terms

Antiderivative
A function F with F′(x) = f(x)
Constant of integration
The arbitrary constant c in an indefinite integral
