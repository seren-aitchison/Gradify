Limits

Substitute if possible; for 0/0 factorise, rationalise or use standard limits; compare left and right limits.

Mathematics · Calculus · about 2 minutes

What you'll be able to do

  • Evaluate limits by substitution, factorising and standard results
  • Interpret one-sided limits and limits at infinity

Evaluating limits

  • If f is continuous at a, substitute: limx→2 (x2 + 1) = 5.
  • 0/0 forms: factorise and cancel: limx→3 (x2 − 9)/(x − 3) = lim (x + 3) = 6.
  • Standard limits: limx→0 (sin x)/x = 1 (x in radians); limh→0 (eh − 1)/h = 1.
  • At infinity, divide by the highest power: limx→∞ (3x2 + 1)/(x2 − 5) = 3.

One-sided limits and formal definition

  • limx→0⁺ 1/x = +∞ and limx→0⁻ 1/x = −∞, so limx→0 1/x doesn't exist.
  • The limit exists only if the left and right limits are equal.
  • Formally: for every ε > 0 there's δ > 0 such that 0 < |x − a| < δ implies |f(x) − L| < ε (School 9).
Worked example

Find limx→4 (√x − 2)/(x − 4).

  1. Substituting gives 0/0, so rewrite x − 4 = (√x − 2)(√x + 2)
  2. (√x − 2)/((√x − 2)(√x + 2)) = 1/(√x + 2)
  3. As x → 4, this approaches 1/(2 + 2) = 1/4
  • Limits needn't equal the function's value: f could even be undefined at a.

Investigate with the lab. Shrink h towards 0 from both sides and watch the secant gradient approach a single value. Then try |x| at x = 0, where the two sides disagree.

Common mistakeConcluding that a 0/0 limit is 0, 1 or undefined without further work.

In 2 lines: Limits describe approaching behaviour. Indeterminate forms need algebraic work.

Practice questions

Answer each one in your head before you open it: recalling beats rereading.

  1. What is limx→∞ (5x + 2)/(2x − 1)?
    • 5/2
    • 0
    • ∞
    • −2
    • 5
    Show the answer

    Answer: 5/2. Divide top and bottom by x: (5 + 2/x)/(2 − 1/x) → 5/2.

  2. What is limx→0 (sin 3x)/x?
    • 1
    • 3
    • 0
    • 1/3
    • It doesn't exist
    Show the answer

    Answer: 3. (sin 3x)/x = 3 × (sin 3x)/(3x), and (sin u)/u → 1 as u → 0.

  3. For f(x) = |x| at x = 0, what do the secant gradients from the right and left approach?
    • 0 from both sides, since the graph touches the axis there
    • +1 from both sides, since |x| = x near 0
    • +1 from the right and −1 from the left, so the limit doesn't exist
    • Both grow without bound, since the corner is infinitely steep
    • −1 from the right and +1 from the left, so the limit is 0
    Show the answer

    Answer: +1 from the right and −1 from the left, so the limit doesn't exist. The one-sided limits differ, so the difference quotient has no limit at 0.

Key terms

Limit
limx→a f(x) = L means f(x) gets arbitrarily close to L as x gets close to a (but not equal to a)
Indeterminate form
An expression like 0/0 or ∞/∞ whose value can't be decided without further work
