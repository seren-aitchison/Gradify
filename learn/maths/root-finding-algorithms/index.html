Root-Finding Algorithms

Bracketing methods are safe and slow; open methods are fast but can fail; Brent's hybrid gives both; multiplicity, stopping rules and systems need care.

Mathematics · Numerical Analysis and Scientific Computing · about 2 minutes

What you'll be able to do

  • Compare bracketing and open root-finding methods
  • Choose a method by robustness, speed and available derivatives

The methods

  • Bisection: linear, guaranteed if f is continuous with a sign change.
  • Newton: quadratic, needs f′ and a good start.
  • Secant: order about 1.618, no derivative needed.
  • Fixed-point iteration: linear when |g′| < 1.

Hybrid methods

  • Brent's method combines bisection, secant and inverse quadratic interpolation.
  • Guaranteed convergence with fast local speed.
  • MATLAB's fzero and SciPy's brentq use it.

Practical issues

  • Multiple roots slow Newton to linear convergence.
  • Stopping criteria: |f(x)| small, step small, or both.
  • Polynomials: companion-matrix eigenvalues find all roots.
  • Systems of equations: multivariate Newton with Jacobians.
Worked example

f(x) = x3 − 2x − 5 has f(2) = −1 and f(3) = 16. Which methods can start from this information?

  1. The sign change brackets a root in [2, 3], so bisection, false position and Brent can start
  2. Newton can start from x₀ = 2 using f′(x) = 3x2 − 2
  3. Newton converges rapidly to the root ≈ 2.0946 (Wallis's classic example)

Investigate with the lab. Solve the same equation with bisection, Newton and secant, and count the iterations each needs for 10 correct decimals.

Common mistakeUsing Newton far from a root without safeguards.

In 2 lines: Bracket for safety, open for speed. Hybrids combine both.

Practice questions

Answer each one in your head before you open it: recalling beats rereading.

  1. Which method is guaranteed to converge for a continuous function with a sign change?
    • Newton's method
    • The secant method
    • Fixed-point iteration
    • Steffensen's method
    • Bisection
    Show the answer

    Answer: Bisection. Bisection always keeps a root inside a halving bracket.

  2. Why does Newton's method slow down at a double root?
    • f′ also vanishes at the root, so convergence drops from quadratic to linear
    • Double roots don't exist for smooth functions, so it never happens
    • Newton's method never converges to any root, whatever its multiplicity
    • The derivative becomes infinite at a double root, so steps vanish
    • It speeds up at double roots, since the function is flatter there
    Show the answer

    Answer: f′ also vanishes at the root, so convergence drops from quadratic to linear. With f′(x*) = 0, the error is only roughly halved each step.

  3. Which method in the lab is guaranteed to converge once it has a valid bracket?
    • Newton–Raphson
    • Bisection
    • The secant method
    • All three always converge
    • None of them
    Show the answer

    Answer: Bisection. Bisection keeps a sign change inside a shrinking interval.

Key terms

Bracketing method
A method that keeps an interval [a, b] with f(a) and f(b) of opposite signs, so a root stays inside
Open method
A method using one or two points without a bracket, such as Newton or secant, which may diverge
