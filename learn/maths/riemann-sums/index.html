Riemann Sums

Rectangles of width Δx approximate the area; the integral is the limit as Δx → 0.

Mathematics · Calculus · about 2 minutes

What you'll be able to do

  • Calculate left, right and midpoint Riemann sums
  • Explain how the definite integral is defined as a limit of sums

Building the sum

  • Split [a, b] into n strips of width Δx = (b − a)/n.
  • Choose a height in each strip: the left endpoint, right endpoint or midpoint.
  • Area ≈ Σ f(xi) Δx.
  • For an increasing function, left sums underestimate and right sums overestimate.

The limit

∫ab f(x) dx = limn→∞ Σi=1n f(xi) Δx
  • The ∫ sign is an elongated S for "sum", and dx comes from Δx.
  • For ∫01 x2 dx with right endpoints: Σ (i/n)2(1/n) = (n + 1)(2n + 1)/(6n2) → 1/3.
Worked example

Estimate ∫02 x2 dx with four strips and right endpoints.

  1. Δx = 0.5; right endpoints 0.5, 1, 1.5, 2
  2. Heights 0.25, 1, 2.25, 4, which sum to 7.5
  3. Estimate = 7.5 × 0.5 = 3.75 (the exact value is 8/3 ≈ 2.67: an overestimate, since x2 is increasing)
  • Midpoint sums are usually much more accurate than left or right sums.
  • Riemann sums are how computers estimate integrals (School 19).

Investigate with the lab. Approximate the area with left rectangles and increase n until you're within 1% (the lab's challenge). Compare how fast left and midpoint sums improve.

Common mistakeForgetting to multiply the sum of heights by the strip width.

In 2 lines: Riemann sums approximate areas with rectangles. The definite integral is their limit.

Practice questions

Answer each one in your head before you open it: recalling beats rereading.

  1. With n strips on [a, b], what is the width of each?
    • n/(b − a)
    • b − a
    • (b − a)/n
    • (a + b)/n
    • 1/n
    Show the answer

    Answer: (b − a)/n. The interval's length divided equally into n parts.

  2. For a decreasing function, how does a right Riemann sum compare with the integral?
    • It overestimates
    • It's exact
    • It's always zero
    • It underestimates
    • It depends on n only
    Show the answer

    Answer: It underestimates. Right endpoints of a decreasing function are the lowest points in each strip.

  3. For an increasing function, how does the left Riemann sum compare with the exact integral?
    • It overestimates, since each strip uses its highest value
    • It is always exact for increasing functions
    • It depends only on n, not on the function
    • It always gives zero for increasing functions
    • It underestimates, since each rectangle uses the lowest value on its strip
    Show the answer

    Answer: It underestimates, since each rectangle uses the lowest value on its strip. On an increasing function the left endpoint is the minimum of each strip.

Key terms

Riemann sum
Σ f(xi*) Δx, the sum of rectangle areas approximating ∫ab f(x) dx
Partition
A division of [a, b] into subintervals of width Δx
