Quadratic Equations

Rearrange to = 0, factorise, set each factor to zero; never divide by the unknown; check solutions fit the context.

Mathematics · Algebra · about 2 minutes

What you'll be able to do

  • Solve quadratic equations by factorising
  • Interpret the solutions as roots of a graph

Solving by factorising

  • Rearrange to = 0, factorise, then use the fact that if a product is zero, one factor is zero.
  • x2 − x − 20 = 0 → (x − 5)(x + 4) = 0 → x = 5 or x = −4.
  • x2 = 6x → x2 − 6x = 0 → x(x − 6) = 0 → x = 0 or 6. Don't divide by x: you'd lose x = 0.
  • 9x2 = 4 → x2 = 4/9 → x = ±2/3: remember both roots.

Graphs and roots

  • The graph of y = ax2 + bx + c is a parabola; its x-intercepts are the roots.
  • Two roots: crosses the x-axis twice; one repeated root: touches it; no real roots: misses it.
  • Many problems lead to quadratics (areas, projectiles, profit); reject solutions that don't fit the context (a negative length).
Worked example

A rectangle has length 3 cm more than its width and area 40 cm2. Find its dimensions.

  1. w(w + 3) = 40, so w2 + 3w − 40 = 0
  2. (w + 8)(w − 5) = 0, so w = −8 or w = 5
  3. A width can't be negative, so the rectangle is 5 cm by 8 cm

Common mistakeSolving x2 = 6x by dividing by x and losing the solution x = 0.

In 2 lines: Quadratics are solved by making them equal zero. Roots are where the parabola meets the x-axis.

Practice questions

Answer each one in your head before you open it: recalling beats rereading.

  1. Solve x2 + 2x − 15 = 0.
    • x = 3 or x = −5
    • x = −3 or x = 5
    • x = 15 or x = −1
    • x = 3 only
    • x = −2 or x = 15
    Show the answer

    Answer: x = 3 or x = −5. It factorises as (x + 5)(x − 3) = 0, so x = −5 or x = 3.

  2. Solve 2x2 = 18.
    • x = 3
    • x = 3 or x = −3
    • x = 9
    • x = ±9
    • x = 4.5
    Show the answer

    Answer: x = 3 or x = −3. Divide by 2 to get x2 = 9, so x = ±3: both the positive and negative roots count.

  3. Why is it wrong to solve x2 = 5x by dividing both sides by x?
    • It gives the wrong positive root
    • Division isn't allowed in equations
    • It loses the solution x = 0
    • It makes the equation linear
    • It doubles the solutions
    Show the answer

    Answer: It loses the solution x = 0. Dividing by x assumes x ≠ 0, but x = 0 is a solution.

Key terms

Quadratic equation
An equation of the form ax2 + bx + c = 0 with a ≠ 0
Root
A solution of an equation; the x-coordinate where a graph crosses the x-axis
