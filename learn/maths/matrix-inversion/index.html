Matrix Inversion

Inverses exist iff det ≠ 0; use the 2 × 2 formula or Gauss–Jordan; (AB)−1 = B−1A−1; solve systems by elimination, not inversion.

Mathematics · Linear Algebra and Matrices · about 2 minutes

What you'll be able to do

  • Find inverses of 2 × 2 matrices and by Gauss–Jordan elimination
  • Use the rules for inverses and know when inverses exist

Finding inverses

  • 2 × 2: [[a, b], [c, d]]−1 = (1/(ad − bc))[[d, −b], [−c, a]].
  • Gauss–Jordan: row reduce [A | I] to [I | A−1].
  • Adjugate formula A−1 = adj(A)/det A (useful in theory, slow in practice).

Rules

  • (AB)−1 = B−1A−1; (Aᵀ)−1 = (A−1)ᵀ; det(A−1) = 1/det A.
  • A is invertible ⇔ det A ≠ 0 ⇔ rank n ⇔ Ax = 0 has only x = 0 ⇔ columns independent.

In practice

  • Solving Ax = b by computing A−1b is slower and less accurate than elimination (LU).
  • Ill-conditioned matrices (nearly singular) amplify errors.
  • Inverses are useful for theory, small systems and change of basis.
Worked example

Find the inverse of [[2, 1], [5, 3]].

  1. det = 2 × 3 − 1 × 5 = 1
  2. Swap the diagonal, negate the off-diagonal: [[3, −1], [−5, 2]]
  3. Divide by det 1: inverse [[3, −1], [−5, 2]] (check: product is I)
  • Check an inverse by multiplying: AA−1 should be I.

Investigate with the lab. Make the determinant 0 and notice that different points land on the same image: the transformation can't be undone, so no inverse exists.

Common mistakeWriting (AB)−1 = A−1B−1.

In 2 lines: Inverses undo matrices. They exist only for non-zero determinants.

Practice questions

Answer each one in your head before you open it: recalling beats rereading.

  1. Which matrix is singular?
    • [[1, 2], [3, 4]]
    • [[1, 0], [0, 1]]
    • [[2, 4], [1, 2]]
    • [[0, 1], [1, 0]]
    • [[3, 1], [1, 3]]
    Show the answer

    Answer: [[2, 4], [1, 2]]. det [[2, 4], [1, 2]] = 2 × 2 − 4 × 1 = 0, so it has no inverse.

  2. Why is solving Ax = b by computing A−1b usually avoided numerically?
    • Inverses never exist
    • It gives the wrong answer exactly
    • It needs complex numbers
    • Elimination is cheaper and less sensitive to rounding
    • It isn't avoided
    Show the answer

    Answer: Elimination is cheaper and less sensitive to rounding. Forming A−1 costs more and amplifies rounding errors.

  3. Why does a matrix with determinant 0 have no inverse?
    • All of its entries must be zero, so there is nothing to invert
    • Determinants have no bearing on whether a matrix is invertible
    • Every square matrix has an inverse, including singular ones
    • Its inverse is the zero matrix, which undoes nothing useful
    • Different inputs land on the same output, so the map can't be undone
    Show the answer

    Answer: Different inputs land on the same output, so the map can't be undone. Area collapses to zero, so the map isn't one-to-one.

Key terms

Inverse matrix
A−1 with AA−1 = A−1A = I
Singular matrix
A square matrix with determinant 0, which has no inverse
