Factor Theorem

f(a) = 0 ⇔ (x − a) is a factor; try divisors of the constant; then divide and factorise the quadratic.

Mathematics · Algebra · about 2 minutes

What you'll be able to do

  • Use the factor theorem to test and find factors
  • Factorise cubics completely

Testing for factors

  • (x − 2) is a factor of x3 − 3x2 + 4 because f(2) = 8 − 12 + 4 = 0.
  • Candidates for integer roots divide the constant term: for x3 − 7x − 6, try ±1, ±2, ±3, ±6.
  • (2x − 1) is a factor if f(1/2) = 0.

Factorising completely

  • Find one factor, divide (or equate coefficients) to get a quadratic, then factorise or solve that.
  • x3 − 7x − 6: f(−1) = −1 + 7 − 6 = 0, so (x + 1) is a factor; dividing gives x2 − x − 6 = (x − 3)(x + 2). So x3 − 7x − 6 = (x + 1)(x − 3)(x + 2).
Worked example

Show that (x − 2) is a factor of 2x3 − 5x2 − x + 6 and factorise completely.

  1. f(2) = 16 − 20 − 2 + 6 = 0, so (x − 2) is a factor
  2. Dividing: 2x3 − 5x2 − x + 6 = (x − 2)(2x2 − x − 3)
  3. 2x2 − x − 3 = (2x − 3)(x + 1), so the answer is (x − 2)(2x − 3)(x + 1)
  • Graphs help: a sketch or calculator plot suggests which values to test first.
  • Fractional roots: for 2x3 + … try ±1/2 and ±3/2 too.
Common mistakeTesting only positive values: roots are often negative.

In 2 lines: f(a) = 0 means (x − a) is a factor. One factor reduces a cubic to a quadratic.

Practice questions

Answer each one in your head before you open it: recalling beats rereading.

  1. Which is a factor of x3 − 4x2 + x + 6?
    • x + 2
    • x − 1
    • x + 3
    • x − 2
    • x − 6
    Show the answer

    Answer: x − 2. By the factor theorem, f(2) = 8 − 16 + 2 + 6 = 0, so (x − 2) is a factor.

  2. (x − 3) is a factor of x3 − 2x2 + kx − 6. What is k?
    • 1
    • −3
    • 3
    • 6
    • −1
    Show the answer

    Answer: −1. f(3) = 27 − 18 + 3k − 6 = 0 gives 3k = −3, so k = −1.

  3. Factorise x3 + x2 − 10x + 8 completely.
    • (x − 1)(x − 2)(x + 4)
    • (x + 1)(x + 2)(x − 4)
    • (x − 1)(x + 2)(x − 4)
    • (x − 2)2(x + 2)
    • (x − 1)(x2 + 2x − 8)
    Show the answer

    Answer: (x − 1)(x − 2)(x + 4). f(1) = 0, and x2 + 2x − 8 = (x − 2)(x + 4).

Key terms

Factor theorem
(x − a) is a factor of f(x) if and only if f(a) = 0
Rational root test
Any rational root p/q of a polynomial with integer coefficients has p dividing the constant term and q dividing the leading coefficient
