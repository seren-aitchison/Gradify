Random Variables

A random variable turns outcomes into numbers; list values and probabilities; indicators have expectation equal to the probability.

Mathematics · Probability · about 2 minutes

What you'll be able to do

  • Define a random variable and list its distribution
  • Distinguish discrete and continuous random variables

The idea

  • Toss three coins and let X be the number of heads: X takes values 0, 1, 2, 3 with probabilities 1/8, 3/8, 3/8, 1/8.
  • Capital X is the variable; lower-case x is a value it takes; P(X = x) is the probability of that value.
  • Discrete: countable values (counts). Continuous: any value in an interval (measurements).

Functions of random variables

  • If X is a random variable, so are 2X + 3, X2 and eX.
  • Y = g(X): find its distribution by working out which X values give each Y value.
  • Several variables on the same experiment can be combined: the total score on two dice is X₁ + X₂.

Indicators

  • An indicator IA has E(IA) = P(A).
  • Counts can be written as sums of indicators, which makes expectations easy: the expected number of fixed points in a random shuffle is 1.
  • Random variables are the bridge from probability to statistics.
Worked example

Two dice are rolled and X is the larger score. Find P(X = 6).

  1. P(X ≤ 5) means both dice are at most 5: (5/6)2 = 25/36
  2. P(X ≤ 6) = 1
  3. P(X = 6) = 1 − 25/36 = 11/36

Investigate with the lab. Treat each sample mean as a random variable: run the simulation twice with the same settings and compare the two histograms.

Common mistakeConfusing the random variable X with a particular value x.

In 2 lines: Random variables map outcomes to numbers. Discrete variables count; continuous ones measure.

Practice questions

Answer each one in your head before you open it: recalling beats rereading.

  1. Which is a discrete random variable?
    • The number of emails received in an hour
    • A person's height
    • The time to run 100 m
    • The temperature at noon
    • The mass of an apple
    Show the answer

    Answer: The number of emails received in an hour. Counts take separate, countable values, unlike measurements.

  2. Three coins are tossed and X counts heads. What is P(X ≥ 2)?
    • 3/8
    • 1/2
    • 1/8
    • 7/8
    • 3/4
    Show the answer

    Answer: 1/2. Add the probabilities of 2 and 3 heads: P(X = 2) + P(X = 3) = 3/8 + 1/8 = 1/2.

  3. Why is a sample mean a random variable?
    • It is always equal to the population mean
    • It has no distribution
    • It depends on which values happen to be sampled, so it varies from sample to sample
    • It is a fixed number
    • It only varies for normal populations
    Show the answer

    Answer: It depends on which values happen to be sampled, so it varies from sample to sample. Each new random sample gives a different mean, with its own distribution.

Key terms

Random variable
A function X from the sample space to the real numbers
Indicator variable
A variable equal to 1 if an event happens and 0 otherwise
