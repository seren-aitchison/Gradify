Linear Models

Linear regression minimises squared error via the normal equations; ridge and lasso regularise; logistic regression models probabilities through the sigmoid; coefficients are interpretable.

Mathematics · Mathematics for Machine Learning and AI · about 2 minutes

What you'll be able to do

  • Fit linear regression by least squares and interpret coefficients
  • Use logistic regression and ridge and lasso regularisation

Linear regression

  • Minimise ‖y − Xw‖2: w = (XᵀX)−1Xᵀy (normal equations).
  • Probabilistic view: Gaussian noise gives least squares as maximum likelihood.
  • Features can be non-linear transforms (polynomials, splines).

Regularisation

  • Ridge (L2): w = (XᵀX + λI)−1Xᵀy, shrinks coefficients, handles collinearity.
  • Lasso (L1): sparse solutions, feature selection.
  • Elastic net combines both.
  • λ chosen by cross-validation.

Classification

  • Logistic regression: log-odds linear in x; cross-entropy loss.
  • Decision boundary wᵀx + b = 0 is a hyperplane.
  • Coefficients: ew is an odds ratio.
  • Softmax regression for many classes.
Worked example

A logistic model has w = 2 and b = −4. Find P(y = 1) at x = 3.

  1. z = 2 × 3 − 4 = 2
  2. σ(2) = 1/(1 + e−2) = 1/(1 + 0.135)
  3. ≈ 0.881

Investigate with the lab. Add points and watch the least-squares line, which minimises the sum of squared residuals, update with each point.

Common mistakeUsing linear regression for a binary outcome, which can predict probabilities outside [0, 1].

In 2 lines: Weighted sums make strong baselines. Regularisation controls complexity.

Practice questions

Answer each one in your head before you open it: recalling beats rereading.

  1. A logistic coefficient is w = ln 3. What happens to the odds when x rises by 1?
    • They rise by 3 percentage points
    • They halve
    • They stay the same
    • They rise by ln 3
    • They triple
    Show the answer

    Answer: They triple. In logistic regression the odds ratio for a one-unit rise in x is ew = eln 3 = 3, so the odds triple.

  2. Why does ridge regression help when features are highly correlated?
    • Adding λI makes XᵀX + λI well conditioned, stabilising coefficient estimates
    • It removes the correlated features from the model before fitting
    • It increases the variance of the coefficients to explore more values
    • It ignores the data and shrinks every coefficient exactly to zero
    • It doesn't help; ridge only matters when features are independent
    Show the answer

    Answer: Adding λI makes XᵀX + λI well conditioned, stabilising coefficient estimates. Near-singular XᵀX makes ordinary least squares unstable.

  3. What does ordinary least squares minimise?
    • The sum of absolute x-values
    • The sum of squared vertical residuals
    • The number of points off the line
    • The correlation coefficient
    • The largest residual only
    Show the answer

    Answer: The sum of squared vertical residuals. OLS chooses coefficients minimising Σ(yᵢ − ŷᵢ)2.

Key terms

Logistic regression
P(y = 1 ∣ x) = σ(wᵀx + b) with sigmoid σ(z) = 1/(1 + e−z), fitted by maximising likelihood
Lasso
Least squares with an L1 penalty λΣ|wⱼ|, which sets some coefficients exactly to zero
