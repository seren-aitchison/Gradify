Initial Value Problems

IVPs specify values at one point; Picard–Lindelöf gives uniqueness for Lipschitz f; non-Lipschitz cases like y′ = 3y2/3 can have many solutions.

Mathematics · Differential Equations · about 2 minutes

What you'll be able to do

  • Solve initial value problems and apply existence and uniqueness theorems
  • Recognise cases where uniqueness fails

Existence and uniqueness

  • Picard–Lindelöf: if f is continuous and Lipschitz in y near (x₀, y₀), there's a unique solution on some interval.
  • Peano: continuity alone gives existence but not uniqueness.
  • For linear equations with continuous coefficients, solutions exist on the whole interval.

Failure of uniqueness

  • y′ = 3y2/3, y(0) = 0 has y = 0 and y = x3 (and others): f isn't Lipschitz at y = 0.
  • Physically, this would mean a system's future isn't determined by its present.

Solving

  • Find the general solution, then use the initial conditions to fix constants.
  • Second-order IVPs need two conditions (position and velocity).
  • Laplace transforms build the initial conditions in automatically (see Laplace Transforms).
Worked example

Solve y″ + y = 0 with y(0) = 1, y′(0) = 0.

  1. General solution: y = A cos x + B sin x
  2. y(0) = A = 1; y′(0) = B = 0
  3. y = cos x, unique since the equation is linear with constant coefficients

Investigate with the lab. Click different starting points on the same slope field and see that each initial value gives a different solution curve.

Common mistakeAssuming every IVP has a unique solution.

In 2 lines: IVPs fix solutions by starting values. Lipschitz conditions ensure uniqueness.

Practice questions

Answer each one in your head before you open it: recalling beats rereading.

  1. Which IVP is guaranteed a unique solution near x = 0?
    • y′ = x2 + y, y(0) = 1
    • y′ = 3y2/3, y(0) = 0
    • y′ = √|y|, y(0) = 0
    • y′ = y1/3, y(0) = 0
    • None of them
    Show the answer

    Answer: y′ = x2 + y, y(0) = 1. x2 + y is smooth, so Lipschitz in y; the others fail at y = 0.

  2. Why does determinism in physics need uniqueness theorems?
    • It guarantees all solutions are periodic
    • Uniqueness means the present state determines one future
    • It makes equations linear
    • It removes the need for initial conditions
    • It doesn't need them
    Show the answer

    Answer: Uniqueness means the present state determines one future. Without uniqueness, the same initial state could evolve in different ways.

  3. Why does an initial value problem need a starting value?
    • It doesn't need one
    • The ODE has no solutions otherwise
    • A first-order ODE has a family of solutions, and the initial value selects one
    • It fixes the step size
    • It makes the solution linear
    Show the answer

    Answer: A first-order ODE has a family of solutions, and the initial value selects one. The general solution has an arbitrary constant fixed by y(x₀).

Key terms

Initial value problem
An ODE with conditions such as y(x₀) = y₀ (and y′(x₀) = y₁ for second order) at one point
Lipschitz condition
|f(x, y₁) − f(x, y₂)| ≤ L|y₁ − y₂|, guaranteeing uniqueness
