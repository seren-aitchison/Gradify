Type I and Type II Errors

Type I errors are false positives (controlled by α); Type II errors are false negatives (controlled by power); there is a trade-off for a fixed sample.

Psychology · Statistics · about 2 minutes

What you'll be able to do

  • Define Type I and Type II errors
  • Explain how α and power relate to each error
  • Analyse the consequences of each error in different research contexts

Two errors

  • Type I error (false positive): rejecting a true null hypothesis, concluding there's an effect when there isn't. Its probability is α.
  • Type II error (false negative): failing to reject a false null hypothesis, missing a real effect. Its probability is β (1 − power).

The trade-off

Making α stricter (say .01) reduces Type I errors but, for a given sample, increases Type II errors. Increasing the sample reduces Type II errors without raising Type I errors. With many tests, Type I errors accumulate: with 20 independent tests of true nulls at α = .05, the chance of at least one false positive is 1 − 0.95²⁰ ≈ 64%. Corrections such as Bonferroni (dividing α by the number of tests) control this.

Worked example

Which error matters more?

  1. Testing a new drug's harmful side effect: a Type II error (missing real harm) could be dangerous.
  2. Claiming a new therapy works: a Type I error could lead to an ineffective therapy being adopted.
  3. The acceptable balance depends on the costs of each mistake.

Preregistering a primary outcome, and treating other outcomes as secondary, is a simple way to stop false positives from accumulating across many measures.

Investigate with the lab. Run a thousand studies with no real effect and count how often p falls below 0.05.

Common mistakeThinking a significant result means a Type I error is impossible. At α = .05, about 1 in 20 tests of true nulls will be significant by chance.

In 2 lines: Type I errors are false positives (α); Type II errors are false negatives (β). Stricter α reduces Type I errors but raises Type II errors unless the sample grows.

Practice questions

Answer each one in your head before you open it: recalling beats rereading.

  1. The probability of a Type I error equals…
    • β
    • Power
    • The effect size
    • α
    Show the answer

    Answer: α. α is the rate of false positives when the null is true.

  2. A study concludes a new teaching method works, but the effect isn't real. This is…
    • A Type I error
    • A Type II error
    • Correct rejection
    • Low ecological validity
    Show the answer

    Answer: A Type I error. Concluding there is an effect when there isn't is a false positive: a Type I error.

  3. In a study of whether a medicine causes a serious side effect, which error is most worrying?
    • A Type I error, a false alarm
    • A Type II error, missing real harm
    • Neither type of error
    • Errors in the literature review
    Show the answer

    Answer: A Type II error, missing real harm. Missing real harm could put patients at risk, so high power matters.

  4. What is a Type I error?
    • Accepting the null hypothesis when it is false
    • Using the wrong statistical test
    • Rejecting the null hypothesis when it is true
    • Choosing too small a sample
    Show the answer

    Answer: Rejecting the null hypothesis when it is true. A false positive; at α = 0.05 it happens about 5% of the time when there is no effect.

Key terms

Type I error
Rejecting a true null hypothesis: a false positive
Type II error
Failing to reject a false null hypothesis: a false negative
Bonferroni correction
Dividing α by the number of tests to control false positives
