Sensory Memory

Sensory memory briefly holds a large, modality-specific copy of input; attention selects what passes to short-term memory.

Psychology · Cognitive Psychology · about 2 minutes

What you'll be able to do

  • Describe the capacity, duration and coding of sensory memory
  • Explain Sperling's whole-report and partial-report findings
  • Evaluate the role of sensory memory in the multi-store model

A brief sensory record

In Atkinson and Shiffrin's (1968) multi-store model, information first enters sensory registers, one for each sense. Visual sensory memory is iconic memory; auditory sensory memory is echoic memory. These stores hold large amounts of raw, unprocessed information in its sensory form (modality-specific coding), but only very briefly.

Iconic memory lasts around a quarter to half a second; echoic memory lasts longer, around 2 to 4 seconds, which helps us make sense of speech, where the meaning of a sound depends on what follows. Only information that receives attention passes on to short-term memory; the rest decays.

Sperling's experiments

Worked example

Whole report versus partial report

  1. Sperling (1960) flashed a grid of 12 letters (three rows of four) for 50 milliseconds.
  2. In whole report, participants recalled about 4 letters, suggesting little was stored.
  3. In partial report, a tone after the flash signalled which row to report. Participants recalled about 3 of the 4 letters in any cued row, implying around 9 of 12 letters were briefly available.
  4. When the tone was delayed by about 1 second, partial-report performance fell to whole-report levels: the icon had faded.

The partial-report advantage shows that sensory memory holds much more than we can report, but that it fades before most of it can be read out.

Common mistakeAssuming sensory memory is the same as short-term memory. It is much briefer, larger and unprocessed.

In 2 lines: Sensory registers hold large, raw copies of input for a fraction of a second (iconic) to a few seconds (echoic). Sperling's partial-report technique showed far more is briefly stored than can be reported.

Practice questions

Answer each one in your head before you open it: recalling beats rereading.

  1. Roughly how long does iconic memory last?
    • About 30 seconds
    • Under a second
    • Several minutes
    • A lifetime
    Show the answer

    Answer: Under a second. The visual icon fades within about half a second.

  2. In Sperling's partial-report condition, participants recalled about 3 letters from any cued row of 4. What did this imply?
    • Only 3 letters were stored
    • Rows were not seen
    • About 9 of 12 letters were available
    • Tones improve eyesight
    Show the answer

    Answer: About 9 of 12 letters were available. Recall from any cued row implies most of the display was briefly held.

  3. Why is echoic memory's longer duration useful?
    • Sounds are larger than images
    • Hearing has no attention
    • Echoes are louder
    • Speech unfolds over time
    Show the answer

    Answer: Speech unfolds over time. Holding sounds for a few seconds lets later sounds clarify earlier ones.

Key terms

Iconic memory
Brief visual sensory memory
Echoic memory
Brief auditory sensory memory, lasting a few seconds
Partial report
Reporting only a cued part of a briefly shown display
