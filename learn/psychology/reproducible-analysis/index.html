Reproducible Analysis

Reproducible analysis scripts every step from raw data to results, so others can check and build on the work.

Psychology · Statistics · about 2 minutes

What you'll be able to do

  • Define reproducibility and distinguish it from replication
  • Describe practices that make an analysis reproducible
  • Evaluate the benefits and costs of reproducible workflows

Reproducible versus replicable

Reproducibility means getting the same results from the same data and analysis. Replicability means getting consistent results from new data. Reproducibility is the minimum standard: if an analysis can't be reproduced, its results can't be checked.

Practices

  • Script the analysis in code (R, Python) or saved syntax rather than point-and-click steps.
  • Never edit raw data: keep it untouched and record every cleaning step in code.
  • Version control (such as Git) records every change.
  • Document variables, exclusions and decisions.
  • Share data (where ethical), code and software versions.
Worked example

A reproducible workflow

  1. Raw survey data are saved read-only.
  2. A script cleans the data (removing failed attention checks as preregistered), computes scale scores and runs the planned t-test.
  3. The script, a codebook and the anonymised data are shared; another researcher reruns it and gets identical results.

Benefits and costs

Benefits: errors are easier to find and fix, analyses can be updated quickly, and others can verify and reuse the work. Costs: learning to code and documenting take time, and incentives don't always reward it. Studies that tried to reproduce published results from shared data have found many could not be reproduced exactly, often because of undocumented steps.

Common mistakeRelying on memory of which menu options were clicked. Unscripted analyses are hard even for the original researcher to reproduce.

In 2 lines: Reproducibility means the same data and code give the same results. Scripting, documenting, version control and sharing make analyses reproducible.

Practice questions

Answer each one in your head before you open it: recalling beats rereading.

  1. Which practice most directly supports reproducibility?
    • Scripting the analysis in code
    • Using a bigger sample
    • Choosing a one-tailed test
    • Increasing α
    Show the answer

    Answer: Scripting the analysis in code. A script records every step so the analysis can be rerun.

  2. A researcher deletes outliers by hand in a spreadsheet and saves over the original file. What is the main problem?
    • The sample becomes too large
    • The deletions can't be traced or reproduced
    • The p-value becomes invalid automatically
    • The study can't be published
    Show the answer

    Answer: The deletions can't be traced or reproduced. Unrecorded edits to raw data make results impossible to check.

  3. Why might a published result fail to reproduce from the authors' own shared data?
    • The data were too reliable
    • The sample was too large
    • Undocumented cleaning or analysis steps
    • The study was preregistered
    Show the answer

    Answer: Undocumented cleaning or analysis steps. Hidden steps between raw data and results are a common cause.

Key terms

Reproducibility
Obtaining the same results from the same data and analysis
Version control
