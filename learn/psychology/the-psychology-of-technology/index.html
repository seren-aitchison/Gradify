The Psychology of Technology

The internet may act as transactive memory, though findings have not all replicated; multitasking and interruptions have costs; cognitive offloading has benefits and trade-offs.

Psychology · Contemporary Psychology · about 2 minutes

What you'll be able to do

  • Describe research on technology and memory
  • Explain how technology affects attention and multitasking
  • Evaluate claims about technology's effects on the mind

Technology and memory

Sparrow, Liu and Wegner (2011) reported that people who expected information to be saved on a computer were less likely to remember it, but more likely to remember where it was stored, suggesting the internet acts as transactive memory, a shared external memory. Some of their findings did not replicate in a large replication project (Camerer et al., 2018), showing the need for caution.

Attention and multitasking

Research on media multitasking suggests switching between tasks has costs in speed and accuracy, because attention is limited. Notifications interrupt work and can take time to recover from. Some studies have linked heavy media multitasking with poorer performance on attention tasks, though causation and effect size are debated.

Worked example

Cognitive offloading

  1. Cognitive offloading means using external tools, such as calendars, maps or phones, to reduce mental effort.
  2. Offloading can free up memory for other tasks and improve performance.
  3. But relying on tools may reduce practice of skills such as navigation or remembering phone numbers.

Evaluation

Technology changes how cognitive work is shared between people and tools, which isn't necessarily harmful. Claims that technology "rewires" or damages the brain are often exaggerated. Replication failures show that striking findings need confirmation.

Common mistakeAssuming technology simply damages the mind. It changes how cognition is shared with tools.

In 2 lines: The internet may act as transactive memory; some findings didn't replicate. Multitasking has costs; offloading has benefits and trade-offs.

Practice questions

Answer each one in your head before you open it: recalling beats rereading.

  1. Using a phone calendar to remember appointments is an example of…
    • Media multitasking
    • Transactive memory loss
    • Overfitting
    • Cognitive offloading
    Show the answer

    Answer: Cognitive offloading. Storing information in an external tool to reduce mental effort is cognitive offloading.

  2. A student answering messages while writing an essay takes longer and makes more errors. This illustrates…
    • Task-switching costs
    • Cognitive offloading
    • Transactive memory
    • Specification curves
    Show the answer

    Answer: Task-switching costs. Limited attention makes switching costly.

  3. Why are claims that technology "damages the brain" often criticised?
    • They are always fully proven by research
    • They exaggerate evidence and ignore shared cognition
    • Technology has no effects on people at all
    • Brains never change in any way over time
    Show the answer

    Answer: They exaggerate evidence and ignore shared cognition. Effects are more nuanced than headlines suggest, and cognition is shared with tools.

Key terms

Transactive memory
A shared memory system in which others or tools store information
Cognitive offloading
Using external tools to reduce mental effort
Media multitasking
Using several media or tasks at once
