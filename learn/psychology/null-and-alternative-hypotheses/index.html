Null and Alternative Hypotheses

Significance testing assesses how surprising the data are if the null hypothesis is true; we reject or fail to reject the null, never prove it.

Psychology · Statistics · about 2 minutes

What you'll be able to do

  • Define the null and alternative hypotheses
  • Explain the logic of null hypothesis significance testing
  • Distinguish one-tailed and two-tailed tests and when each is justified

Two hypotheses

  • The null hypothesis (H0) states there is no effect, difference or relationship in the population.
  • The alternative hypothesis (H1) states there is an effect. It can be directional (one-tailed) or non-directional (two-tailed).

The logic of testing

Statistical tests ask: if the null hypothesis were true, how surprising would data like these (or more extreme) be? If very surprising, below a chosen threshold (α, usually .05), we reject the null. If not, we fail to reject it. We never prove the null true, and rejecting it doesn't prove the alternative; it only says the data are unlikely under the null.

Worked example

Testing a memory intervention

  1. H0: mean recall is the same with and without the intervention.
  2. H1 (one-tailed): mean recall is higher with the intervention.
  3. The data show a difference that would occur less than 5% of the time if H0 were true, so H0 is rejected and H1 supported.

One- or two-tailed?

A one-tailed test puts all of α in one direction, making it easier to detect an effect in that direction but impossible to detect one in the other. It must be justified before seeing the data by theory or previous research; choosing it after seeing the data inflates false positives.

Common mistakeSaying "we accepted the null hypothesis, so there is no effect". A non-significant result may reflect low power.

In 2 lines: H0 states no effect; H1 states an effect, one- or two-tailed. Tests ask how surprising the data are under H0; we reject or fail to reject it.

Practice questions

Answer each one in your head before you open it: recalling beats rereading.

  1. If data are very unlikely under the null hypothesis, the researcher…
    • Rejects the null hypothesis
    • Proves the alternative hypothesis
    • Accepts the null hypothesis
    • Changes the significance level
    Show the answer

    Answer: Rejects the null hypothesis. Unlikely data lead to rejecting H0, not proving H1.

  2. A result is not significant at .05. What is the correct conclusion?
    • The null hypothesis is proven true
    • There is insufficient evidence to reject the null
    • There is definitely no effect
    • The study was unethical
    Show the answer

    Answer: There is insufficient evidence to reject the null. Non-significance can reflect a small effect or low power.

  3. What is the main criticism of treating p < .05 as a strict dividing line?
    • It makes tests too slow to run
    • It is only used in physics
    • It turns evidence into a yes-or-no
    • It always gives the correct answer
    Show the answer

    Answer: It turns evidence into a yes-or-no. Results just above and below .05 provide similar evidence; dichotomising encourages misinterpretation.

Key terms

Null hypothesis
The hypothesis that there is no effect, difference or relationship in the population
Alternative hypothesis
The hypothesis that there is an effect, difference or relationship
Significance level (α)
The threshold probability for rejecting the null, usually .05
