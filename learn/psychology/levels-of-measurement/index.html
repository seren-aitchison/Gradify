Levels of Measurement

Nominal, ordinal, interval and ratio data carry increasing information, and the level determines which averages and tests are appropriate.

Psychology · Statistics · about 2 minutes

What you'll be able to do

  • Define nominal, ordinal, interval and ratio data
  • Classify variables by their level of measurement
  • Explain how the level of measurement constrains the choice of statistics

Four levels

  • Nominal: categories with no order (diagnosis, eye colour, which condition someone chose). You can only count frequencies.
  • Ordinal: ordered categories or ranks, with unequal or unknown gaps (finishing position in a race, ratings from "never" to "always").
  • Interval: equal intervals between values but no true zero (temperature in degrees Celsius; many standardised test scores).
  • Ratio: equal intervals and a true zero, so ratios make sense (reaction time, number of words recalled, age).

The scheme was proposed by Stevens (1946). The mnemonic NOIR lists the levels in order of increasing information.

Why it matters

The level decides which descriptive statistics are meaningful: the mode for nominal data, the median for ordinal, the mean for interval and ratio. It also guides the choice of inferential test: parametric tests such as the t-test assume at least interval data, while non-parametric tests suit ordinal data.

Worked example

Classifying a questionnaire study

  1. Gender identity recorded as categories: nominal.
  2. Agreement rated 1 (strongly disagree) to 5 (strongly agree): ordinal for a single item.
  3. Total anxiety score summed across 20 items: often treated as interval.
  4. Minutes spent on social media: ratio.

Investigate with the lab. Enter counts into a two-by-two table and see that chi-square works with nominal data.

Grey areas

Whether summed rating scales can be treated as interval data is debated. Many researchers analyse them with parametric tests, arguing the results are robust; others insist on non-parametric methods for anything built from ordinal items.

Common mistakeCalculating a mean for nominal data, such as an "average diagnosis". Categories without order can only be counted.

In 2 lines: Levels of measurement are nominal, ordinal, interval and ratio (NOIR). The level determines the appropriate averages, graphs and tests.

Practice questions

Answer each one in your head before you open it: recalling beats rereading.

  1. Reaction time in milliseconds is…
    • Ratio data
    • Nominal data
    • Ordinal data
    • Interval data only
    Show the answer

    Answer: Ratio data. It has equal intervals and a true zero, so ratios (twice as slow) make sense.

  2. A researcher records which of four therapy types each client received. Which average is appropriate?
    • The mean
    • The mode
    • The median
    • The standard deviation
    Show the answer

    Answer: The mode. Therapy type is nominal, so only the most frequent category (mode) makes sense.

  3. Why is the level of measurement relevant to choosing between a t-test and a Mann–Whitney test?
    • Non-parametric tests need ratio data
    • The t-test is only for nominal data
    • Parametric tests assume at least interval data
    • The level makes no difference to test choice
    Show the answer

    Answer: Parametric tests assume at least interval data. Ordinal data suit non-parametric tests; interval or ratio data allow parametric tests if other assumptions hold.

  4. Which level of measurement is data on whether people did or didn't help?
    • Ordinal
    • Interval
    • Ratio
    • Nominal
    Show the answer

    Answer: Nominal. Categories with no order are nominal, which suits chi-square.

Key terms

Nominal data
Categories with no inherent order
Ordinal data
Ordered categories or ranks without equal intervals
Ratio data
Data with equal intervals and a true zero point
