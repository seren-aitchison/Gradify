Problem Solving

Problem solving uses algorithms, heuristics, insight and analogy, but can be blocked by fixation and mental set.

Psychology · Cognitive Psychology · about 2 minutes

What you'll be able to do

  • Describe problem solving in terms of problem spaces and strategies
  • Explain insight and the barriers of functional fixedness and mental set
  • Apply strategies such as means–ends analysis and analogy to problems

Problem spaces and strategies

Newell and Simon (1972) described a problem as a problem space: an initial state, a goal state and the operators that move between states. Algorithms guarantee a solution by checking every possibility but may be slow. Heuristics are rules of thumb that are faster but not guaranteed. Means–ends analysis reduces the difference between the current state and the goal, often by setting sub-goals; the Tower of Hanoi puzzle is a classic test.

Insight

Some problems are solved by sudden insight, an "aha" moment when the problem is restructured. Köhler (1925) described chimpanzees apparently suddenly stacking boxes to reach bananas. Insight problems often need a new way of seeing the problem.

Worked example

Barriers to problem solving

  1. Functional fixedness: in Duncker's (1945) candle problem, people struggle to fix a candle to a wall using a box of tacks because they see the box only as a container, not a shelf.
  2. Mental set: in Luchins's (1942) water-jar problems, people kept using a complex formula learned earlier even when a simpler solution was available.
  3. Both show that past experience can block new solutions.

Analogical problem solving applies a solution from one problem to another with similar structure. Gick and Holyoak (1980) found people rarely spotted a useful analogy spontaneously, but often did when hinted to use it.

Common mistakeAssuming experience always helps. Past solutions can create mental set and functional fixedness.

In 2 lines: Problems can be described as spaces solved by algorithms or heuristics. Insight restructures problems; fixation and mental set block solutions; analogies help when noticed.

Practice questions

Answer each one in your head before you open it: recalling beats rereading.

  1. Duncker's candle problem demonstrates…
    • Mental set
    • Means–ends analysis
    • Insight learning in apes
    • Functional fixedness
    Show the answer

    Answer: Functional fixedness. Seeing the box only as a container blocks the solution.

  2. A student keeps using a long method for maths problems even when a shortcut works. This is…
    • Mental set
    • Functional fixedness
    • Analogy
    • Insight
    Show the answer

    Answer: Mental set. Persisting with a learned method is mental set.

  3. Why might experts sometimes be slower than novices on unusual problems?
    • Experts have less knowledge
    • Experience creates mental set
    • Novices use algorithms
    • Experts lack heuristics
    Show the answer

    Answer: Experience creates mental set. Habitual approaches can block novel solutions.

Key terms

Heuristic
A rule of thumb that simplifies problem solving
Functional fixedness
Seeing an object only in terms of its usual function
Means–ends analysis
Reducing the gap between current state and goal through sub-goals
