Individual Differences in Learning

Pupils differ in prior knowledge, working memory and other factors; teaching should adapt while keeping high expectations; brain training shows little transfer.

Psychology · Applied Psychology · about 2 minutes

What you'll be able to do

  • Describe key individual differences relevant to learning
  • Explain how prior knowledge and working memory affect learning
  • Evaluate approaches to differentiation and adaptive teaching

Key differences

Pupils differ in prior knowledge, working memory capacity, attention, language skills, processing speed, motivation and self-regulation. Prior knowledge is one of the strongest predictors of learning: new information is easier to understand and remember when it connects to what pupils already know.

Working memory

Gathercole and Alloway (2008) found children with poor working memory struggle with following instructions, keeping track of tasks and learning in mainstream classrooms, and are often seen as inattentive. Strategies include breaking instructions into steps, providing memory aids and reducing unnecessary load. "Brain training" to increase working memory capacity shows little transfer to classroom learning (Melby-Lervåg and Hulme, 2013).

Worked example

The expertise reversal effect

  1. Kalyuga et al. (2003) found that worked examples help novices, but can slow down learners who already have expertise.
  2. For experts, independent problem-solving becomes more effective.
  3. The best instruction depends on learners' prior knowledge.

Adaptive teaching

Older approaches to differentiation sometimes meant preparing different worksheets for groups, which can lower expectations. Current guidance in England emphasises adaptive teaching: high expectations for all, with teachers responding to pupils' needs through scaffolding, questioning and feedback (DfE Teachers' Standards and Early Career Framework). The aim is to help all pupils reach ambitious goals.

Common mistakeAssuming differentiation means giving some pupils easier tasks. Adaptive teaching keeps high expectations with tailored support.

In 2 lines: Prior knowledge and working memory strongly affect learning. Instruction should match expertise; adaptive teaching keeps high expectations; brain training shows little transfer.

Practice questions

Answer each one in your head before you open it: recalling beats rereading.

  1. Which factor is one of the strongest predictors of new learning?
    • Shoe size
    • Learning style
    • Birth order
    • Prior knowledge
    Show the answer

    Answer: Prior knowledge. New learning builds on what is already known.

  2. A pupil often forgets multi-step instructions and is seen as inattentive. A likely explanation is…
    • Poor working memory
    • Low intelligence only
    • Learning style mismatch
    • Laziness
    Show the answer

    Answer: Poor working memory. Gathercole and Alloway linked this to working memory.

  3. Why might worked examples slow down experts?
    • Experts can't read examples
    • They add redundant information
    • Examples are always harmful
    • Novices don't need help
    Show the answer

    Answer: They add redundant information. For experts, worked examples are redundant.

Key terms

Prior knowledge
What learners already know, which supports new learning
Expertise reversal effect
Instruction helpful for novices becoming less effective for experts
Adaptive teaching
Responding to pupils' needs while maintaining high expectations
