Working Memory

Working memory is a multi-component system for holding and manipulating information, supported by dual-task and neuropsychological evidence.

Psychology · Cognitive Psychology · about 2 minutes

What you'll be able to do

  • Describe the components of the working memory model
  • Explain dual-task and neuropsychological evidence for separate components
  • Evaluate the working memory model against the multi-store model

Beyond a single short-term store

Baddeley and Hitch (1974) argued that short-term memory isn't a single passive store but an active working memory with several components:

  • Central executive: directs attention and coordinates the other parts; has limited capacity and no storage of its own.
  • Phonological loop: holds speech-based information. It has a phonological store (the "inner ear") and an articulatory control process (the "inner voice") that rehearses.
  • Visuospatial sketchpad: holds visual and spatial information (the "inner eye").
  • Episodic buffer (added by Baddeley, 2000): a limited-capacity store that combines information from the other parts and long-term memory into integrated episodes.

Evidence

Dual-task studies show two verbal tasks interfere with each other more than a verbal and a visual task do, suggesting separate stores. The word length effect shows people remember more short words than long ones, because the loop holds about as much as can be said in roughly two seconds. Articulatory suppression (repeating "the the the") removes the word length effect by blocking rehearsal.

Worked example

Neuropsychological evidence

  1. Patient KF had brain damage that impaired verbal short-term memory for heard material (Shallice and Warrington, 1970).
  2. His visual short-term memory and long-term memory were relatively intact.
  3. This suggests separate short-term components, which the single store in the multi-store model can't explain.

Investigate with the lab. Measure your digit span, then try chunking the digits into groups and measure it again.

Common mistakeThinking the central executive is well understood. It is the least specified component of the model.

In 2 lines: The model has a central executive, phonological loop, visuospatial sketchpad and episodic buffer. Dual-task studies and patients such as KF support separate components; the executive is vague.

Practice questions

Answer each one in your head before you open it: recalling beats rereading.

  1. Which component of working memory holds visual and spatial information?
    • Phonological loop
    • Episodic buffer
    • Central executive
    • Visuospatial sketchpad
    Show the answer

    Answer: Visuospatial sketchpad. The visuospatial sketchpad, the "inner eye", stores visual and spatial material.

  2. A participant can track a moving dot while repeating digits, but struggles to repeat digits while reading. Why?
    • Reading and digits both use the phonological loop
    • Dots use the episodic buffer
    • The executive has unlimited capacity
    • Digits are visual
    Show the answer

    Answer: Reading and digits both use the phonological loop. Two verbal tasks compete for the same component.

  3. How does patient KF challenge the multi-store model?
    • He had no long-term memory
    • Short-term memory looks fractionated
    • He had perfect recall
    • He recalled only long words
    Show the answer

    Answer: Short-term memory looks fractionated. Selective verbal impairment implies separate components.

  4. How does chunking increase memory span?
    • It makes each digit shorter to say
    • It moves items straight to long-term memory
    • It groups items into meaningful units, so more items fit
    • It doubles the capacity of the phonological loop
    Show the answer

    Answer: It groups items into meaningful units, so more items fit. Short-term memory holds a limited number of chunks, not individual items.

Key terms

Central executive
The component that directs attention and coordinates working memory
Phonological loop
The component that holds and rehearses speech-based information
Word length effect
Better recall of short words than long words
