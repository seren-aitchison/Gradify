Chi-square Tests

Chi-square tests compare observed and expected frequencies for nominal data; report χ², df, p and Cramér's V.

Psychology · Statistics · about 2 minutes

What you'll be able to do

  • Identify when a chi-square test is appropriate
  • Calculate expected frequencies for a contingency table
  • Interpret a chi-square result with Cramér's V

Counting in categories

When both variables are nominal, data are frequencies: how many people fall in each category. The chi-square (χ²) test of independence asks whether the pattern of counts in a contingency table differs from what we'd expect if the variables were unrelated. The goodness-of-fit test compares counts in one variable with expected proportions. Pearson introduced the test in 1900.

Expected frequencies

For each cell, expected = (row total × column total) ÷ grand total. χ² = Σ (observed − expected)² ÷ expected. Degrees of freedom = (rows − 1) × (columns − 1). Expected frequencies should generally be at least 5 per cell.

Worked example

Helping and gender of the person in need

  1. Observed: helped a woman 20 of 30 times, a man 10 of 30 times; did not help: 10 and 20.
  2. Each expected count = (30 × 30) ÷ 60 = 15.
  3. χ² = 4 × (5² ÷ 15) ≈ 6.67, df = 1, p ≈ .010; Cramér's V ≈ .33, a moderate association.

Reporting the percentages in each row alongside χ² shows the direction and size of the association, which the test statistic alone doesn't.

Common mistakeRunning chi-square on percentages or means. It must use raw frequencies, and each person must appear in only one cell.

In 2 lines: Chi-square tests analyse frequencies in categories against expected counts. Use raw counts, check expected frequencies, and report Cramér's V.

Practice questions

Answer each one in your head before you open it: recalling beats rereading.

  1. Chi-square tests are used for…
    • Comparing two means
    • Ranked correlations
    • Repeated measures scores
    • Frequency data in categories
    Show the answer

    Answer: Frequency data in categories. Chi-square analyses counts of nominal data.

  2. Researchers record whether 80 students chose science or arts and whether they attended a state or private school. Which test fits?
    • Chi-square test
    • Independent t-test
    • Pearson's r
    • Paired t-test
    Show the answer

    Answer: Chi-square test. Both variables are categorical, so the data are frequencies suited to chi-square.

  3. Why must each participant contribute to only one cell?
    • It makes the table smaller
    • The test assumes independent observations
    • Expected counts must be zero
    • It increases the degrees of freedom
    Show the answer

    Answer: The test assumes independent observations. Counting the same person twice violates independence.

Key terms

Chi-square test
A test comparing observed frequencies with expected frequencies
Contingency table
A table of frequencies cross-classified by two categorical variables
Cramér's V
An effect size for chi-square, from 0 (no association) to 1
