Computational Psychology

Computational models make theories precise and testable; Marr's three levels guide explanation; reinforcement learning and drift diffusion models explain learning and choice; good fit isn't proof.

Psychology · Contemporary Psychology · about 2 minutes

What you'll be able to do

  • Explain the purpose of computational models in psychology
  • Describe examples of computational models of learning and decision-making
  • Evaluate the strengths and limits of computational approaches

Why build models?

A computational model specifies a theory precisely enough to be run as a program. This forces theories to be explicit, allows quantitative predictions and lets researchers compare competing explanations against data. Marr (1982) distinguished three levels of explanation: computational (what problem is solved and why), algorithmic (how it is solved) and implementational (how the brain does it).

Examples

Reinforcement learning models describe how agents learn from rewards using prediction errors: the difference between expected and actual outcomes. Dopamine neurons appear to signal reward prediction errors. Drift diffusion models describe decisions as evidence accumulating over time until it reaches a threshold, predicting both choices and reaction times.

Worked example

A worked prediction error

  1. A participant expects a reward of 5 points from a choice but receives 8.
  2. The prediction error is 8 − 5 = +3, so the model increases the expected value of that choice.
  3. If the learning rate is 0.5, the new expectation is 5 + 0.5 × 3 = 6.5. This example is illustrative.

Evaluation

Models make theories precise and testable and link behaviour to brain activity. But a model that fits data well isn't necessarily true: different models can fit the same data, and complex models can overfit. Models also simplify, leaving out emotion, context and individual differences unless these are built in.

Common mistakeAssuming a model that fits data must be correct. Other models may fit equally well.

Practice questions

Answer each one in your head before you open it: recalling beats rereading.

  1. Describing decisions as evidence accumulating until a threshold is reached is a…
    • Drift diffusion model
    • Reinforcement learning model
    • Network model
    • Lesion study
    Show the answer

    Answer: Drift diffusion model. Drift diffusion models describe evidence accumulation.

  2. A model with many parameters fits one dataset perfectly but predicts new data poorly. This is…
    • Reverse inference
    • Overfitting
    • Statistical power
    • Implementational explanation
    Show the answer

    Answer: Overfitting. Fitting noise reduces predictive accuracy.

  3. Why isn't a good model fit proof that a model is correct?
    • Models never fit any real data
    • A good fit always proves truth
    • Other models can fit the same data equally well
    • Data can never test any model
    Show the answer

    Answer: Other models can fit the same data equally well. Model comparison and new predictions are needed.

Key terms

Computational model
A theory specified precisely enough to run as a program
Prediction error
The difference between expected and actual outcomes
Overfitting
A model fitting noise in data rather than the underlying process
