Qualitative Analysis

Qualitative analysis uses flame tests, precipitation and gas tests for inorganic ions and characteristic reagents for organic groups, applied in a logical order to avoid interference.

Chemistry · Analytical Chemistry and Spectroscopy · about 2 minutes

What you'll be able to do

  • Describe tests for common cations and anions
  • Describe tests for organic functional groups
  • Plan a sequence of tests to identify an unknown

Inorganic tests

  • Flame tests: Li red, Na yellow, K lilac, Ca orange-red, Cu blue-green.
  • Carbonates fizz with acid, giving CO₂ that turns limewater milky.
  • Halides with acidified AgNO₃: white AgCl, cream AgBr, yellow AgI.
  • Sulfates with acidified BaCl₂: white BaSO₄.
  • Ammonium with warm NaOH releases ammonia, turning damp red litmus blue.

Organic tests

  • Alkenes: decolourise bromine water.
  • Carbonyls: orange precipitate with 2,4-DNPH.
  • Aldehydes: silver mirror with Tollens'.
  • Carboxylic acids: fizz with sodium carbonate.

Tests are done in a logical order so earlier reagents do not interfere with later ones. For example, carbonate is tested before sulfate, because carbonate would also precipitate with barium ions unless acid removes it first. Modern labs use instruments, but simple tests remain quick and cheap.

Worked example

Identifying an unknown salt.

  1. A flame test gives a lilac flame: potassium.
  2. Acidified silver nitrate gives a cream precipitate: bromide.
  3. The precipitate dissolves in concentrated ammonia.
  4. The salt is potassium bromide.
Common mistakeAdding barium chloride without acid first. Carbonate would also give a white precipitate.

In 3 lines: Flame and precipitate tests. Organic group tests. Logical order.

Practice questions

Answer each one in your head before you open it: recalling beats rereading.

  1. Which halide gives a yellow precipitate with acidified silver nitrate?
    • Chloride
    • Bromide
    • Fluoride
    • Iodide
    Show the answer

    Answer: Iodide. Silver iodide is pale yellow and insoluble in ammonia.

  2. Why is the sample acidified before adding barium chloride?
    • To remove carbonate, which would also precipitate with barium
    • To make the sulfate ions more soluble
    • To change the flame colour of barium
    • To prevent any precipitate from forming
    Show the answer

    Answer: To remove carbonate, which would also precipitate with barium. Carbonate gives a false positive unless destroyed.

  3. Why are tests performed in a particular order?
    • The order of tests makes no difference to results
    • Earlier reagents can interfere with later tests
    • All the tests use exactly the same reagent
    • Later tests always remove the ions found earlier
    Show the answer

    Answer: Earlier reagents can interfere with later tests. Planning the order avoids false positives from earlier reagents.

Key terms

Flame test
Identifying metal ions by flame colour
Precipitate
An insoluble solid formed in solution
Interference
A substance giving a false result in a test
