Quantum Numbers

n gives the shell, l the subshell shape, mₗ the orientation and mₛ the spin; their allowed values give n² orbitals and 2n² electrons per shell.

Chemistry · Atomic Structure and Quantum Chemistry · about 3 minutes

What you'll be able to do

  • Name and describe the four quantum numbers
  • State the allowed values of each and relate them to shells, subshells and orbitals
  • Use quantum numbers to count the orbitals and electrons in a shell

The four quantum numbers

  • Principal quantum number, n = 1, 2, 3…: the shell, and mainly the orbital's size and energy.
  • Angular momentum (azimuthal) quantum number, l = 0 to n − 1: the subshell and the orbital's shape. l = 0, 1, 2, 3 are s, p, d, f.
  • Magnetic quantum number, mₗ = −l to +l: the orbital's orientation, giving 2l + 1 orbitals in each subshell.
  • Spin quantum number, mₛ = +½ or −½: the electron's spin.

The first three come from solving the Schrödinger equation for the electron; spin was added after experiments such as Stern and Gerlach's (1922) showed electrons behave like tiny magnets with two possible orientations.

Counting with quantum numbers

Worked example

How many orbitals and electrons are in the n = 3 shell?

  1. l can be 0, 1 or 2 (3s, 3p, 3d).
  2. mₗ gives 1, 3 and 5 orbitals: 9 orbitals in total, which is n².
  3. Two spins per orbital: 18 electrons, which is 2n².

Labelling an electron

The outer electron of a sodium atom is in a 3s orbital: n = 3, l = 0, mₗ = 0, mₛ = +½ (or −½). A 2p electron has n = 2, l = 1 and mₗ = −1, 0 or +1. No two electrons in an atom can share all four values, the Pauli exclusion principle.

For hydrogen, the energy depends only on n. In atoms with more electrons it also depends on l, because electrons in different subshells are shielded differently, which is why 4s fills before 3d.

Investigate with the lab. Step from 1s to 3d and read the quantum numbers n, l and mₗ for each orbital shown.

Common mistakeThinking l can equal n. The largest value of l in shell n is n − 1, so there is no 1p or 2d orbital.

In 3 lines: Four quantum numbers: n, l, mₗ and mₛ. l runs from 0 to n − 1 and mₗ from −l to +l. Each shell has n² orbitals and holds 2n² electrons.

Practice questions

Answer each one in your head before you open it: recalling beats rereading.

  1. Which set of quantum numbers is not allowed?
    • n = 2, l = 2, mₗ = 0
    • n = 2, l = 1, mₗ = −1
    • n = 3, l = 0, mₗ = 0
    • n = 3, l = 2, mₗ = +2
    Show the answer

    Answer: n = 2, l = 2, mₗ = 0. l must be less than n, so l = 2 isn't allowed in the second shell.

  2. An electron has n = 3 and l = 1. Which orbital is it in?
    • A 3s orbital
    • A 3p orbital
    • A 3d orbital
    • A 1p orbital
    Show the answer

    Answer: A 3p orbital. l = 1 is a p orbital, and n = 3 places it in the third shell.

  3. Why does each orbital hold at most two electrons?
    • Orbitals are too small for three electrons
    • Three electrons would have no charge
    • Electrons in the same orbital share n, l and mₗ, so they can differ only in spin, which has two values
    • The nucleus attracts only two electrons per orbital
    Show the answer

    Answer: Electrons in the same orbital share n, l and mₗ, so they can differ only in spin, which has two values. With three quantum numbers fixed by the orbital, the Pauli principle allows only the two spin states.

  4. What does the quantum number l describe?
    • The orbital's energy level only
    • The electron's spin direction
    • The number of electrons in the atom
    • The shape of the orbital
    Show the answer

    Answer: The shape of the orbital. l = 0, 1 and 2 correspond to s, p and d orbitals.

Key terms

Principal quantum number
n, the quantum number for an orbital's shell, size and main energy
Angular momentum quantum number
l, the quantum number for an orbital's shape (s, p, d, f for l = 0, 1, 2, 3)
Magnetic quantum number
mₗ, the quantum number for an orbital's orientation, from −l to +l
