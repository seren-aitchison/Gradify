Le Chatelier's Principle

Le Chatelier's principle states that a disturbed equilibrium shifts to oppose the change: adding reactant or removing product shifts right, heating favours the endothermic direction, raising pressure favours fewer gas molecules, and catalysts cause no shift.

Chemistry · Chemical Equilibrium · about 2 minutes

What you'll be able to do

  • State Le Chatelier's principle
  • Predict shifts in equilibrium position after a change
  • Recognise the limits of the principle

The principle

  • If a system at equilibrium is disturbed, the position shifts to oppose the change.
  • Changes include concentration, pressure and temperature.
  • The system partially counteracts, but does not fully undo, the change.
  • Catalysts do not shift equilibrium.

Applying it

  • Add reactant: shifts right.
  • Remove product: shifts right.
  • Increase temperature: shifts in the endothermic direction.
  • Increase pressure: shifts towards fewer gas molecules.

Henri Le Chatelier stated the principle in 1884. It is a qualitative guide; quantitative predictions use K. Only temperature changes the value of K; other changes shift the position while K stays constant.

Worked example

The chromate-dichromate equilibrium.

  1. 2CrO₄²⁻ (yellow) + 2H⁺ ⇌ Cr₂O₇²⁻ (orange) + H₂O.
  2. Adding acid increases [H⁺], so the position shifts right and turns orange.
  3. Adding alkali removes H⁺, so it shifts left and turns yellow.
  4. Colour changes reveal the shift.
Common mistakeThinking the system completely cancels a change. It only partially opposes it.

In 3 lines: Opposes change. Concentration, pressure, temperature. Catalysts do not shift.

Practice questions

Answer each one in your head before you open it: recalling beats rereading.

  1. What happens when acid is added to yellow chromate solution?
    • It turns pale green as chromium is reduced
    • It turns green
    • It turns orange as equilibrium shifts right
    • Nothing happens
    Show the answer

    Answer: It turns orange as equilibrium shifts right. Extra H⁺ drives formation of orange dichromate.

  2. Which direction does increasing temperature favour?
    • The exothermic direction
    • The side with more gas
    • No direction
    • The endothermic direction
    Show the answer

    Answer: The endothermic direction. The system absorbs the added heat by favouring the endothermic direction.

  3. Why doesn't the system fully undo a change?
    • It only partially opposes the change while K is restored
    • It always overcorrects past the original
    • It ignores all changes
    • K changes to match
    Show the answer

    Answer: It only partially opposes the change while K is restored. The new equilibrium still reflects the change.
