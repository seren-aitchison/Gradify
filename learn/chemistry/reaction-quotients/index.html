Reaction Quotients

The reaction quotient Q uses current concentrations in the K expression; comparing Q with K predicts the direction: Q < K forward, Q > K backward, Q = K at equilibrium, and ΔG = ΔG⦵ + RT ln Q.

Chemistry · Chemical Equilibrium · about 2 minutes

What you'll be able to do

  • Define the reaction quotient Q
  • Compare Q with K to predict the direction of reaction
  • Link Q to Gibbs free energy

The reaction quotient

  • Q has the same form as K but uses current concentrations or pressures.
  • At equilibrium, Q = K.
  • Q can be calculated for any mixture.
  • It shows how far a mixture is from equilibrium.

Predicting direction

  • Q < K: too few products; the reaction moves forward.
  • Q > K: too many products; the reaction moves backward.
  • Q = K: at equilibrium, no net change.
  • ΔG = ΔG⦵ + RT ln Q links Q to free energy.

When ΔG = 0, Q = K, which is the condition for equilibrium. Q explains Le Chatelier's principle: adding reactant lowers Q below K, so the reaction moves forward until Q equals K again.

Worked example

Predicting direction.

  1. For A ⇌ B, K = 4.
  2. A mixture has [A] = 0.50 and [B] = 1.00 mol dm⁻³.
  3. Q = 1.00 ÷ 0.50 = 2, which is less than K.
  4. The reaction moves forward, forming more B.
Common mistakeThinking Q and K are always the same. Q equals K only at equilibrium.

In 3 lines: Q uses current values. Compare Q and K. Link to ΔG.

Practice questions

Answer each one in your head before you open it: recalling beats rereading.

  1. What is true when Q equals K?
    • The reaction moves forward
    • The reaction moves backward
    • The reaction is complete
    • The system is at equilibrium
    Show the answer

    Answer: The system is at equilibrium. No net change occurs when Q = K because the system is at equilibrium.

  2. How does adding reactant affect Q?
    • It lowers Q below K, so the reaction moves forward
    • It raises Q above K so the reaction goes back
    • It changes K
    • It makes Q equal to zero
    Show the answer

    Answer: It lowers Q below K, so the reaction moves forward. More reactant increases the denominator of Q, lowering it below K.

  3. How does Q explain Le Chatelier's principle?
    • Q changes K directly
    • Changes make Q differ from K, and the reaction shifts until Q equals K
    • Q is always equal to K
    • Le Chatelier's principle ignores concentrations
    Show the answer

    Answer: Changes make Q differ from K, and the reaction shifts until Q equals K. After a change, the system shifts in the direction that restores Q = K.

Key terms

Reaction quotient
Q, the K expression using current concentrations
Direction of reaction
Whether a mixture moves towards products or reactants
Equilibrium condition
Q equals K
