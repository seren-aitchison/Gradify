Genetic Code

The genetic code is a triplet, degenerate, non-overlapping and nearly universal code of 64 codons, with AUG as start and three stop codons, read in a fixed frame, so insertions and deletions cause frameshifts.

Biology · Genetics and Molecular Biology · about 2 minutes

What you'll be able to do

  • Describe the triplet nature of the genetic code
  • Explain degeneracy, universality and non-overlapping features
  • Use a codon table to translate sequences

Features

  • Triplet: each codon is three bases, giving 4³ = 64 codons.
  • Degenerate: most amino acids are coded by more than one codon (61 codons for 20 amino acids).
  • Non-overlapping: each base is part of only one codon.
  • Universal: the same codons code for the same amino acids in almost all organisms.
  • Start and stop: AUG starts; UAA, UAG and UGA stop.

Reading frames

  • The code is read in a fixed reading frame from the start codon.
  • Inserting or deleting a base shifts the frame, changing every following codon (frameshift).
  • Degeneracy means some base changes, especially in the third position, do not change the amino acid.

The code was cracked in the 1960s by Nirenberg, Khorana and others, using synthetic RNA. Its near universality is evidence of common ancestry and allows genes to be moved between organisms, such as human insulin genes expressed in bacteria. A few exceptions exist, such as in mitochondria, where UGA codes for tryptophan.

Worked example

Using a codon table.

  1. mRNA: AUG UUU GGC UGA.
  2. AUG = methionine (start); UUU = phenylalanine; GGC = glycine.
  3. UGA = stop.
  4. The peptide is Met-Phe-Gly.
Common mistakeSaying each amino acid has exactly one codon. Most have several, because the code is degenerate.

In 3 lines: Triplet, 64 codons. Degenerate and universal. Frameshifts change everything after.

Practice questions

Answer each one in your head before you open it: recalling beats rereading.

  1. What does it mean that the genetic code is degenerate?
    • Most amino acids are coded by more than one codon
    • Each codon codes for several amino acids
    • The code changes between organisms
    • Codons overlap
    Show the answer

    Answer: Most amino acids are coded by more than one codon. 61 codons code for 20 amino acids, so most have several.

  2. Why does deleting one base usually have a large effect?
    • It removes only a single amino acid
    • It shifts the reading frame, changing all later codons
    • It never affects the protein produced
    • It breaks the sugar-phosphate backbone
    Show the answer

    Answer: It shifts the reading frame, changing all later codons. Frameshifts alter every codon after the deletion.

  3. Why is the near universality of the genetic code useful in biotechnology?
    • It means all organisms make the same proteins
    • It prevents mutations
    • A gene from one organism can be expressed correctly in another
    • It makes genes impossible to transfer
    Show the answer

    Answer: A gene from one organism can be expressed correctly in another. Shared codon meanings let bacteria make human proteins such as insulin.

Key terms

Codon
A triplet of bases coding for an amino acid or stop
Degenerate
Having more than one codon for most amino acids
Reading frame
The way a sequence is divided into codons
