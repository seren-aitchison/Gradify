Phylogenetic Analysis

Phylogenetic trees are built by distance methods such as neighbour joining, parsimony, maximum likelihood or Bayesian inference; bootstrapping tests support and outgroups root trees.

Biology · Bioinformatics and Computational Biology · about 2 minutes

What you'll be able to do

  • Describe distance-based and character-based tree methods
  • Explain bootstrapping
  • Explain how trees are rooted

Methods

  • Distance methods, such as neighbour joining, build trees from pairwise distances.
  • Maximum parsimony chooses the tree needing fewest changes.
  • Maximum likelihood finds the tree that makes the data most probable under a model of evolution.
  • Bayesian inference estimates the probability of trees given the data.

Confidence and rooting

  • Bootstrapping resamples alignment columns many times to test tree support.
  • Bootstrap values above about 70% are often taken as good support.
  • Trees are rooted using an outgroup, a species known to be outside the group.
  • Models account for different rates of substitution.

Phylogenetic analysis of virus genomes was used to trace the spread of SARS-CoV-2 variants. Long-branch attraction can cause fast-evolving lineages to group together incorrectly. Choosing appropriate models and checking support reduces errors.

Worked example

Bootstrapping a tree.

  1. A tree is built from an alignment of 500 positions.
  2. 1,000 new alignments are made by sampling columns with replacement.
  3. A tree is built from each.
  4. A grouping appearing in 950 of them has 95% bootstrap support.
Common mistakeThinking a bootstrap value is the probability a grouping is true. It measures how consistently the data support it.

In 3 lines: Distance and character methods. Bootstrap support. Outgroup rooting.

Practice questions

Answer each one in your head before you open it: recalling beats rereading.

  1. Which method finds the tree requiring the fewest changes?
    • Maximum likelihood
    • Neighbour joining
    • Bootstrapping
    • Maximum parsimony
    Show the answer

    Answer: Maximum parsimony. Parsimony prefers the simplest explanation.

  2. How is a phylogenetic tree rooted?
    • By including an outgroup
    • By deleting the longest branch
    • By adding more ingroup species
    • By removing all gaps
    Show the answer

    Answer: By including an outgroup. The outgroup branches off first, showing where the root lies.

  3. What is long-branch attraction?
    • Short branches always being correct
    • Fast-evolving lineages wrongly grouping together
    • Outgroups being too similar
    • Bootstrapping failing to run
    Show the answer

    Answer: Fast-evolving lineages wrongly grouping together. Many changes can create false similarity.

Key terms

Neighbour joining
A distance-based tree-building method
Bootstrapping
Resampling data to assess support for tree branches
Outgroup
A taxon outside the group used to root a tree
