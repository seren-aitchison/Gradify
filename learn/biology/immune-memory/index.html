Immune Memory

Memory B and T cells survive after infection, giving faster and stronger secondary responses due to greater numbers, easier activation and matured antibodies; memory can last for life, though some pathogens evade it by antigenic variation.

Biology · Immunology · about 2 minutes

What you'll be able to do

  • Describe memory B and T cells
  • Explain why secondary responses are stronger
  • Explain how long immune memory lasts

Memory cells

  • After an infection, most effector cells die, but memory cells survive.
  • Memory B cells rapidly produce high-affinity antibodies on re-exposure.
  • Memory T cells include central memory (in lymph nodes) and effector memory (in tissues).
  • Tissue-resident memory T cells stay at sites such as the skin and lungs.

Why responses are stronger

  • There are many more antigen-specific cells than before.
  • Memory cells activate more easily.
  • Antibodies have already undergone affinity maturation and class switching to IgG.
  • Long-lived plasma cells may maintain antibody levels for years.

Memory to some infections, such as measles, lasts for life, while immunity to others, such as seasonal coronaviruses, wanes more quickly. People who survived the 1918 influenza pandemic still had antibodies to the virus over 90 years later. Antigenic variation can allow pathogens to evade memory.

Worked example

Memory lasting decades.

  1. Survivors of the 1918 influenza pandemic were tested in 2008.
  2. Their blood still contained B cells making antibodies to the 1918 virus.
  3. These antibodies neutralised the virus in experiments.
  4. Immune memory had lasted about 90 years.
Common mistakeThinking immune memory lasts the same time for every infection. Its duration varies with the pathogen.

In 3 lines: Memory B and T cells. Faster, stronger responses. Duration varies.

Practice questions

Answer each one in your head before you open it: recalling beats rereading.

  1. What happens to most effector cells after an infection clears?
    • They die, leaving memory cells
    • They all become plasma cells
    • They become red blood cells
    • They stay active forever
    Show the answer

    Answer: They die, leaving memory cells. Contraction leaves a pool of memory cells.

  2. Why are secondary responses stronger?
    • Antibodies are weaker the second time
    • There are many more specific cells that activate easily
    • Innate immunity is absent
    • Pathogens are always weaker
    Show the answer

    Answer: There are many more specific cells that activate easily. Expanded memory populations respond rapidly.

  3. Why can some pathogens reinfect despite immune memory?
    • Memory cells are destroyed instantly
    • Memory never forms
    • Antigenic variation changes the targets memory recognises
    • Pathogens are too small to recognise
    Show the answer

    Answer: Antigenic variation changes the targets memory recognises. Changed surface antigens are no longer recognised by memory cells.

Key terms

Memory cell
A long-lived lymphocyte that responds quickly to re-exposure
Tissue-resident memory T cell
A memory T cell remaining in a tissue
Long-lived plasma cell
A plasma cell producing antibody for years
