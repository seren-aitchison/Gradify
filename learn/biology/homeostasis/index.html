Homeostasis

Homeostasis maintains a stable internal environment using receptors, coordinators and effectors around set points; negative feedback reverses changes, as with insulin and glucose, while positive feedback amplifies them, as in childbirth.

Biology · Human Anatomy and Physiology · about 2 minutes

What you'll be able to do

  • Define homeostasis
  • Describe the components of a negative feedback loop
  • Distinguish negative and positive feedback with examples

Control systems

  • Homeostasis is maintaining a stable internal environment despite external changes.
  • Controlled variables include body temperature, blood glucose, blood pH, water balance and blood pressure.
  • A control system has a receptor (detects change), a coordinator (such as the brain) and an effector (makes the response).
  • Each variable has a set point, such as about 37 °C for core temperature.

Feedback

  • Negative feedback reverses a change, returning the variable towards the set point.
  • Example: rising blood glucose triggers insulin release, which lowers glucose.
  • Positive feedback amplifies a change and is rarer.
  • Example: oxytocin increasing contractions during childbirth, and blood clotting.

Homeostasis allows enzymes and cells to work in optimal conditions. Failure of homeostasis causes disease: in type 1 diabetes, insulin is not produced, so blood glucose cannot be controlled. Many variables are controlled by more than one effector working in opposite directions, which gives finer control, as with insulin and glucagon.

Worked example

Blood glucose control.

  1. After a meal, blood glucose rises above the set point.
  2. The pancreas detects this and releases insulin.
  3. Cells take up glucose and the liver stores it as glycogen.
  4. Blood glucose falls back towards normal: negative feedback.
Common mistakeThinking homeostasis keeps variables exactly constant. Variables fluctuate within a narrow range around a set point.

In 3 lines: Stable internal environment. Receptor, coordinator, effector. Negative versus positive feedback.

Practice questions

Answer each one in your head before you open it: recalling beats rereading.

  1. What is the role of an effector in a control system?
    • To detect the change in the variable
    • To store the set point permanently
    • To carry out the response that changes the variable
    • To prevent any response occurring
    Show the answer

    Answer: To carry out the response that changes the variable. Effectors such as muscles or glands make the corrective response.

  2. Why is insulin release after a meal an example of negative feedback?
    • It raises blood glucose even further
    • It has no effect on blood glucose
    • It stops all glucose absorption
    • It lowers blood glucose back towards the set point
    Show the answer

    Answer: It lowers blood glucose back towards the set point. The response opposes the original rise, returning glucose to the set point.

  3. Why do opposing hormones such as insulin and glucagon give finer control?
    • The variable can be actively pushed in either direction
    • They both raise blood glucose together
    • They cancel each other permanently
    • They are released only in disease
    Show the answer

    Answer: The variable can be actively pushed in either direction. Two antagonistic effectors allow rapid correction both ways.

Key terms

Homeostasis
Maintenance of a stable internal environment
Negative feedback
A response that reverses a change
Positive feedback
A response that amplifies a change
